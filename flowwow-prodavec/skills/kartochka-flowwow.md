# Карточка Flowwow: стандарт сборки

## Обязательные поля

| Поле | Требование |
|---|---|
| Название | до 60–70 знаков, ключи впереди, повод/получатель |
| Цена | одна цифра, не ниже 3 000 ₽ при пакете «Полный» |
| Наличие | остаток 3–10 или срок изготовления; не «последний» |
| Состав | поштучно, конкретные растения и размеры стеблей |
| Размер | Ш×В с упаковкой, см |
| Вес | граммы |
| Описание | 400–700 знаков по структуре из `kopiraiting.md` |
| Фото | 6 штук 1:1 ≥1200×1200, без водяного знака |
| Тематическая категория | подборка, если товар подходит по стоп-словам |

## Порядок сборки

1. Взять фото и замеры у себя (свои кадры), не у Вовы.
2. Написать название и описание по `kopiraiting.md`.
3. Проверить стоп-слова (чужие праздники и получатели).
4. Собрать карточку в кабинете, отправить на модерацию.
5. После публикации открыть как покупатель: цена, состав, фото, доставка.
6. Записать: карточка, дата, что изменилось.

## Топ-18

18 карточек, которые видит покупатель первыми. Товары в топ-18 получают **в 7 раз больше показов** (16 против 2,3 за 30 дней). Заполнять лучшими сезонными позициями и менять раз в 2 недели.

## Чек-лист перед публикацией

- [ ] название по формуле, без КАПСА и «недорого»;
- [ ] цена выше порога маржи;
- [ ] остаток 3–10 или срок изготовления;
- [ ] состав поштучно, размер и вес;
- [ ] 6 фото 1:1 без водяного знака;
- [ ] описание: повод → состав → размер → доставка → призыв;
- [ ] нет стоп-слов и чужих праздников;
- [ ] тематическая подборка выбрана;
- [ ] проверено на телефоне.
