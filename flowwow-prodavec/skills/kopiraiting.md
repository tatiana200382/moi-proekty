# Копирайтинг для карточек Flowwow

Навык Марка. Пишет сам, ни к кому не обращается.

## Формулы, которым следую

| Формула | Когда | Пример |
|---|---|---|
| **AIDA** | карточка целиком | Внимание (повод) → Интерес (состав) → Желание (эмоция вручения) → Действие (заказ) |
| **PAS** | если у клиента проблема | Проблема («не знаю, что подарить») → Усиление («а дата уже завтра») → Решение (букет + доставка) |
| **4U** | заголовок | Полезность, Срочность, Уникальность, Конкретность |
| **«Ты-язык»** | описание | не «мы дарим», а «вы получаете» |
| **Конкретика вместо эпитетов** | всегда | не «шикарный букет», а «9 роз 60 см, гортензия, 2 ветки эвкалипта» |

## Структура названия (до 60–70 знаков, ключи впереди)

```
<Что это> <повод или получатель> — <состав коротко> <размер>
Букет для мамы — 9 роз и эустома, 45 см
Цветы в коробке на свидание — розы 40 см, 25×25
```

Правила названия:
1. Первые 3–4 слова — самое важное: тип товара и ключевой цветок.
2. Повод пишем для кого: «маме», «на свидание», «коллеге».
3. Никаких «недорого», «шикарный», «элитный», «★», КАПСА.
4. Не указывать чужой праздник — это стоп-слово для подборки (например, «8 Марта» в карточке под День матери).

## Структура описания (400–700 знаков)

```
1. Первая строка-крючок: что человек получит и по какому поводу.
2. Состав поштучно, с размерами стеблей.
3. Размер с упаковкой (Ш×В), вес.
4. Что входит дополнительно: открытка, памятка по уходу, фото до отправки.
5. Как и когда доставляем: по городу, день в день, самовывоз (адрес и часы).
6. Один призыв.
```

Чего не делаем: не обещаем «гарантию 7 дней», не пишем «всё расскажем в чате», не вставляем телефоны, ссылки, QR.

## Приёмы, которые повышают заказ

- **Повод в первой строке**, а не в конце.
- **Момент вручения**: «приоткрыла коробку — и весь офис обернулся».
- **Снятие страха**: фото до отправки, замена при получении, состав поштучно.
- **Ясность по доставке**: сколько стоит и когда привезут.
- **Одна мысль — один абзац по 2 строки**: на телефоне длинные абзацы не читают.

## Упражнения для тренировки (делать по одному в день)

1. Переписать 3 названия конкурентов по формуле «что + для кого + состав + размер».
2. Взять свой готовый букет и написать 5 крючков-первых строк, выбрать один.
3. Сократить описание до 400 знаков, сохранив состав, размер, доставку и призыв.
4. Описать один букет для трёх аудиторий: маме, на свидание, в офис.
5. Найти все стоп-слова в своей карточке и убрать.
6. Взять отзыв клиента и превратить его фразу в первую строку описания.

## Чек-лист перед сдачей текста

- [ ] повод и получатель в первой строке;
- [ ] состав поштучно, с размерами;
- [ ] размер и вес;
- [ ] доставка: срок и стоимость;
- [ ] один призыв;
- [ ] нет стоп-слов других праздников;
- [ ] нет телефонов, ссылок, обещаний без подтверждения;
- [ ] проверено на телефоне: первые 3 строки читаются.
