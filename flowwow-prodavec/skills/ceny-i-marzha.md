# Цены и маржа

## Как считать

```bash
node ../flowwow-vitrina/tools/flowwow-calc.mjs 3850            # пакет «Полный»
node ../flowwow-vitrina/tools/flowwow-calc.mjs 3850 --half     # «Половинка»
node ../flowwow-vitrina/tools/flowwow-calc.mjs 3850 --self     # своя доставка
node ../flowwow-vitrina/tools/flowwow-calc.mjs 3850 --cost=2100
```

## Ориентиры (СПб, цветы)

| Цена | Выплата («Полный») | Маржа при себестоимости 55% |
|---|---|---|
| 2 500 ₽ | 1 522 ₽ | −147 ₽ (убыток) |
| 3 000 ₽ | 1 894 ₽ | 244 ₽ |
| 3 850 ₽ | 2 525 ₽ | 408 ₽ |
| 5 000 ₽ | 3 380 ₽ | 630 ₽ |

**Порог: 3 000 ₽.** Ниже — не публикуем.

## Правила по ценам

- Цену меняем только с «да» владельца.
- Скидки ниже себестоимости не ставим никогда.
- Скидка допустима, если цена со скидкой остаётся выше порога и маржа положительная — считать калькулятором до публикации.
- Сравниваем с рынком: топ-карточки СПб 2 325–4 500 ₽.

## Что записывать

После каждой смены цены: дата, было → стало, причина, расчёт маржи.
