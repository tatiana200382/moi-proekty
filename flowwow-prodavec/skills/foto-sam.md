# Фото для Flowwow: делаю сам

Навык Марка. Свой пайплайн, Вова не нужен.

## Требования площадки

| Параметр | Значение |
|---|---|
| Пропорции | **1:1** |
| Размер | **1200×1200** (минимум), лучше 1500×1500 |
| Количество | до **6** на карточку |
| Формат | JPEG/PNG, до 10 МБ |
| **Запрещено** | водяные знаки, логотипы, рамки, контакты, QR, коллажи |
| Инфографика | не больше **15%** площади, нейтральные цвета |

## Порядок обработки

1. **Выбор кадра:** короткая сторона исходника ≥ 1200 px; сжатые копии из мессенджеров не берём.
2. Баланс белого по серой карте или по нейтральному фону.
3. Экспозиция: белые лепестки не пересвечены, детали в светах сохранены.
4. Света/тени: тени не чёрные, света не белые пятна.
5. HSL: зелень −20…−40 по насыщенности, чтобы не «кислотная».
6. Резкость 40–60, без гало.
7. Кадрирование в **1:1** по букету, головки не обрезать, упаковка видна.
8. Фон: светлый и ровный; если фон грязный — размыть или заменить на нейтральный.
9. Экспорт: sRGB, JPEG 85–90.
10. **Водяной знак не ставим** — на Flowwow за это отклоняют.

## Набор кадров на карточку (6 штук)

1. Букет целиком на нейтральном фоне.
2. Крупный план цветов (текстура).
3. В руках — масштаб.
4. Упаковка/лента.
5. Деталь: открытка, бирка, состав.
6. В интерьере или у окна — «как в жизни».

## Инструменты

- Pillow: кроп, цвет, резкость, размер.
- HTML-рендер (`../ii-marketolog/tools/render.sh`) — если нужна инфографика ≤15%.
- Проверка результата: открыть файл и посмотреть на телефоне.

## Чек-лист

- [ ] 1:1, ≥1200×1200;
- [ ] нет водяного знака, логотипа, рамки, текста с контактами;
- [ ] букет целиком, головки не обрезаны;
- [ ] белое не пересвечено, зелень не кислотная;
- [ ] 6 разных кадров, без повторов;
- [ ] сохранено в `results/foto/` с датой и названием карточки.
