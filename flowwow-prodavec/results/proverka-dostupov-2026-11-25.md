## Почему кабинет не открывался

| Проверка | Результат |
|---|---|
| `ping` API | `{"say":"hello"}` |
| Внешний IPv4 (`curl -4 ifconfig.me`) | 188.242.157.159 — совпадает с IP в отчёте «Forbidden» |
| `curl` с обычным User-Agent на публичную страницу магазина | HTTP 200 — IP не в блоке |
| Командная строка Chrome (`chrome://version`) | `--headless=new`, User-Agent `HeadlessChrome/158` |
| После перезапуска без `--headless=new` | публичная страница открылась, кабинет открылся |

Вывод подтверждён: блокировала защита сайта из-за headless-браузера. Пункт 4 правила «как человек» (видимое окно, не headless) нарушался не по замыслу, а из-за способа запуска Chrome.

## Что осталось проверить
