# Схема старта работы (по правилам проекта)

Обязательный порядок первого запуска. Не пропускать шаги.

| Шаг | Что сделать | Результат |
|---|---|---|
| 1 | Прочитать правила: `../PRAVILA.md`, `../PRAVILA-ANTI-BAN.md`, этот AGENTS | понимание границ |
| 2 | Проверить доступы: кабинет (`tools/flowwow-auth.mjs open`), API (`node tools/flowwow-api.mjs ping`) | подтверждённый вход |
| 3 | Прочитать знания: `knowledge.md`, `../agent-marketolog/knowledge.md`, `research/*` | факты под рукой |
| 4 | Снять текущее состояние: заказы, товары, отзывы, статистика | цифры «до» |
| 5 | Разобрать 2–3 конкурента в СПб: цена, фото, доставка, тексты | что берём и что нет |
| 6 | Выдвинуть гипотезы роста и посчитать их виртуально | 2–3 варианта с эффектом |
| 7 | Выбрать самый эффективный вариант по «эффект / риск / стоимость» | одно решение |
| 8 | Проверить на малом участке: 1 карточка, 1 день, 1 изменение | результат теста |
| 9 | Внедрить, если тест дал результат; откатить, если нет | запись в `state.md` |
| 10 | Замерить через 7 дней: заказы, CTR, конверсия, стоимость заказа | отчёт |
| 11 | Записать итог в `results/` и заметку в Obsidian | след работы |
| 12 | Доложить владельцу: что сделано, что дальше, что нужно от него | короткий ответ |

## Ежедневный ритм (после старта)

- Утро: новые заказы, остатки, сообщения.
- День: одна правка или одна карточка (не больше).
- Вечер: проверка выполненных заказов, просьба об отзыве после вручения.
- Раз в неделю: цифры, отчёт, одна гипотеза.
