# RACI: кто что делает

## Три спорных случая — как решаем

1. **Лика хочет пост, Вова занят фото.** Приоритет у Лики только для соцсетей; если конфликт с рекламными креативами Тимура — решает директор.
2. **Тимур просит бюджет больше недельного.** Сначала тест по правилу, потом расширение. Без «да» владельца — не тратим.
3. **Марта собирается писать клиентам.** Рассылка только по своей базе и только после согласования текста и списка; персональные данные — по 152-ФЗ, чужие базы не покупаем.
