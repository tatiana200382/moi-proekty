# Бриф на задачу

Без брифа задача не начинается. Бриф — 8 полей, заполняется за 3 минуты.

```md
## Бриф №____ от ____.____.2026

**Задача:** что нужно получить (одно предложение).
**Зачем:** какая метрика должна измениться и на сколько.
**Кому:** кому адресовано (клиент, владелец, партнёр).
**Где:** канал — ВК, Telegram, карты, Авито, Flowwow, сайт, почта.
**Вход:** какие данные и файлы уже есть (модель, цена, фото, цифры).
**Бюджет:** 0 ₽ / до ____ ₽ (тратит только владелец).
**Срок:** когда нужен результат.
**Готово, если:** критерий приёмки — что проверяет принимающий.
```

## Пример

```
Задача: пост «букет дня» на 14 февраля.
Зачем: 5 заявок из ВК за неделю.
Кому: клиенты 25–45, покупают подарок партнёру.
Где: ВК, затем Telegram (текст другой).
Вход: фото buket-31, цена 4 350 ₽, три адреса, часы.
Бюджет: 0 ₽ (органика) + 1 500 ₽ на продвижение — только после «да».
Срок: 10.02, 18:00.
Готово, если: цена и часы проверены, фото своё, есть призыв и метрика.
```

## Что делать, если бриф неполный

1. Назвать прямо, каких полей нет.
2. Задать **один** вопрос — самый важный.
3. Не начинать работу «на догадках»: лучшее, что можно сделать без входа, — черновик с пометкой «гипотеза».
