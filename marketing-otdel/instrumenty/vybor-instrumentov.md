# Выбор инструментов: как выбирали и что выбрали

Правило владельца — `../../PRAVILA.md`, раздел «Выбор инструментов»: сначала GitHub, 10–20 кандидатов, критерии, 2–3 лучших, запись вывода.

## 1. Задача

Вооружить девять ролей отдела так, чтобы инструменты:
- работали на нашем Mac **без Docker и без прав администратора**;
- решали конкретную задачу роли, а не «в целом полезны»;
- были живыми (коммит не старше 6 месяцев);
- не требовали платной подписки на старте;
- не нарушали правила данных.

## 2. Что рассматривали

Проверено по GitHub API **44 репозитория** (полная таблица — `katalog-github.md`), в том числе:
n8n, Dify, Flowise, Browser Use, MCP-серверы, Ollama, Open WebUI, CrewAI, Postiz, listmonk, Mautic, Twenty, EspoCRM, Chatwoot, erxes, Krayin, Plausible, Umami, Metabase, PostHog, Superset, Evidence, Matomo, SerpBear, Unlighthouse, Lighthouse, Google Ads API, Meta SDK, rembg, Upscayl, ComfyUI, InvokeAI, Penpot, ImageMagick, libvips, PhotoPrism, Remotion, FFmpeg, Marketing Skills, Botpress, Formbricks, Astro.

## 3. Критерии

| Критерий | Порог |
|---|---|
| Звёзды | от 1 000 (для узкой задачи — от 500) |
| Последний коммит | не старше 6 месяцев |
| Лицензия | открытая или разрешающая внутреннее использование |
| Установка | без Docker/прав администратора — для инструментов «сейчас» |
| Документация | есть быстрый старт и примеры |
| Зависимости | не тянет за собой сервер, БД и Java одновременно |
| Риск | нет парсинга чужих данных, накруток, бана аккаунтов |

### Что НЕ взяли

- **Flowise** — архив с августа 2026.
- **Dify, Open WebUI, Ollama, CrewAI** — мощно, но нужен сервер/GPU и время; вернёмся, когда появится задача, которую не решают скрипты.
- **PostHog, Superset, Matomo** — тяжёлые, избыточны для трёх магазинов.
- **PhotoPrism** — 85 фото нормально живут в папках.
- **Парсеры Авито** — нет лицензии и риск бана.
- **Upscayl, ComfyUI, InvokeAI** — генерация и апскейл пока не нужны: фото есть, качество достаточное.

## 5. Вывод

На старте отдел работает на **пяти вещах**: Marketing Skills (знания), n8n (автоматизация), Lighthouse/Unlighthouse (аудит), ImageMagick + rembg (фото), таблицы (учёт). Остальное — по мере появления данных и денег.

Правило пересмотра: раз в квартал директор проверяет, что реально используется. Инструмент, который не открывали 60 дней, выключается — «чтобы было» не считается.
