# Установка и выключение инструментов

Цель — ставить только то, что реально нужно, и уметь выключать без следов. Все команды проверены на нашем Mac (11.11.2026): Node.js 26, npm/npx есть, Java есть, Docker и Homebrew — нет.

**Урок 11.11.2026.** Отдельный venv на встроенном Python Harness не работает для пакетов с C-расширениями: Python подписан, а сторонние `.so` — нет, macOS их не загружает («different Team IDs»). Поэтому numpy, rembg и Pillow в venv падают. Рабочая схема: **Pillow — только из встроенного Python**, ffmpeg — статичный бинарник, остальное — стандартная библиотека. `~/.venv-marketing` удалён как нерабочий.

## Правила

1. Ставим в папку проекта или в домашнюю папку инструментов, не в системные каталоги.
2. Никаких `sudo` и прав администратора.
3. Токены — только в `~/.config/...`, не в проекте.
4. Каждая установка — строка в `stack-po-rolyam.md` (кто владелец, зачем).
5. Не понравилось — удалить в тот же день.

## Что ставится за вечер

### Lighthouse (аудит страницы)

```bash
npx --yes lighthouse https://example.ru --preset=desktop --view
```

Отчёт откроется в браузере. Владелец — Ян. Ничего не остаётся в системе: npx кеширует пакет и всё.

### Unlighthouse (аудит всего сайта)

```bash
npx --yes unlighthouse --site https://example.ru
```

Нужен Chrome; у нас он есть. Владелец — Ян.

### n8n (автоматизация)

```bash
npx --yes n8n
```

Открывается `http://localhost:5678`. Данные — SQLite в `~/.n8n`. Владелец — Тимур.

Важно: n8n под своей лицензией (Sustainable Use). Для внутреннего использования магазина бесплатен; продавать доступ нельзя. Перед коммерческим использованием — прочитать лицензию.

### rembg (вырезать фон у фото)

```bash
python3 -m venv ~/.venv-rembg
~/.venv-rembg/bin/pip install rembg pillow
~/.venv-rembg/bin/rembg i foto.jpg vyhod.png
```

Первый запуск скачивает модель (~180 МБ). Владелец — Вова.
Альтернатива без установки: системный Vision через Objective-C, уже использовали (`/tmp/cutout/cut.m`).

### ImageMagick

Готового менеджера пакетов нет — берём статичный бинарник с официального сайта и кладём в `~/bin`. Пока заменяем: **Pillow** (уже есть) и `sips`.

```bash
sips -Z 1600 foto.jpg --out foto-1600.jpg   # быстрое уменьшение
```

### FFmpeg

Статичный бинарник в `~/bin/ffmpeg`, `chmod +x`. Для видео и GIF. Пока не критично: Remotion и Chrome-headless закрывают карточки.

### Metabase (дашборд)

```bash
java -jar metabase.jar    # JAR скачать с metabase.com
```

Java есть. Нужен, когда накопятся данные за 4–6 недель. Владелец — Дана.

## Как выключить и удалить

| Что | Как |
|---|---|
| n8n | остановить процесс, удалить `~/.n8n` |
| rembg | удалить `~/.venv-rembg` |
| статичные бинарники | удалить файл из `~/bin` |
| npx-пакеты | `npm cache clean --force` (по желанию) |
| сервис | удалить его строку из `stack-po-rolyam.md` |

## Проверка после установки

1. Команда запускается без ошибок.
2. Есть скриншот или вывод, подтверждающий работу.
3. Строка в `stack-po-rolyam.md`: статус 🟡 → 🟢.
4. Если инструмент тянет данные — проверено, что токен вне репозитория.

Инструмент без проверки считается не установленным.
