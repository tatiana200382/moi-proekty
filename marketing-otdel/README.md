# Маркетинговый отдел Silver Song Flowers

Отдел из девяти ИИ-ролей под общим правилом: **заявки, а не посты**. Внутри — исследование рынка и кейсов, программа обучения, инструменты, процессы и папки сотрудников.

Создан 10.11.2026. Владелец — Татьяна, сеть из трёх цветочных магазинов в Санкт-Петербурге.

## Кто в отделе

1. **Директор по маркетингу** — план недели, приоритеты, приёмка (папка `../direktor-marketinga/`).
2. **Лика** — SMM и контент.
3. **Тимур** — платный трафик и тесты.
4. **Ян** — сайт, SEO и карточки на картах.
5. **Дана** — аналитика и отчёты.
6. **Марта** — CRM и удержание.
7. **Олег** — B2B и партнёрства.
8. **Вова** — производство контента и дизайн (`../agent-marketolog/`).
9. **Витрина Flowwow** — маркетплейс (`../flowwow-vitrina/`).

## Как это работает

```
Пн: Дана считает → директор планирует 3–5 действий → брифы ролям
Вт–Чт: работа и контроль тестов
Пт: цифры, журнал тестов, итог владельцу
```

Подробно — [`processy/nedelnyy-cikl.md`](processy/nedelnyy-cikl.md).

## Что уже готово

- Исследование рынка РФ и мира, разбор кейсов — `strategiya/`.
- Программа обучения: 7 модулей, экзамен, статус — `obuchenie/`.
- Каталог 44 инструментов с проверкой GitHub — `instrumenty/`.
- Процессы: недельный цикл, RACI, бриф, отчёт, метрики — `processy/`.
- Шесть новых сотрудников с паспортами и полномочиями — `sotrudniki/`.

## Чего не хватает для полной работы

1. **Цифры по каналам** за неделю: звонки, сообщения, заявки, продажи по точкам.
2. **Доступ к статистике** карточек Яндекс.Бизнеса и ВК (вход через Chrome).
3. **Токен Flowwow** или скриншоты кабинета для витрины.
4. **Решение по бюджету** на первый тест (до 5 000 ₽).
5. **Разрешение** на использование контактов клиентов для CRM.

Пока этого нет, отдел работает на гипотезах и помечает их как гипотезы.

## Главный принцип

Не «сделать много», а «сделать то, что можно проверить». Каждая неделя заканчивается цифрой, каждая цифра — источником.
