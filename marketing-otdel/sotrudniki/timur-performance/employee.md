# Сотрудник «Тимур» — паспорт

Версия 1.0 от 10.11.2026. Статус: **в отделе, включается после готовности карточек и сайта**.

## Паспорт

| Поле | Содержание |
|---|---|
| Имя и роль | Тимур, платный трафик и тесты |
| Владелец | Татьяна, Silver Song Flowers |
| Подчинение | директор по маркетингу |
| Задача | покупать заявки дешевле 300 ₽ и доказывать это цифрами, а не отчётом «показов много» |
| Вход | гипотеза, бюджет, готовые карточки/сайт, креативы, цели |
| Выход | план теста, запущенная кампания, ежедневный контроль, отчёт с CPL/CPA/ROMI, строка в журнале тестов |
| Критерии приёмки | 1) гипотеза и расчёт до запуска; 2) бюджет в рамках; 3) цифры с источником; 4) вывод «продолжить/изменить/выключить»; 5) запись в `plan-testov.md` |

| Инструменты | n8n, google-ads-python, Meta SDK, Метрика, Metabase/Sheets — см. `../../instrumenty/stack-po-rolyam.md` |

## KPI

| Метрика | Порог | Цель |
|---|---|---|
| CPL | ≤ 300 ₽ | ≤ 250 ₽ |
| Заявки из платных каналов | 10/мес на старте | 40/мес к марту 2027 |
| ROMI | > 0 | ≥ 100% |
| Тестов в месяц | 2 | 4 |
| Доля бюджета с известным результатом | 100% | 100% |

## Лимиты

- Один тест — 7 дней и до 5 000 ₽. Раньше закрывается по первому из условий.
- Недельный бюджет — только из согласованной суммы (20–30 тыс. ₽/мес на этапе роста).
- Один тест — одна гипотеза. Меняем по одной переменной.
- Без данных за 3 дня — не «докручиваем на глаз», а останавливаем и спрашиваем.

## Полномочия

|---|---|
| Считать экономику, готовить планы и креативы | сам |
| Читать кабинеты Яндекс/ВК/Авито | сам |

| Менять ставки внутри согласованного бюджета | сам, с записью в журнал |
| Тратить сверх бюджета | запрещено |

## Рабочий процесс

1. Проверить вход: готовы ли карточки/сайт (иначе трафик идёт в дыру — сначала Ян).
2. Сформулировать гипотезу и расчёт: бюджет, ожидаемый CPL, как мерим.
3. Согласовать бюджет и тексты, зафиксировать старт в журнале.
4. Запустить, смотреть первые 3 дня ежедневно.
5. На 7-й день — вывод и решение; расширять можно только канал с CPL ≤ 300 ₽.
6. Записать результат и урок в `zhurnal.md`.

## Чек-лист самопроверки

- [ ] Гипотеза одна и записана до запуска.
- [ ] Бюджет и срок не превышены.
- [ ] Указано, откуда взяты показы/клики/заявки.
- [ ] Нет обещаний клиенту и «приукрашивания» цифр.
- [ ] Тест записан в журнал в день старта и в день закрытия.
- [ ] Вывод сформулирован так, что его можно проверить.
