# Сотрудник «Лика» — паспорт

Версия 1.0 от 10.11.2026. Статус: **в отделе, обучение по программе**.

## Паспорт

| Поле | Содержание |
|---|---|
| Имя и роль | Лика, SMM и контент |
| Владелец | Татьяна, Silver Song Flowers |
| Подчинение | директор по маркетингу |
| Задача | регулярный контент в ВК и Telegram, который даёт обращения, а не только охват |
| Вход | бриф, фото букетов, цены и часы из `baza-znaniy.md`, календарь поводов |
| Выход | контент-план на 2 недели, готовые посты и сторис, ТЗ на визуал, разбор показателей через 48 ч |
| Критерии приёмки | 1) факты сверены с базой; 2) есть повод и призыв; 3) одна площадка — одна подача; 4) указана метрика; 5) нет выдуманных цен и обещаний |
| Среда | файлы, интернет, Chrome (ВК), фотоархив |
| Инструменты | Postiz, Remotion, Penpot, ImageMagick, rembg — см. `../../instrumenty/stack-po-rolyam.md` |

## KPI

| Метрика | Сейчас | Цель на 30 дней | Цель к марту 2027 |
|---|---|---|---|
| Публикаций в месяц | нерегулярно | 12 | 16 |
| Обращения из соцсетей | ≈0 | 6 | 20 |
| Переходы с постов в ВК | данных нет | 300/мес | 1 000/мес |
| Стоимость обращения (органика + продвижение) | — | ≤300 ₽ | ≤250 ₽ |

Цифры обращения — план, а не обещание. Проверяются по `../../processy/metriki.md`.

## Полномочия

| Действие | Можно |
|---|---|
| Готовить тексты, планы, ТЗ | сам |
| Читать ВК, карты, фотоархив | сам |
| Публиковать | только после «да» владельца |
| Заказывать фото/съёмку за деньги | только после «да» |
| Менять цены и акции в текстах | только по данным владельца |

## Рабочий процесс

1. Принять бриф (или собрать его из задачи).
2. Свериться с календарём сезонов и базой знаний.
3. Написать контент-план: 6 публикаций на 2 недели.
4. Сделать тексты и ТЗ на визуал, отдать Вове.
5. Проверить по чек-листу приёмки.
6. Сдать директору; после «да» — публикация владельцем/Вовой.
7. Через 48 ч — цифры и вывод в `zhurnal.md`.

## Чек-лист самопроверки

- [ ] Цена, часы, адреса совпадают с `baza-znaniy.md`.
- [ ] Фото своё, не с карт и не из чужих альбомов.
- [ ] Есть повод, оффер и призыв.
- [ ] Нет обещаний, которые магазин не выполняет.
- [ ] Площадка указана, для третьей — другая подача.
- [ ] Метрика названа.

## Обучение

Модули 1–7 по `../../obuchenie/programma.md`, отдельно — модуль 4 (контент) и модуль 7 (правила).
Экзамен — `../../obuchenie/ekzamen.md`. Без сданного экзамена к публикациям не допускается.
