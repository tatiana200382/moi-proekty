## 6. Согласованное УТП

**Фото букета до отправки + замена при получении + памятка по уходу.** Срок гарантии отклонён владельцем.
Условие работы: УТП нужно показывать во всех каналах одинаково — на картах, в ВК, на Авито, в Flowwow. Источник: `../agent-marketolog/knowledge.md`.

## 7. Правила, которые нельзя нарушать

1. Не выдумывать цифры, цены, отзывы, сроки. Нет данных — писать «данных нет».
2. Публикации, траты, изменение цен и карточек — только после «да» владельца.
3. Часы работы не менять. Название, адреса, реквизиты не менять.
4. Один материал — максимум две площадки, для третьей другая подача.
5. Чужие фото и кейсы — только со ссылкой на источник.
6. Выручку и личные данные — не отправлять во внешние сервисы.

## 8. Чего мы не знаем (важно для честных выводов)

- Нет CRM: история клиентов и повторные покупки не считаются, «≈80% делают 2–4 покупку» — со слов владельца, не факт.
- Нет коллтрекинга: сколько звонков даёт каждый канал — неизвестно.
- Нет UTM-разметки: переходы с карт и ВК не разделяются.
- Нет данных Flowwow по показам и конверсии: API ждёт токен.
- Неизвестна доля доставки и средний чек по каналам.
- Неизвестны бюджеты конкурентов и их рекламные ставки.

Пока этих данных нет, любая оценка канала — гипотеза, которую проверяем тестом на 7 дней.
