# Модуль 6. Инструменты и данные

**Цель:** выбрать инструмент по правилам, а не по первому впечатлению; не потерять данные и не слить секреты.

## 1. Как выбирать инструмент (правило владельца)

1. Искать в первую очередь **на GitHub** + официальная документация.
2. Собрать **10–20 кандидатов** (для мелкой задачи — минимум 5).
3. Сравнивать: звёзды, форки, **последний коммит** (не старше 6 месяцев), открытые issues, лицензия, документация, зависимости, безопасность, активность.
4. Отобрать 2–3 и объяснить, почему они лучше.
5. Не брать заброшенное, даже популярное.
6. Записать вывод: что рассматривали, что выбрали, почему.

Готовый разбор — `../instrumenty/katalog-github.md` и `../instrumenty/vybor-instrumentov.md`.

## 2. Что реально работает на нашем Mac

| Есть | Чего нет |
|---|---|
| Node.js 26, Python 3.9 (системный) и 3.12 с pandas/Pillow | Docker |
| Chrome под управлением (CDP, порт 9224) | Homebrew |
| Git, GitHub, SSH-ключ | CRM, коллтрекинг, сквозная аналитика |
| Бот MAX для заявок | API ВК, Авито-автозагрузка (нужна подписка) |

**Вывод:** не тащим сюда тяжёлые self-hosted платформы (n8n в Docker, Postiz с БД, Metabase на Java) «чтобы было». Сначала — скрипты, таблицы и родные кабинеты. Платформу ставим, когда она окупает время.

## 4. Безопасность данных

- Токены и куки — только в `~/.config/...`, никогда в папке проекта и в git.
- `.env` и `cookies.env` — в `.gitignore`.
- В сторонние сервисы не отправлять выручку, телефоны клиентов, переписку.
- Персональные данные — по 152-ФЗ: цель, согласие, срок хранения.
- API-ключи не вставлять в скриншоты и отчёты.

## 5. Проверка инструмента за 10 минут

1. Лицензия подходит для коммерческого использования?
2. Последний коммит — свежее 6 месяцев?
3. Есть ли установка без Docker и без прав администратора?
4. Можно ли выключить и удалить без последствий?
5. Что он делает с нашими данными?

Пять «да» — можно пробовать. Хотя бы одно «нет» — искать замену.

## 6. Практика

1. Взять один инструмент из `katalog-github.md` и проверить по пяти вопросам.
2. Написать, что он даёт отделу и сколько времени экономит в неделю.
3. Предложить, что выключить, если он не окупится.

**Сдать:** короткий разбор в `results/`.

## 7. Что запомнить

- Инструмент без процесса — игрушка.
- Сначала измерение, потом автоматизация.
- Секреты живут вне репозитория.
