# Режим эффективности отдела маркетинга (с 21.11.2026)

Отдел пересобран: меньше ролей, один процесс, обязательный результат каждую неделю. Причина — за месяц 41 файл отчётов, но **ноль публикаций и ноль заявок**.

## 1. Пять активных ролей вместо девяти

| Роль | Зона | Главная метрика | Папка |
|---|---|---|---|
| **Директор** | план, бюджет, приёмка, отчёт | заявки из онлайна, цена заявки | `direktor-marketinga/` |
| **Лика** | тексты постов, объявлений, сторис | сдано в срок, 0 правок | `sotrudniki/lika-smm/` |
| **Вова** | фото, публикация, Авито, карточки | опубликовано и проверено | `../agent-marketolog/` |
| **Ян** | карты, отзывы, сайт | звонки и маршруты с карточек | `sotrudniki/yan-seo/` |
| **Тимур** | платный трафик (после карточек) | цена заявки ≤ 300 ₽ | `sotrudniki/timur-performance/` |

**На паузе до появления данных:** Дана (аналитика — пока считает директор), Марта (CRM —нет базы), Олег (B2B — с января). Их папки остаются, задачи не ставятся.

**По вызову:** промо-стратег (идеи акций) и креативный директор (бриф и подача) — подключаются, когда директор ставит задачу на кампанию. В штатном недельном цикле их нет.

## 2. Один процесс

Главный процесс — `processy/nedelnyy-cikl.md`. `../direktor-marketinga/proces.md` объявлен справочным: он описывает роли, но не задаёт порядок.

Каждая задача идёт только так: **бриф → задача → материал → приёмка → публикация → замер**. Без брифа не начинается, без замера не закрывается.

## 3. Обязательный результат недели

Неделя считается рабочей, если сделано **всё три**:

1. **Опубликован минимум один материал** — пост, объявление или карточка.
2. **Запущен один замер** — кодовое слово, промокод или отдельная ссылка.
3. **Сдан отчёт с цифрой** — заявки, цена заявки, вывод: масштабировать / править / закрыть.

Нет публикации — нет недели. Внутренние документы и планы результатом не считаются.

## 4. Лимиты, чтобы не распыляться

- **3 задачи в неделю**, не больше. Четвёртая — только вместо одной из трёх.
- **Один канал в фокусе** на неделю. Остальные — поддержка.
- **Одна публикация в день** на канал.
- **Не больше 2 итераций правок** на материал: третья — возврат брифа.

## 5. Что запрещено

- Писать «в работе», «прорабатываем», «готовим концепцию» без даты и ответственного.
- Начинать новую роль, канал или идею, пока текущая неделя не закрыта.
- Отчёт без цифры в рублях или штуках заявок.
- Делать материалы «в стол»: без публикации и без замера.
