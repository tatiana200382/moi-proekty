# Что за сервер ai.m-tik.com и годится ли он для заявок

Дата: 24.11.2026.

## Проверка

| Проверка | Результат |
|---|---|
| IP, на который указывает `ai.m-tik.com` | `188.242.157.159` |
| Этот же IP у вашего домашнего интернета | **да** (совпадает) |
| Пинг с вашего Mac | **2 мс** — значит машина **в той же домашней сети** |
| SSH (порт 22) | открыт |
| Ollama API (11434) | открыт **в интернет без пароля** |

**Вывод: это не облачный сервер, а машина у вас дома** (мини-ПК, NAS или второй компьютер). Порты проброшены через роутер.

## Годится ли для переноса заявок

| Критерий | Оценка |
|---|---|
| Можно поставить наши скрипты (Linux, SSH) | **да** |
| Освободит Mac | **да** |
| Работает 24/7 при выключенном свете | **нет** — та же домашняя зависимость |
| Тот же IP, что у Mac → Авито не удивится | **плюс** |
| Безопасность | **плохо**: 11434 и 22 открыты наружу |

## Что это значит

**Если эта машина включена всегда** (мини-ПК с автозапуском, NAS) — на неё **можно** перенести опрос Авито, и Mac станет свободен. Но при отключении света или интернета заявки снова встанут.

**Настоящие 24/7** даёт только сервер в дата-центре.

## Что нужно, чтобы проверить точнее

1. **Что это за устройство** (мини-ПК, NAS, второй Mac) и включено ли оно круглосуточно.
2. **Доступ по SSH** (логин и пароль/ключ) — без него я туда не поставлю скрипты.
3. **Есть ли ИБП** (блок бесперебойного питания) — иначе свет выключает всё.

## Что сделать в любом случае

1. **Закрыть 11434 снаружи** — сейчас любой может пользоваться вашими моделями.
2. **Закрыть SSH для всех, кроме вас** (или оставить только по ключу).
3. Решить: домашняя машина (бесплатно, но зависит от света) или VPS (400–900 ₽/мес, круглосуточно).
