# Схема «Чат заявки» — как вы нарисовали

```
Трибуца 8 ─┐
Ленинский 56 ─┼─→ работники магазинов ─→ [ ЧАТ ЗАЯВКИ ] ←→ Авито
Белышева 5/6 ─┘                              ↕            ←→ ВК
                                             ↕            ←→ Яндекс
```

## Что это значит по шагам

1. Клиент пишет в **Авито / ВК / Яндекс**.
2. Заявка попадает в **один чат «Заявки»** — его видят сотрудники всех трёх точек.
3. Сотрудник отвечает **в том же чате**.
4. Ответ уходит обратно **в тот канал**, откуда пришёл клиент.
5. Ничего не теряется: вся переписка в одном месте.

## Что уже работает

| Канал | Заявка приходит в чат | Ответ уходит в канал | Статус |
|---|---|---|---|
| **Авито** | ✅ карточка с перепиской | ✅ скрипт отправляет в чат Авито | **работает** |
| **ВК** | ✅ сборщик читает диалоги | ⚠️ нужен токен сообщества или браузер | частично |
| **Яндекс** | ✅ заявка видна в кабинете | ❌ у Яндекса нет чата — только звонок | только уведомление |

## Чего не хватает для полной схемы

### 1. Отдельный чат «Заявки»

Сейчас карточки приходят в личный чат с Котиком. Чтобы сотрудники видели только заявки:

1. В Telegram создайте группу — например **«Заявки Silver Song»**.
2. Добавьте в неё **Котика** (бота).
3. Напишите мне — я переключу отправку карточек в группу.

### 2. Ответы в ВК

Два пути:
- **Токен сообщества ВК** (права на сообщения) — тогда бот отвечает сам. Нужно создать в настройках сообщества.
- **Через браузер** — как с Авито, медленнее и с риском.

### 3. Яндекс

У Яндекс.Бизнеса **нет чата**: заявка = телефон или почта. Вариант: присылать в чат карточку «позвонить клиенту» с номером и текстом заявки. Ответ — звонок, его в переписке не сохранить.

## Роли в схеме

| Кто | Что делает |
|---|---|
| **Сотрудник магазина** | видит заявку в чате, отвечает командой `#номер ответ: текст` |
| **Котик** | принимает команду, запускает отправку, подтверждает «отправлено» |
| **Я (система)** | собираю заявки из каналов, отправляю ответы, храню историю |

## Формат ответа для сотрудника

```
#u2i-xEx2zqdyoJnr8ewagY8RGA ответ: Здравствуйте! Подберу вариант до 3 500 ₽ с доставкой.
```

Номер — последняя строка карточки. После отправки Котик пишет «отправлено в Авито».
