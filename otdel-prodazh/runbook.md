# Runbook: как работает и что делать, если сломалось

Одна страница для владельца и для агента. Без неё «автономность» — это вера, а не система.

## Как устроено

```
Яндекс.Карты ─┐
ВК (группа) ──┼─ Chrome 9224 ─ collect.py ─ заявки (json)
Авито (нет) ──┘                              │
                                             ▼
                              sales_pipeline.py: A/B/C, дедлайн
                                             │
                        ┌────────────────────┴──────────────┐
                        ▼                                   ▼
                 MAX «Заявки»: карточки заявок              CSV + state.json
                        │                                   │
                        └──────── итоги 09:00/19:00, пятница 16:00
```

## Что где лежит

| Часть | Путь |
|---|---|
| Сбор заявок | `agent-marketolog/bot/collect.py` |
| Карточки и логика продаж | `otdel-prodazh/tools/sales_pipeline.py` |
| Цикл каждые 5 минут | `otdel-prodazh/tools/watch-sales.command` |
| Запуск/остановка | `start_autonomy.sh` / `stop_autonomy.sh` |
| Проверка | `healthcheck.sh` |
| Состояние | `otdel-prodazh/runtime/state.json` |
| Таблица | `otdel-prodazh/runtime/zayavki.csv` |
| Логи | `otdel-prodazh/runtime/logs/` |

## Расписание

| Когда | Что |
|---|---|
| каждые 5 минут | сбор + проверка + отправка карточек заявок |
| 09:00 | итог дня |
| 19:00 | итог дня |
| пятница 16:00 | итог недели |

## Команды

```bash
# запустить в фоне
./otdel-prodazh/tools/start_autonomy.sh

# проверить здоровье
./otdel-prodazh/tools/healthcheck.sh

# состояние заявок
python3 otdel-prodazh/tools/sales_pipeline.py --status

# посмотреть примеры карточек
python3 otdel-prodazh/tools/sales_pipeline.py --demo

# итог без отправки
python3 otdel-prodazh/tools/sales_pipeline.py --preview

# остановить
./otdel-prodazh/tools/stop_autonomy.sh
```

## Если сломалось

| Симптом | Причина | Что делать |
|---|---|---|
| В логе «Chrome CDP не отвечает» | Chrome закрыт или без порта 9224 | открыть Chrome с профилем `.chrome-profile`; проверить `curl 127.0.0.1:9224/json/version` |
| «Яндекс: не найдена таблица» | сессия Яндекса истекла | открыть кабинет в Chrome, войти заново |
| «ВКонтакте: 0 диалогов» | сессия ВК истекла или сообщения выключены | открыть `vk.ru/gim188108705`, проверить вход |
| MAX не отправляет | токен/чат/сеть | `python3 agent-marketolog/bot/max_client.py me`; проверить `~/.config/max-bot/token` |
| Карточки не появляются | цикл не запущен | `./otdel-prodazh/tools/healthcheck.sh`, затем `start_autonomy.sh` |
| Дубли карточек | сброшен state | проверить `runtime/state.json`; дубли удалить, ID не повторять |
| После перезагрузки тишина | не сработала автозагрузка | открыть `watch-sales.command` вручную; проверить Login Items |
| «Operation not permitted» у launchd | macOS не даёт фоновому процессу доступ к Рабочему столу | использовать `start_autonomy.sh` (через Терминал) — это штатный путь |

## Автозагрузка

Штатный способ — Login Item `watch-sales.command` (уже добавлен). При входе открывается Терминал и запускает цикл; окно можно свернуть, но не закрывать.

Продвинутый способ — launchd (`install_launchd_fda.sh`). Он требует **Full Disk Access** для `/bin/bash`, иначе macOS блокирует папку на Рабочем столе. Без этого не использовать.

## Данные и приватность

- Телефоны и адреса — только в `runtime/` и MAX; `runtime/` не попадает в GitHub (`.gitignore`).
- Клиентам автоматика не пишет.
- Логи не содержат полного текста переписки, только статусы и ошибки.
- При передаче файлов — обезличивать.

## Честные ограничения

1. **Автоответы клиентам — вручную.** Официального API ВК/Яндекса нет; автоматизация интерфейса рискует блокировкой.
2. **Звонки — вручную.** Пока нет переадресации.
3. **Авито выключен.** Нет объявлений магазина.
4. **Mac должен быть включён.** Спящий Mac не собирает заявки; после пробуждения цикл догоняет.
5. **Ошибки не прячутся.** Если сбор упал, в MAX придёт итог с нулями, а в логе — причина. Лучше ноль, чем выдумка.

## Что проверить раз в неделю

- 3 «ОК» в `healthcheck.sh`.
- 0 просроченных карточек.
- У всех потерь есть причина.
- В CSV нет дублей.
- Итог недели ушёл в MAX.
