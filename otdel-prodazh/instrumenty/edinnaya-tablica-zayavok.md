# Единая таблица заявок

Одно место, куда попадает **каждое** обращение: звонок, сообщение, заход в зал, заявка с карт. Пока таблица одна — её можно посчитать. Когда их три, считается только то, что удобно.

## Колонки

| Колонка | Тип | Обязательно | Пример |
|---|---|---|---|
| `id` | число | да | 1024 |
| `дата_времени` | дата-время | да | 11.11.2026 14:05 |
| `канал` | список | да | ВК |
| `точка` | список | да | Трибуца |
| `имя` | текст | да | Анна |
| `телефон` | текст | если есть | +7 … |
| `повод` | текст | да | годовщина |
| `бюджет` | число | если назван | 3000 |
| `дата_заказа` | дата | да | 12.11.2026 |
| `адрес` | текст | для доставки | ул. … |
| `статус` | список | да | заказ |
| `причина` | список | для отказа/потери | дорого |
| `сумма` | число | для заказа | 3200 |
| `допродажа` | число | если была | 300 |
| `кто_взял` | список | да | Ева |
| `следующий_шаг` | текст | да, если не закрыто | отправить фото |
| `когда` | дата-время | да, если не закрыто | 11.11.2026 16:00 |
| `комментарий` | текст | нет | просил до 15:00 |

## Списки значений

**Канал:** звонок · ВК · Telegram · WhatsApp · карты · сайт · зал · бот · сарафан.

**Статус:** новая · в работе · заказ · отказ · потеря · позже.

**Причина:** нет_ответа · поздно · дорого · нет_в_наличии · не_успели · выбрал_конкурента · передумал · не_дозвонились · неизвестно.

## Правила заполнения

1. Одна строка — одно обращение. Повторный заказ того же клиента — новая строка, тот же телефон.
2. Нет статуса — строку не закрывать.
3. `отказ` и `потеря` без причины — ошибка.
4. `в работе` без `следующий_шаг` и `когда` — ошибка.
5. Сумма — только подтверждённая оплата, не «примерно».
6. Дубли проверяются по телефону раз в день.

## Как завести (для новичка)

1. Открыть [sheets.new](https://sheets.new) — создастся пустая таблица.
2. Назвать «Заявки Silver Song Flowers, 2026».
3. В первую строку вставить заголовки из таблицы выше (или импортировать `zayavki-primer.csv`).
4. Выделить первую строку → «Вид» → «Закрепить» → «1 строка».
5. Для `канал`, `статус`, `причина` — «Данные» → «Настройка проверки данных» → «Список».
6. Включить фильтр: «Данные» → «Создать фильтр».
7. Поделиться: только с теми, кто работает с заявками; доступ «Редактор», не «Все, у кого есть ссылка».
8. Установить приложение Google Таблицы на телефон — чтобы заполнять в зале.
9. Раз в неделю — копия в CSV в папку проекта (бэкап).

## Что проверять каждый день

| Когда | Что |
|---|---|
| 09:30 | все ночные сообщения получили ответ |
| 13:00 | нет строк `новая` старше 30 минут |
| 18:00 | у всех `в работе` есть следующий шаг |
| 21:30 | итог дня: обращения, заказы, потери, причины |

## Приватность

Телефоны и адреса — персональные данные. Не публиковать таблицу, не давать доступ «по ссылке», не выгружать в сторонние сервисы. При передаче файла — обезличивать (без телефонов и адресов).
