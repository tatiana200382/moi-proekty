## Вывод

Сообщество создано как **сообщество-мессенджер** (`gim…`). У него админка в веб-версии не открывается по прямым ссылкам — нужен вход через приложение ВК или через «VK Бизнес».

Ключ доступа (токен) **нельзя создать без подтверждения по СМС** — это защита ВК, её обходить нельзя.

## Два пути

### Путь 1. Ключ вручную (2 минуты)

1. Открыть ВК **в приложении на телефоне** (не в браузере).
2. Сообщество → **Управление** → **Работа с API** → **Ключи доступа** → «Создать ключ».
3. Права: **«Сообщения сообщества»**.
4. Код из СМС → скопировать ключ → прислать.

Скрипт `vk-reply.py` уже готов: как только ключ появится, ответы из MAX пойдут в ВК.

### Путь 2. Без токена — через браузер

Отвечать в ВК так же, как в Авито: открывать диалог в вашем Chrome и вводить текст.
- Плюс: не нужен ключ.
- Минус: медленнее, зависит от вёрстки, риск ограничений ВК.

## Что сейчас работает без ВК

- Авито → MAX «Заявки» → ответ → Авито: **работает**.
- ВК → MAX «Заявки»: заявка приходит, ответ вручную.
- Яндекс → MAX «Заявки»: заявка приходит, ответ звонком.
