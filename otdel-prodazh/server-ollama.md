# Можно ли перенести на свой сервер с Ollama

Дата: 24.11.2026. Короткий ответ: **частично да**, но «перенести как есть» не получится.

## Что именно «модель»

Сейчас в работе две разные вещи:

| Часть | Что это | Переносится? |
|---|---|---|
| **Модель** (DeepSeek-V4.1-Flash и др.) | «мозг», который пишет текст | да — на Ollama ставится локальная модель |
| **Обвязка** (DeepSeek Harness) | инструменты: файлы, браузер, память, команды | нет — это отдельная программа |
| **Скрипты** (заявки, фото, Авито) | Python-код, работает локально | уже локально, ничего переносить не надо |

**Вывод:** Ollama заменяет только «мозг». Инструменты и логика остаются — их надо будет связать с Ollama.

## Что даёт Ollama

| Плюс | Минус |
|---|---|
| Данные клиентов **не уходят в облако** | качество моделей ниже облачных |
| Фиксированные расходы (свой сервер) | нужен GPU и обслуживание |
| Работает без интернета | скорость ответа ниже |
| Полный контроль | настройка и поддержка — на вас |

## Что нужно по железу (ориентиры)

| Модель | Память GPU | Что тянет |
|---|---|---|
| 7–8B (Qwen2.5, Llama 3.1) | 8–10 ГБ | короткие ответы, черновики |
| 14B (Qwen2.5-14B, DeepSeek-R1-14B) | 16–20 ГБ | тексты для карточек, ответы клиентам |
| 32B | 24–32 ГБ | сложные тексты, анализ |
| 70B | 2×48 ГБ | близко к облаку, дорого |

**Варианты:**
- **Mac Studio / Mac mini M4 Pro (64 ГБ)** — 250–400 тыс. ₽, тянет 32B;
- **аренда GPU** (RunPod, Vast.ai) — 1–3 $/час за A10/A100;
- **российские облака с GPU** — дороже, но оплата в рублях.

## Как это технически

1. Установить Ollama на сервер: `curl -fsSL https://ollama.com/install.sh | sh`
2. Скачать модель: `ollama pull qwen2.5:14b`
3. Проверить: `ollama run qwen2.5:14b "привет"`
4. API: `http://сервер:11434/api/chat` (или совместимый с OpenAI `/v1/chat/completions`)
5. В наших скриптах заменить вызов облачного API на этот адрес.

## Что можно перенести уже сейчас

| Задача | Годится ли локальная модель |
|---|---|
| Черновики ответов клиентам | **да** (14B хватает) |
| Тексты для Авито | да, с проверкой человеком |
| Разбор заявок, фильтр спама | **да** (это классификация, 7B хватает) |
| Обработка фото | нет — это не языковая модель |
| Публикация в Авито, браузер | нет — это скрипты, они и так локальные |
| Сложные стратегии, планы | лучше облако |

## Мой совет

**Гибрид:**

1. **Локально (Ollama)**: черновики ответов, фильтр спама, разбор заявок — данные клиентов не уходят наружу.
2. **Облако**: сложные тексты, стратегия, анализ — там качество выше.
3. **Скрипты** остаются как есть: они уже на вашем компьютере.

## Что нужно решить

1. **Зачем** переносить: приватность, независимость от подписок или экономия?
2. **Бюджет на железо**: 0 ₽ (уже есть Mac) или 300+ тыс. ₽ (сервер).
3. **Кто обслуживает** сервер: обновления, резервные копии, простой.

## Чего нельзя обещать

- Локальная модель **не будет** отвечать так же хорошо, как облачная: разница заметна на длинных текстах и сложных инструкциях.
- **Полного переноса «одной кнопкой»** нет: Ollama даёт модель, а не готового сотрудника.
- **Безопасность**: сервер с перепиской клиентов нужно защищать — это персональные данные.
