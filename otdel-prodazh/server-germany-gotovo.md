## Как включить VPN (весь трафик через Германию)

Конфиг готов: `~/.config/hetzner/wg-mac.conf`

1. Установить **WireGuard** из App Store (бесплатно);
2. «+» → «Импорт из файла» → выбрать `wg-mac.conf`;
3. Включить туннель — IP станет немецким.
