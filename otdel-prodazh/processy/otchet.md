# Отчёт отдела продаж

Отчёт — одна страница. Не «что делали», а «что получилось и что решаем». Пишется в пятницу, читается владельцем за 3 минуты.

## Шаблон

```
# Отчёт отдела продаж, неделя <даты>

## Цифры
| Показатель | Неделя | Прошлая | План |
|---|---|---|---|
| Обращения | | | |
| Заказы | | | |
| CR | | | |
| Средний чек | | | |
| Потери | | | |
| Доля потерь | | | |
| Возвращённые заказы | | | |
| Допродажи (₽) | | | |

Источники: таблица заявок, касса, Яндекс.Доставка. Где данных нет — «данных нет».

## Что сработало
1–3 пункта с цифрой.

## Что не сработало
1–3 пункта с причиной, без оправданий.

## Решения
- Продолжить:
- Изменить:
- Выключить:

## Что нужно от владельца
- «Да» на:
- Прайс/доступ:

## Следующая неделя
3–5 действий, у каждого метрика и срок.
```

## Правила

1. **Цифра без источника — не цифра.** Под таблицей — откуда взято.
2. **Плохая неделя — тоже результат.** Не подгонять и не прятать.
3. **Не больше 5 решений.** Иначе это не решения, а список желаний.
4. **Один вывод на канал.** «В ВК отвечали медленно, 4 потери» лучше, чем «работали с ВК».
5. **Следующая неделя начинается с цифры**, а не с «продолжаем работу».

- Копия владельцу — сообщением, 5–7 строк.
- Итог — в `~/AI-Memory-Lab/01_проекты/мой-проект/`.
