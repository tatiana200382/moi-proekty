# Карточка заявки: стандарт

**Заявка** — обращение клиента: звонок, сообщение, заказ с карт.
**Карточка заявки** — структурированная запись об этом обращении, которую отдел присылает владельцу в MAX. Одна заявка — одна карточка.
**Карточка A («готова»)** — по ней можно действовать без уточнений.
**Карточка B** — не хватает телефона, даты или деталей.
**Карточка C** — не заявка: тест, спам, нет контакта и заказа. Не отправляется.

## Три уровня

| Уровень | Когда | Что в карточке | Что делает владелец |
|---|---|---|---|
| **A — готова** | есть контакт и заказ/состав | клиент, телефон, состав, сумма, действие, дедлайн | звонит и подтверждает |
| **B — уточнить** | есть контакт, но нет деталей | клиент, контакт, чего не хватает, 2 вопроса | отвечает или поручает |
| **C — не заявка** | тест, спам, нет контакта и заказа | не отправляется | ничего |

## Обязательные поля

| Поле | Зачем |
|---|---|
| Клиент | имя или ник |
| Контакт | телефон или почта; без него карточка не A |
| Источник | Яндекс, ВК, Авито — чтобы считать каналы |
| Что нужно | состав, букет, вопрос |
| Сумма | если известна; иначе «не указана» |
| Дата/время | когда нужно; иначе в «чего не хватает» |
| Адрес | для доставки; иначе уточнить |
| Действие | одно конкретное: позвонить, подтвердить, предложить |
| Дедлайн | когда карточка должна быть закрыта |
| ID | чтобы отметить результат |

## Пример карточки A

```
🔥 КАРТОЧКА ЗАЯВКИ · готова · Яндекс.Карты
№ 1494024 · 03.11.2026 22:31
Клиент: Елена Братухина
Телефон: +7 911 164 95 99
Что нужно:
• Букет "Аромат" — 3 200 ₽
Сумма: 3 200 ₽
Действие: позвонить, подтвердить дату, время и адрес
Дедлайн: 11.11.2026 06:12
Черновик ответа: ...
ID: yandex:1494024
```

## Пример карточки B

```
🟡 КАРТОЧКА ЗАЯВКИ · уточнить · ВКонтакте
Клиент: Анна
Чего не хватает: телефон, бюджет, дата
Действие: задать 2 вопроса: повод/дата и бюджет
Дедлайн: 11.11.2026 10:12
ID: vk:...
```

## Критерии приёмки

- [ ] Контакт есть или явно указано, что его нет.
- [ ] Понятно, что человек хочет.
- [ ] Есть одно действие, а не список «разобраться».
- [ ] Дедлайн реален.
- [ ] Нет обещаний, которых отдел не выполнит.
- [ ] Персональные данные не ушли дальше чата владельца.

## Что происходит дальше

1. Владелец звонит/пишет и подтверждает.
2. Результат отмечается: `order`, `lost`, `in_work` — командой `--mark` или в таблице.
3. Если заказ — сумма и дата попадают в итог недели.
4. Если потеря — причина обязательна: дорого, нет в наличии, не успели, выбрал конкурента, передумал, не отвечает.

## Чего не бывает

- Карточки A без контакта.
- Карточки без действия.
- Карточки без дедлайна.
- Отправки клиенту без проверки человеком.
