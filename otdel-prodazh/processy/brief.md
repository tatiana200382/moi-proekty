# Бриф на задачу

Бриф — это не «сделай красиво», а ответ на семь вопросов. Без брифа задача возвращается автору, а не уходит в работу.

## Поля

| Поле | Что писать | Пример |
|---|---|---|
| Задача | одно действие | «Разобрать 11 сообщений ВК» |
| Зачем | какая метрика улучшится | «убрать потери, вернуть заказы» |
| Кому | сегмент/повод | «подарок, бюджет 2–5 тыс. ₽» |
| Канал | где | «ВК, личные сообщения» |
| Срок | дата и время | «11.11 до 18:00» |
| Бюджет | деньги, если есть | «0 ₽» |
| Метрика | чем измеряем | «11 ответов, 3 заказа, 0 непрочитанных» |
| Ограничения | что нельзя | «скидку не обещать, цены из прайса» |
| Приёмка | кто и когда | «директор, 12.11 в 10:00» |

## Шаблон

```
Задача:
Зачем:
Кому:
Канал:
Срок:
Бюджет:
Метрика:
Ограничения:
Приёмка:
```

## Пример заполненного

```
Задача: ответить на 11 непрочитанных сообщений ВК
Зачем: закрыть потери, вернуть хотя бы 3 заказа
Кому: люди, писавшие с 01.11 по 10.11
Канал: ВК, личные сообщения
Срок: 11.11 до 18:00
Бюджет: 0 ₽
Метрика: 11 ответов, 3 заказа, 0 непрочитанных
Ограничения: цены только из прайса, скидку не обещать, извиниться за задержку
Приёмка: директор, 12.11 в 10:00
```

## Что не бриф

- «Позвони клиентам» — кому, зачем, сколько, когда.
- «Подними чек» — на сколько и как.
- «Разберись с ВК» — что именно считается результатом.

## После брифа

1. Исполнитель делает черновик в своей папке `results/`.
2. Самопроверка по `employee.md`.
3. Приёмка: «принято» или «переделать» с причиной.
4. Строка в таблице и в `../zhurnal.md`.
