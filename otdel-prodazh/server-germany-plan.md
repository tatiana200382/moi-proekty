# Немецкий сервер: план для GPT, Клода и импортных сервисов

Дата: 25.11.2026. Авито и заявки не трогаем — ждём решения по нашему серверу.

## Что покупаем

**Hetzner Cloud, CX22**, локация Falkenstein (Германия) или Helsinki.

| Параметр | Значение |
|---|---|
| 2 ядра, 4 ГБ RAM, 40 ГБ SSD | хватает с запасом |
| Цена | **≈€4–5/мес** (≈450 ₽) |
| ОС | **Ubuntu 24.04** |
| IPv4 | включён |

## Что будет установлено

| Компонент | Зачем |
|---|---|
| **WireGuard VPN** | ваши устройства (Mac, iPhone) выходят в мир с немецкого IP |
| **SOCKS5 + HTTP прокси** | скрипты и браузер обращаются к импортным API |
| **LiteLLM** (шлюз моделей) | один адрес для GPT и Клода: удобно подключать к любому приложению |
| **Docker + compose** | сервисы в контейнерах, легко обновлять |
| **ufw + fail2ban** | наружу открыты только 22 (по ключу), 51820 (VPN), 443 |
| **Мониторинг** | проверка живости, автоперезапуск, логи |

## Архитектура

```
ваш Mac / iPhone
      │  WireGuard (шифрованный туннель)
      ▼
немецкий сервер ──► ChatGPT API
      │        ──► Claude API
      │        ──► импортные сайты
      └── прокси (для скриптов)
```

После подключения:

- **chatgpt.com и claude.ai открываются** без отдельного VPN;
- **API-ключи лежат на сервере**, а не в приложениях на Mac;
- при выключенном Mac сервер работает.
