# Сообщение администратору: доступ для туннеля (без прав администратора)

Дата: 25.11.2026. Владелец: Татьяна, Silver Song Flowers.

## Зачем

Заявки с Авито должны приходить в чат MAX круглосуточно, в том числе когда ноутбук выключен. Для этого нужен **российский IP**: из Германии Авито отвечает 429, а MAX API недоступен.

Наш сервер в Германии будет ходить в Авито и MAX через ваш российский хост `ai.m-tik.com`. Нужен **обычный пользователь с SSH и пересылкой портов** — **без sudo, без root, без доступа к файлам и базам**.

## Текст для администратора

---

Здравствуйте!

Нужна помощь с доступом, **без прав администратора**.

Задача: сервис уведомлений о заявках с Авито должен работать круглосуточно. Для этого наш сервер в Германии должен обращаться к Авито и MAX с российского IP — через `ai.m-tik.com` по SSH-туннелю.

Прошу создать **обычного пользователя без sudo**, например `tunnel`:

1. `useradd -m -s /usr/sbin/nologin tunnel` (или любой существующий пользователь без прав)
2. Добавить наш публичный ключ в `/home/tunnel/.ssh/authorized_keys`:
   ```
   ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIGB5b1zK0frEl6hxZHvTzbhgYNfK9PnD4K9xEZN73kpV ru-exit-from-hetzner
   ```
3. В `sshd_config` (или в файле для этого пользователя) разрешить:
   ```
   AllowTcpForwarding yes
   PermitOpen any
   ```
4. Сообщить порт SSH (если не 22).

Мы будем использовать только **динамическую пересылку портов** (аналог `ssh -D`): ни файлов, ни команд, ни базы — только сетевой туннель.

Если это неприемлемо — альтернатива: **прокси на этом хосте** (squid с логином и паролем), открытый **только** для нашего IP `2.31.104.44`.

## Что это даёт

| Что | Как |
|---|---|
| Авито | российский IP, без 429 |
| MAX | доступен |
| Права администратора | **не нужны** |
| Доступ к данным | **нет** — только сеть |

## Откат

```
usermod -L tunnel      # или userdel -r tunnel
```
