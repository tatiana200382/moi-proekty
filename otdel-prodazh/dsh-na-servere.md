# Второй DSH на немецком сервере

Дата: 25.11.2026. Состояние: **запущен и доступен снаружи**.

## Что сделано
| Компонент | Значение |
|---|---|
| Node.js на сервере | v22.23.5 |
| DSH (npm) | `@deepseek-ai/dsh@0.2.2-rc.5` |
| Служба | `dsh-web.service` (автозапуск, перезапуск при падении) |
| Внутренний адрес | `127.0.0.1:49999` |
| Nginx | порт **8443**, TLS (Let's Encrypt), basic auth |
| Домен | `2-31-104-44.sslip.io` (указывает на наш IP) |
| Рабочая папка на сервере | `/root/workspace` (копия проекта) |
| Swap | 2 ГБ (памяти на сервере 927 МБ) |

## Доступ (браузер)
```
https://2-31-104-44.sslip.io:8443/?token=<токен из журнала>
```
Логин basic auth: `silver` / пароль прокси.

Токен выдаётся при старте службы:
```
journalctl -u dsh-web -n 50 --no-pager | grep -o 'token=[A-Za-z0-9_-]*' | tail -1
```

## Ограничения
- Сервер: 1 CPU, 927 МБ RAM + 2 ГБ swap → медленнее Мака.
- Порт 443 занят Xray (туннель телефона) — поэтому DSH на 8443.
- Файлы на сервере — **копия**; синхронизация вручную (rsync/git).

## Откат
```
systemctl disable --now dsh-web
rm -f /etc/systemd/system/dsh-web.service
rm -f /etc/nginx/sites-enabled/dsh-server
nginx -t && systemctl reload nginx
```
