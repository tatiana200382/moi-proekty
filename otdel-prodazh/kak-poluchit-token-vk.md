# Токен ВКонтакте: что это и где взять

## Что значит «после токена»

Токен (ключ доступа) — это **пароль программы к вашему сообществу**. С ним бот может отправлять сообщения клиентам от имени магазина, не заходя в браузер.

Без токена: заявки из ВК в MAX приходят, но ответить из чата нельзя — только вручную в ВК.
С токеном: сотрудник пишет ответ в MAX → бот отправляет его клиенту в ВК.

## Где взять — 5 шагов

1. Откройте своё сообщество: **vk.ru/gim188108705** (Silver Song Flowers).
2. Слева или в шапке — **«Управление»**.
3. Раздел **«Работа с API»** → вкладка **«Ключи доступа»**.
4. Нажмите **«Создать ключ»**, отметьте права:
   - ✅ **Сообщения сообщества** (обязательно);
   - ✅ Управление сообществом (по желанию).
5. Подтвердите по коду из СМС и **скопируйте ключ** — он показывается один раз.

## Куда положить

Сохраните двумя файлами:

```
~/.config/vk-bot/token      ← сам ключ (одна строка)
~/.config/vk-bot/group_id   ← число 188108705
```

Или просто пришлите ключ мне — я сохраню сам.

## Что проверить до этого

В настройках сообщества → **«Сообщения»** должно быть включено **«Сообщения сообщества»**. Иначе API вернёт ошибку «messages disabled».

## Безопасность

- Токен = полный доступ к сообщениям. Не публикуйте его и не пересылайте в чатах.
- Если ключ утёк — в том же разделе «Ключи доступа» его можно **отозвать** и создать новый.

## После подключения

Схема станет одинаковой для двух каналов:

```
Авито → MAX «Заявки» → ответ сотрудника → уходит в Авито
ВК    → MAX «Заявки» → ответ сотрудника → уходит в ВК
Яндекс → MAX «Заявки» → звонок клиенту (чата нет)
```
