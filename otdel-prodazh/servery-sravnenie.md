# Сравнение серверов: что подходит нам

Дата: 24.11.2026. Задача: круглосуточные заявки (Авито, ВК → MAX), работа с импортными сервисами (GPT, API), возможность перенести модели.

## Главное противоречие

| Что нужно | Где требуется |
|---|---|
| **Авито, ВК, MAX** | **российский IP** — с зарубежного блокируют |
| **OpenAI (ChatGPT), импортные API** | **зарубежный IP** — из РФ не пускают |
| **Данные клиентов** (имена, телефоны) | **Россия** — по 152-ФЗ |

**Один сервер это не решает.** Нужны либо два сервера, либо российский сервер + зарубежный шлюз.

## Три архитектуры

### Вариант A. Два сервера — правильно и надёжно

```
Российский VPS (Timeweb)     →  Авито, ВК, MAX, данные клиентов
Зарубежный VPS (Hetzner)     →  GPT, импортные API, VPN-шлюз
```

**Цена:** 500 ₽ + 450 ₽ ≈ **950–1100 ₽/мес**.
**Плюсы:** каждый сервис видит «правильный» IP, данные клиентов в РФ, отказ одного не ломает второй.
**Минусы:** две машины обслуживать.

### Вариант B. Один российский + VPN-сервис

```
Российский VPS (Timeweb) → Авито, ВК, MAX, данные
                        → GPT через VPN/прокси
```

**Цена:** 500 ₽ + 200–400 ₽ (VPN) ≈ **700–900 ₽/мес**.
**Плюсы:** дешевле, одна машина.
**Минусы:** OpenAI может блокировать прокси; настройка хрупкая.

### Вариант C. Один зарубежный — не подходит

Авито с зарубежного IP **блокирует** кабинет и показывает «проблемы с IP». Отпадает.

**Кому подходит:** важна максимальная надёжность и возможен рост до своих моделей (GPU у Selectel).

## Что нельзя перенести «туда»

| Что | Почему |
|---|---|
| **ChatGPT (сам сервис)** | это облако OpenAI, не переносится |
| **DeepSeek/моя модель** | можно только локальные модели на **GPU-сервере** (от 5–15 тыс ₽/мес) |
| **Инструменты агента** (файлы, браузер, скрипты) | переносятся — это обычные программы |

**Вывод:** «перенести GPT» = арендовать GPU и поставить локальную модель (будет слабее). «Перенести меня» = перенести скрипты и обвязку, что **уже подготовлено** (архив 11 МБ).

## Что рекомендую

**Вариант 1: Timeweb Cloud + Hetzner CX22, ≈950 ₽/мес.**

Причины:

1. **Авито не блокирует** — российский IP.

3. **Данные клиентов в РФ** — требование закона.
4. **Дешёво** — меньше 1000 ₽ в месяц.
5. **Готово к переносу** — архив и установщик уже есть.
