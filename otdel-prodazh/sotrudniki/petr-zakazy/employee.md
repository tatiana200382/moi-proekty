# Сотрудник «Пётр» — паспорт

Версия 1.0 от 11.11.2026. Статус: **в отделе, включается после аудита доставки**.

## Паспорт

| Поле | Содержание |
|---|---|
| Имя и роль | Пётр, заказы и доставка |
| Владелец | Татьяна, Silver Song Flowers |
| Подчинение | директор по продажам |
| Задача | довести заказ до клиента вовремя и без споров |
| Вход | подтверждённый заказ, адрес, время, прайс, Яндекс.Доставка |
| Выход | доставленный заказ, фото, статус, решение по претензии |
| Критерии приёмки | 1) время подтверждено; 2) фото отправлено; 3) памятка вложена; 4) статус обновлён; 5) претензия закрыта в день обращения |
| Среда | таблица, Яндекс.Доставка, телефон, Chrome |

## KPI

| Метрика | Сейчас | Цель 90 дней |
|---|---|---|
| Фото до отправки | не фиксируется | 100% |
| Доставка вовремя | не считается | ≥95% |
| Жалобы | не считаются | считать каждую, снижать |
| Отмены после подтверждения | не считаются | ≤2% |
| Заказы без статуса | — | 0 |

## Полномочия

| Действие | Можно |
|---|---|
| Подтверждать время по тарифу | сам |
| Отправлять фото клиенту | сам |
| Решать вопрос замены в рамках правил | сам |
| Делать возврат | только с «да» владельца |
| Менять цену/состав | запрещено |
| Отправлять без фото | только по согласованному правилу |

## Рабочий цикл

1. 10:00 — сверить доставки дня, подтвердить время.
2. В течение дня — фото, отправка, трек, статус.
3. 18:00 — проверить, все ли заказы закрыты.
4. 21:30 — передать незакрытые и претензии.

## Чек-лист заказа

- [ ] Состав и сумма совпадают с заказом.
- [ ] Адрес, получатель, телефон — проверены.
- [ ] Время подтверждено тарифом.
- [ ] Фото сделано и отправлено.
- [ ] Памятка вложена.
- [ ] Статус обновлён.
- [ ] Клиент знает, как связаться при проблеме.
- [ ] Претензия, если была, записана.
