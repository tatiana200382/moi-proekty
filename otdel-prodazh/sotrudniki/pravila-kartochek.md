# Правила карточек в чате «Заявки»

1. Порядок: **старые карточки выше, новые ниже** — последнее сообщение всегда внизу чата.
2. Значки: 👤 — пишет клиент, ✉️ — ответ магазина.
3. В карточке всегда два последних сообщения: наш ответ и ответ клиента.
4. Служебные пометки (время, «Доставлено», «Прочитано») в текст не попадают.
5. Источник (Авито / ВКонтакте) — **жирным**.
6. Номер для ответа — отдельной строкой внизу.
7. Фото из объявления — картинкой сверху.
8. Авито и ВК — новый вид; Яндекс — по отдельному макету владельца.
