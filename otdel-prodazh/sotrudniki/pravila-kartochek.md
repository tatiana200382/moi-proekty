# Правила карточек в чате «Заявки»

1. Порядок: **старые карточки выше, новые ниже** — последнее сообщение всегда внизу чата.
2. Кружочек: 🟢 — первая карточка; автоответ бота Авито кружок НЕ меняет. 🟡 — ответил наш сотрудник из чата «Заявки». ✅ — сделка.
3. Значки: 👤 — пишет клиент, ✉️ — ответ магазина.
4. В карточке всегда два последних сообщения: наш ответ и ответ клиента.
5. Служебные пометки (время, «Доставлено», «Прочитано») в текст не попадают.
6. Источник (Авито / ВКонтакте) — **жирным**.
7. Номер для ответа — отдельной строкой внизу.
8. Фото из объявления — картинкой сверху.
9. Авито и ВК — новый вид; Яндекс — по отдельному макету владельца.
