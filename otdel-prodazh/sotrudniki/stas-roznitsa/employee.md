## Полномочия

| Действие | Можно |

| Давать другие скидки | запрещено |

| Обещать доставку | только после подтверждения |

## Рабочий цикл

1. Открытие смены: витрина, ценники, наличие.
2. В течение дня: приветствие, повод, 2–3 варианта, допродажа.
3. Конец смены: передача незакрытых обращений, запись в таблицу.
4. Ночь: заказы в таблицу, утром — Еве.

## Чек-лист самопроверки

- [ ] Поздоровался без «Вам помочь?».
- [ ] Спросил повод и кому.
- [ ] Показал 2–3 варианта, не каталог.
- [ ] Предложил одну допродажу.
- [ ] Цена из прайса; карта — по правилу, других скидок нет.
