# Покупка серверов: Timeweb Cloud (СПб + Амстердам)

Дата: 24.11.2026. Решение: один провайдер, две локации, оплата рублями, админ не нужен.

## Почему так

| Нужно | Где решается |
|---|---|
| Авито, ВК, MAX (российский IP) | сервер **Санкт-Петербург** |
| GPT, импортные API (зарубежный IP) | сервер **Амстердам** |
| Данные клиентов по 152-ФЗ | только российский сервер |
| Оплата рублями, одна панель | Timeweb Cloud умеет обе локации |

**Итого:** ~500 ₽ (СПб) + ~700 ₽ (Амстердам) ≈ **1200 ₽/мес**.

## Что делает владелец (10–15 минут)

1. Зарегистрироваться на [timeweb.cloud](https://timeweb.cloud) (почта + телефон).
2. Пополнить баланс на **1500 ₽** (карта РФ, СБП).
3. Создать **сервер №1**:

| Параметр | Значение |
|---|---|
| Локация | **Санкт-Петербург** |
| ОС | **Ubuntu 24.04** (или 26.04, если есть) |
| Конфигурация | 2 ядра, 4 ГБ RAM, 40 ГБ SSD |
| Цена | ~500–700 ₽/мес |

4. Создать **сервер №2**:

| Параметр | Значение |
|---|---|
| Локация | **Амстердам** |
| ОС | **Ubuntu 24.04** |
| Конфигурация | 2 ядра, 4 ГБ RAM, 40 ГБ SSD |
| Цена | ~700–900 ₽/мес |

5. В разделе **«SSH-ключи»** добавить наш ключ (он ниже) — до создания серверов, тогда он подставится автоматически.
6. Прислать мне: **два IP-адреса** и **имя пользователя** (обычно `root`).

## Что будет работать после

```
Авито / ВК  ──►  сервер СПб  ──►  MAX (чат заявок)
                    │
                    └──►  Амстердам  ──►  GPT, импортные API
```

## Резерв на случай сбоя

- Mac остаётся **холодным резервом**: проверяет сторож, включается только если сервер молчит;
- код и доступы лежат в git — восстановление за 10 минут.

## Если Timeweb не подойдёт

Альтернатива: **Selectel** (РФ, надёжнее, дороже) + **Hetzner** (Германия, дешевле, оплата картой).

## Мой совет

**Берите Timeweb Cloud, обе локации там.** Причины:

1. **Одна панель** — не надо вести два кабинета;
2. **Оплата рублями** — без валютных карт и рисков;
3. **Российский IP для Авито** и **нидерландский для GPT** — оба требования закрыты;
4. **Наш SSH-ключ** — доступ только у нас, админ не нужен;
5. **1200 ₽/мес** — дешевле, чем потерянная ночная заявка.
