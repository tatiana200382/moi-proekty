# Единая переписка по всем каналам: что возможно

Дата: 23.11.2026. Запрос: все сообщения из Авито, Яндекс.Карт, MAX и Telegram — в одном чате; ответы уходят обратно в тот же канал.

## Что уже есть

| Канал | Чтение | Отправка | Статус |
|---|---|---|---|
| **MAX** | ✅ бот читает (`/updates`) | ✅ бот отправляет | работает: карточки заявок уходят в MAX |
| **Telegram** | ✅ через бота Котика | ✅ через бота Котика | бот занят Котиком: второй процесс не может читать те же сообщения |
| **Авито** | ✅ читаем через браузер (12 чатов видели) | ⚠️ только через браузерную автоматизацию | официального API нет; автоматическая отправка = риск блокировки |
| **Яндекс.Карты** | ✅ заявки видны в кабинете | ❌ чата нет | только ссылка в CRM, отвечать вручную |

## Что реально можно собрать

### Вариант A. «Единая лента + маршрутизация» (рекомендую)

1. Все заявки уже собираются в одну таблицу `runtime/zayavki.csv`.
2. В Telegram приходит карточка: канал, клиент, вопрос, черновик ответа.
3. Сотрудник отвечает **командой** в чате: `/otvet <номер> текст`.
4. Роутер отправляет ответ:
   - **MAX** — ботом автоматически;
   - **Telegram** — через Котика (тот же бот);
   - **Авито** — либо вручную (ссылка на чат), либо браузерной автоматизацией (риск);
   - **Яндекс** — ссылка «ответить в кабинете».
5. Все ответы пишутся в историю заявки — ничего не теряется.

**Что нужно:** новый токен бота для Telegram-приёма (создать у @BotFather за 2 минуты) — иначе будет конфликт с Котиком.

### Вариант B. Полный инбокс с интерфейсом

Нужен сервер (n8n / Chatwoot) и доступ к API Авито. Дороже, дольше, но красивее: единый экран, назначение ответственных, SLA.

**Условие:** подключить «Интеграцию по API» в Авито (раздел есть в кабинете) или партнёрский доступ. Без этого Авито остаётся полуручным.

## Чего нельзя обещать

- **Автоматическая отправка в Авито** через браузер — работает нестабильно и нарушает правила площадки. При блокировке теряем аккаунт с объявлениями.
- **Яндекс.Карты** — у них нет чата для продавца; заявка = телефон/почта, ответ вручную.
- **Полная синхронизация истории** между каналами — только то, что бот видел; прошлые сообщения не подтянутся.

## Что нужно от владельца

1. **Создать второго Telegram-бота** (или разрешить перенастроить Котика) — иначе приём сообщений конфликтует.
2. **Решить по Авито:** оставляем ручной ответ по ссылке (безопасно) или пробуем автоматизацию (риск).
3. **Сказать, кто отвечает:** вы, Ева или оба — от этого зависит маршрут и права.
4. **Подтвердить приоритет каналов:** MAX и Telegram — автоматически, Авито — вручную.

## Минимальный шаг, который можно сделать сегодня

1. Все карточки уже идут в MAX и Telegram.
2. Добавить в карточку **ссылку на чат Авито** (для ответа в один клик).
3. Добавить в карточку **ссылку на заявку в Яндекс.Бизнесе**.
4. Ответы, отправленные в MAX, сохранять в историю заявки.

Это даёт «одно место, где видно всё» без риска для Авито. Полная двусторонняя маршрутизация — следующий шаг, когда будет второй бот и решение по Авито.
