# Как сотрудникам подключиться к боту заявок

Дата: 24.11.2026.

## Главное

Бот **не живёт в телефоне владельца**. Он работает на серверах MAX — у него есть адрес, по которому его может открыть любой человек:

```
https://max.ru/id784803628181_bot
```

## Что сделать (одно действие)

Отправьте сотрудникам эту ссылку. Они:

1. открывают её **в MAX** (на телефоне или компьютере);
2. нажимают **«Написать»**;
3. пишут боту: `номер заявки, пробел, текст`.

Всё — бот получает сообщение и отправляет ответ клиенту.

## Что сотрудник увидит

| Сообщение | Что делать |
|---|---|
| «✅ Отправлено в Авито ✅» | клиент получил ответ |
| «⚠️ Не отправлено» | причина: нет доступа, неверный номер |

## Формат команды

```
u2i-ag_9dPqu7pxf2Q9YUPvjOA Здравствуйте! Забронировал букет на 28 ноября.
```

Номер — из карточки заявки в общем чате.

## Где смотреть заявки

В **общем чате «Заявки»** — там карточки с перепиской и номером.

## Важно про доступ

Сейчас бот принимает команды **от любого, кто нашёл ссылку**. Если нужно ограничить круг — скажите, добавлю список разрешённых сотрудников: бот будет отвечать только им, остальным напишет «нет доступа».

## Что сотруднику НЕ нужно

- регистрировать новый аккаунт MAX (достаточно своего);
- заходить в Авито или ВК;
- устанавливать что-то ещё.

## Проверка

Пусть сотрудник напишет тестовую строку с несуществующим номером:

```
test123456 проверка
```

Бот ответит «⚠️ Не отправлено» — значит связь есть и команда принимается.
