# Сбор базы контактов

Один запуск — и на выходе Excel-файл: все контакты с телефона и из Telegram, с ролями, ссылками, телефонами и оценкой полезности.

## Быстрый старт

1. Установите **Python 3.10+** с [python.org](https://www.python.org/downloads/). При установке отметьте **Add Python to PATH**.
2. Откройте `config.json` и заполните:
   - `telegram.chats` — названия рабочих чатов, откуда брать людей (можно оставить пустым);
   - `phone.adb_path` — полный путь к `adb.exe`, если ADB не в PATH.
3. Двойной клик по **`Собрать-базу.cmd`**.
4. Первый запуск спросит номер телефона и код из Telegram — один раз.
5. Готовый файл появится в папке `output/`.

Всё остальное скрипт делает сам: снимает контакты с телефона, выгружает Telegram, склеивает дубли, размечает роли и собирает Excel.

## Что нужно

| | Обязательно | Зачем |
|---|---|---|
| Windows | да | скрипт запуска и ADB |
| Python 3.10+ | да | на нём всё работает |
| Телефон Android | нет | контакты из телефонной книги |
| Аккаунт Telegram | нет | контакты и профили из Telegram |

Если телефона нет — уберите телефон из `config.json` (`"phone": {"enabled": false}`) и получите базу только из Telegram.

## Что получится

Файл `output/База_контактов.xlsx`, восемь листов:

- **Сводка** — сколько всего, сколько подрядчиков, где пробелы;
- **Подрядчики** — рабочий список: роль, телефон, Telegram, канал, сайт;
- **База** — все контакты с источниками;
- **Задачи** — кто нужен под каждую типовую задачу;
- **Пробелы** — где людей не хватает;
- **Роли** — распределение по профессиям;
- **Из чата** — люди, найденные в рабочих чатах, с контекстом;
- **Методика** — как считалось, чтобы можно было проверить.

## Если что-то пошло не так

Все сообщения об ошибках написаны по-русски и объясняют, что делать. Частые случаи разобраны в `ИНСТРУКЦИЯ.md`.

Скрипт можно запускать повторно: уже собранные данные не теряются, докачивается только новое.
