# Отчётность: только результат

Отдел отчитывается не действиями, а цифрами: сколько заявок, сколько заказов, сколько денег, сколько потеряли и почему. Всё остальное — процесс, он остаётся в логах.

## Итог дня (09:00 и 19:00, MAX)

```
📊 Отдел продаж · 11.11.2026, 19:00
Карточек к действию: 2 · ждут уточнения: 3 · просрочено: 0
Подтверждённых заказов: 1 · выручка: 3 200 ₽
Потерь: 1

Можно звонить:
• Елена · 3 200 ₽ · до 18:00
• Игорь · сумма не указана · до 19:30
```

Если новых нет:

```
📊 Отдел продаж · 11.11.2026, 09:00
Карточек к действию: 0 · ждут уточнения: 0 · просрочено: 0
Новых заявок нет. Отдел на связи.
```

## Итог недели (пятница, 16:00, MAX)

```
📈 Итог недели · 04.11–11.11.2026
Заявок: 12 · заказов: 5 · конверсия: 42%
Выручка: 14 500 ₽ · потерь: 3
Средний чек: 2 900 ₽
Причины потерь: дорого — 2, нет в наличии — 1

Следующий шаг: разобрать просрочки и закрыть причины потерь.
```

## Что считается результатом

| Показатель | Формула | Источник |
|---|---|---|
| Заявки | строки со статусом A/B за период | state.json |
| Заказы | статус `order` | отметка владельца/директора |
| Выручка | сумма заказов | поле `amount` |
| Средний чек | выручка ÷ заказы | расчёт |
| Конверсия | заказы ÷ заявки | расчёт |
| Потери | статус `lost` | отметка + причина |
| Просрочки | дедлайн прошёл, статус не закрыт | автоматически |
| Скорость карточки | время от появления до отправки | автоматически |

## Что не считается результатом

- «Ответили на сообщения».
- «Изучили 50 кейсов».
- «Настроили таблицу».
- «Провели встречу».
- «Отправили 100 карточек» — важно, что с ними стало.

## Где смотреть

| Что | Где |
|---|---|
| Карточки и итоги | чат MAX «Заявки» |
| Таблица | `otdel-prodazh/runtime/zayavki.csv` |
| Состояние | `python3 otdel-prodazh/tools/sales_pipeline.py --status` |
| Логи | `otdel-prodazh/runtime/logs/` |
| Итог в базу знаний | заметка в Obsidian, 5–7 строк |

## Как отметить результат

```bash
# заказ
python3 otdel-prodazh/tools/sales_pipeline.py --mark yandex:1494024 order --amount 3200

# потеря с причиной
python3 otdel-prodazh/tools/sales_pipeline.py --mark vk:abc lost --note "дорого"

# вернули в работу
python3 otdel-prodazh/tools/sales_pipeline.py --mark yandex:1494024 in_work
```

Без отметки отдел не знает, чем закончилась заявка, и не может отчитаться результатом.

## Правило отчёта

1. Сначала цифра, потом вывод.
2. Плохая неделя — тоже результат: не прятать и не «оптимизировать».
3. У каждой потери — причина.
4. Одно решение на отчёт, а не список желаний.
