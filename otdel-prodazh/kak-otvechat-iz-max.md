# Заявки Авито через Telegram

Котик (Аня) работает как единый вход для заявок: карточки приходят в Telegram, ответы уходят обратно в Авито.

## Что приходит

Карточка вида:

```
🟦 Новое сообщение · Авито
Объявление: Букет на День матери 29.11
Клиент: София
Текст: Подскажите, какие есть варианты до 3 500 ₽ с доставкой до Орджоникидзе 39?

Ответить: «#u2i-xEx2zqdyoJnr8ewagY8RGA ответ: ваш текст»
Номер заявки: u2i-xEx2zqdyoJnr8ewagY8RGA
```

## Как ответить

Владелец или сотрудник пишет в Telegram:

```
#u2i-xEx2zqdyoJnr8ewagY8RGA ответ: Здравствуйте! Подберу вариант до 3 500 ₽ с доставкой...
```

Котик выполняет:

```bash
python3 "/Users/tatiana/Desktop/Обучение ИИ/proekty/Мои проекты/otdel-prodazh/tools/avito-reply.py" <номер> "<текст>"
```

Скрипт открывает чат Авито в управляемом Chrome владельца, вводит текст и отправляет.

## Правила ответа

1. Цену букета не называть — она зависит от состава.
2. Доставка — **от 500 ₽**, точную сумму по адресу.
3. Один вопрос за сообщение.
4. Ответ ≤15 минут с 9:00 до 22:00.
5. Скидка 10% — только на слово «МАМА» и только на предзаказ.

## Проверка перед отправкой

- Убедиться, что номер заявки совпадает с чатом.
- Не отправлять текст, содержащий телефон, — он передаётся отдельным полем.
- Если Авито не отвечает, сказать владельцу: «Авито недоступен, ответ сохранён».

## Служебное

- Приём карточек: `otdel-prodazh/tools/avito-forward.py`.
- Отправка ответов: `otdel-prodazh/tools/avito-reply.py`.
- Состояние: `otdel-prodazh/runtime/avito-forward.json`.
