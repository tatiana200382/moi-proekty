# Модуль 4. Допродажи и сервис

**Цель:** поднять чек без навязывания и выполнить обещание так, чтобы клиент вернулся.

## 1. Допродажа

Один уместный вопрос после согласия на букет:

- «Открытку подпишем?»
- «Вазу под эти стебли подобрать?»
- «Шарик к букету добавить?»

Не список из пяти позиций. Не «возьмите ещё». Не после «нет».

Экономика: 1 100 заказов × 20% × 300 ₽ = 66 000 ₽/мес (пример, цену допродажи взять из прайса).

## 2. Путь заказа на доставку

```
Заказ → подтверждение времени → сборка → фото клиенту → «да» → Яндекс → доставлено → отзыв
```

| Шаг | Кто | Что нельзя пропустить |
|---|---|---|
| Подтверждение | Ника/Ева/Пётр | адрес, получатель, телефон, время |
| Сборка | флорист | состав по заказу, свежесть |
| Фото | Пётр/флорист | фото именно этого букета, при дневном свете |
| Отправка | Пётр | только после «да» или если клиент не отвечает — по правилу |
| Доставка | Яндекс | трек, время, замена при браке |
| Отзыв | Марта | просьба без накрутки |

Если клиент не отвечает на фото — не отправлять молча в спорном случае; позвонить. Правило согласовать с владельцем.

## 3. Претензия

1. Выслушать, не спорить.
2. Спросить фото и номер заказа.
3. Предложить замену или возврат — в рамках правил владельца.
4. Записать в таблицу: причина, решение, срок.
5. Вернуться с ответом в тот же день.

Обещание «замена при получении» — не реклама, а обязательство. Спор решает владелец, не сотрудник.

## 4. Что портит сервис

- «Привезём к 15:00» без проверки.
- Фото «похожего» букета вместо заказанного.
- Молчание после оплаты.
- «Это не мы, это курьер».
- Просьба «поставить пять звёзд» без решения проблемы.

## 5. Практика

1. Составить 5 допродаж к конкретным букетам из прайса (не выдумывать цены).
2. Пройти чек-лист заказа на доставку на трёх реальных заказах.
3. Разобрать одну претензию (реальную или учебную): что ответили бы.

**Сдать:** `results/praktika-4.md`.

## 6. Что запомнить

- Допродажа — один вопрос и только к месту.
- Фото до отправки — часть заказа, а не любезность.
- Претензия решается в день обращения.
