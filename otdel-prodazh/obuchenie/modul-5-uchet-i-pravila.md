# Модуль 5. Учёт, правила, этика

**Цель:** каждое обращение видно в цифрах, данные клиентов защищены, обещания не расходятся с правилами.

## 1. Одна таблица на всё

Все обращения — в одном месте: [`../instrumenty/edinnaya-tablica-zayavok.md`](../instrumenty/edinnaya-tablica-zayavok.md). Телефон, ВК, Telegram, WhatsApp, зал, бот — одна строка на обращение.

Минимальные поля:

`дата · канал · точка · имя · телефон · повод · бюджет · дата_заказа · статус · причина · сумма · допродажа · кто_взял · следующий_шаг · когда`

## 2. Статусы

| Статус | Значение |
|---|---|
| `новая` | обращение пришло, ответа ещё нет |
| `в работе` | идёт диалог |
| `заказ` | оплачен/подтверждён |
| `отказ` | человек отказался, причина записана |
| `потеря` | не ответили/не дожали, причина записана |
| `позже` | просил вернуться к дате |

Статус `в работе` без следующего шага и даты — ошибка.

## 3. Источник обращения

Обязательно: `звонок`, `ВК`, `Telegram`, `WhatsApp`, `карты`, `сайт`, `зал`, `бот`, `сарафан`.
Без источника нельзя понять, какой канал приносит деньги.

## 3а. Скидочная карта

| Вопрос | Ответ |
|---|---|
| Когда выдаём | при единовременной покупке от 5 000 ₽ |
| Что даёт | скидку на все следующие покупки, любой товар |
| На текущую покупку | не действует — карта на будущее |
| Процент | владелец не подтвердил — не называть |
| Учёт | отметка «карта выдана» в строке заказа |

Карта — правило, а не повод для торга. Другие скидки — только владелец.

## 4. Персональные данные

- Телефон и адрес — только для выполнения заказа.
- Не пересылать в сторонние сервисы, не публиковать, не покупать базы.
- Не хранить в открытых чатах и заметках.
- Удалить данные по просьбе клиента.
- 152-ФЗ: собираем минимум, используем по цели, не передаём третьим лицам без основания.

## 5. Честность

- Не записывать «заказ», пока нет оплаты/подтверждения.
- Не придумывать причину отказа — если неизвестна, писать `неизвестно` и разбирать.
- Не подгонять цифры под план. Плохая неделя — тоже результат.
- Не выдавать карту, если покупка меньше 5 000 ₽, и не обещать процент, которого не подтвердили.
- Не писать отзывы от лица клиентов и не просить «пять звёзд».

## 6. Приёмка

Перед сдачей проверь:

- [ ] У каждой строки есть статус и следующий шаг (или причина).
- [ ] Источник указан.
- [ ] Сумма совпадает с кассой/подтверждением.
- [ ] Обещания клиенту выполнимы.
- [ ] Нет лишних персональных данных.

## 7. Практика

Заполнить 10 строк таблицы по реальным обращениям за день: от звонка/сообщения до статуса. Ошибки разобрать с директором.

**Сдать:** `results/praktika-5.md` + заполненные строки в таблице.

## 8. Что запомнить

- Нет строки — не было обращения.
- Статус без причины — потеря.
- Данные клиента — не товар.
