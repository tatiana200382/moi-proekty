# Модуль 6. 50 цветочных бизнесов: разбор и зачёт

**Цель:** понимать, какие приёмы продаж работают в цветочном бизнесе, и уметь выбрать те, что подходят нашему магазину — без копирования всего подряд.

Обязателен **всем** ролям отдела. Без зачёта сотрудник не допускается к клиентам.

## 1. Что читаем

Основной файл — [`../strategiya/keysy-50-cvetochnyh-biznesov.md`](../strategiya/keysy-50-cvetochnyh-biznesov.md): 50 компаний, приём и источник. Читать не подряд, а так:

1. Пробежать таблицу и отметить 5 компаний, которые похожи на нас (розница, доставка, небольшой город).
2. Прочитать их приёмы и источник.
3. Выбрать 5 приёмов, которые реально можно запустить в своей роли.
4. Сверить с [`../strategiya/chto-primenyat-u-nas.md`](../strategiya/chto-primenyat-u-nas.md) — не дублировать.

## 2. Что должно остаться в голове

| Вывод | Доказательство |
|---|---|
| Возврат клиента важнее нового трафика | Lacy Bird: 40% повторных после напоминания о дате |
| Мессенджер — основной канал, а не «дополнительный» | Lacy Bird: Open Rate 86%, 2 млн ₽ с одной рассылки |
| Лояльность работает, если она простая | Lacy Bird: 41% в программе; сеть NDA: >50% |
| Фото до отправки — стандарт, а не бонус | French Florist: видео по QR; L'Flowers: фото как обещание |
| Комплект продаётся лучше «просто букета» | Teleflora, Prestige, Bunches |
| Свой клиент дешевле агрегаторного | French Florist: 95% клиентов из интернета; роялти франшизы 6% против 40% у агрегаторов |
| Подписка и B2B — после базы и сервиса | Bloom & Wild, H.Bloom, McQueens |

## 3. Что запомнить про цифры

- Все цифры в кейсах — **чужие результаты**, а не наш прогноз.
- Мы берём приём и проверяем его на своём потоке: 30 дней, метрика, стоп-условие.
- Если цифра из кейса не подтверждена источником — в отчёте писать «оценка».

## 4. Практика по ролям

| Роль | Задание |
|---|---|
| Директор | Выбрать 3 приёма из [`chto-primenyat-u-nas.md`](../strategiya/chto-primenyat-u-nas.md), назначить метрику и срок |
| Ника | 3 приёма для звонков: что сказать в первые 30 секунд, как закрыть, как напомнить о карте |
| Ева | 3 приёма для переписки: первое сообщение, напоминание о дате, возврат «подумаю» |
| Стас | 3 приёма для зала: комплект, карта, повторный визит |
| Лиза | 3 приёма для возврата: дата, прошлогодний заказ, «позже» |
| Пётр | 3 приёма для доставки: фото, видео, самовывоз |
| Инна | 3 метрики, которые докажут эффект: повторные, attach rate, доля самовывоза |

**Формат сдачи:** `results/keysy-5.md` — пять приёмов, по каждому: что делаем, метрика, стоимость, риск, первый шаг. Не больше одной страницы.

## 5. Самопроверка перед зачётом

- [ ] Могу назвать 5 приёмов и компании, где они работают.
- [ ] Понимаю, какие цифры чужие, а какие наши.
- [ ] Выбрал приёмы под свою роль, а не «все сразу».
- [ ] У каждого приёма есть метрика и первый шаг.
- [ ] Понимаю, что мы **не** копируем и почему.
