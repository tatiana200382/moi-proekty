# Зарубежный сервер: покупка и что на нём будет

Дата: 25.11.2026. Задача: доступ к GPT и импортным сервисам, круглосуточно, без зависимости от домашнего компьютера.

## Что покупаем

**Timeweb Cloud, локация Амстердам** — от **639 ₽/мес** (европейские серверы, оплата рублями).

| Параметр | Значение |
|---|---|
| Локация | **Амстердам** (или Франкфурт) |
| ОС | **Ubuntu 24.04** |
| Конфигурация | 1–2 ядра, **2–4 ГБ RAM**, 40 ГБ SSD |
| Цена | **639–900 ₽/мес** |
| Оплата | карта РФ, СБП |

Ссылка: [timeweb.cloud/services/servers-europe](https://timeweb.cloud/services/servers-europe)

## Что будет на сервере

| Компонент | Зачем |
|---|---|
| **WireGuard VPN** | ваши устройства выходят в мир с европейского IP |
| **HTTP/SOCKS-прокси** | скрипты обращаются к OpenAI и импортным API |
| **Docker** | запуск сервисов в контейнерах |
| **Наш агентский стек** | скрипты заявок, отчёты, обработка (по желанию) |
| **Мониторинг** | сторож, логи, автоперезапуск |

## Что делаете вы — 10–15 минут

1. Зарегистрироваться на [timeweb.cloud](https://timeweb.cloud).
2. Пополнить баланс на **1000 ₽**.
3. Создать сервер: **Амстердам**, Ubuntu 24.04, 2 ГБ, 639 ₽.
4. В разделе **SSH-ключи** добавить мой ключ (до создания сервера).
5. Прислать мне **IP** и логин (`root`).

## Проверка результата

| Проверка | Ожидание |
|---|---|
| `curl ipify` через сервер | нидерландский IP |
| Открытие chatgpt.com | работает без домашнего VPN |
| Прокси из скрипта | отвечает 200 |
| Перезагрузка сервера | всё поднимается само |

## Чего этот сервер НЕ решает

| Не решает | Почему |
|---|---|
| **Авито** | нужен российский IP — остаётся на Mac или на втором сервере (СПб) |
| **Перенос ChatGPT** | это сервис OpenAI, не переносится |
| **Свои модели** | нужен GPU-сервер (дороже) |

**Вывод:** это «окно в мир» для GPT и импортных сервисов. Авито и заявки остаются на российской стороне.

## План на две машины

```
Mac / сервер СПб  →  Авито, ВК, MAX (российский IP)
     │
     └─►  Амстердам  →  GPT, импортные API, VPN для устройств
```
