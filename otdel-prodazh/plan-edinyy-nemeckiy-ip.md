# План: один немецкий IP для всех приложений

Дата: 25.11.2026. Статус: **исследование, ничего не установлено**.

## 1. Задача

Весь трафик Mac (браузер + приложения: Telegram, ChatGPT, Claude) идёт через **наш сервер в Германии** (`2.31.104.44`), внешний IP — **один и тот же**. Авито и ВК требуют российский IP, поэтому нужен **выборочный** маршрут, а не «всё подряд».

## 2. Ограничения

| Ограничение | Следствие |
|---|---|
| macOS 26 | старые VPN-расширения не работают, TUN требует прав |
| Приложения не умеют прокси | нужен перехват на уровне системы (TUN) |
| Авито | нужен российский IP → исключения |
| Один IP | нельзя прыгать между серверами |
| Рабочий компьютер | любая ошибка = нет интернета |

## 3. Что уже проверено на практике

| Проверка | Результат |
|---|---|
| WireGuard-сервер на нашем сервере | ✅ работает (телефон подключается, трафик идёт) |
| Прокси squid на 3128 | ✅ работает (терминал получает `2.31.104.44`) |
| Приложения через системный прокси | ⚠️ подключаются, но нестабильно |
| Профиль IKEv2 на macOS 26 | ❌ служба не создаётся |
| Официальный WireGuard 1.0.16 | ❌ расширение падает |
| OpenVPN (Tunnelblick) | ⚠️ туннель есть, маршруты не применяются |
| Ручные маршруты | ❌ дважды ломали интернет |
| sing-box (WG через SOCKS, без TUN) | ⚠️ рукопожатие проходит, данные не идут — требует отладки MTU |

## 5. Шесть вариантов решения

### Вариант 1 — sing-box GUI + WireGuard к нашему серверу

| Плюс | Минус |
|---|---|
| Один клиент для всего, поддерживает WG | нужен профиль-конфиг |
| Умеет исключения (Авито — напрямую) | TUN требует одобрения расширения |
| Бесплатно | интерфейс на английском |

### Вариант 2 — Clash Verge Rev (mihomo) + WireGuard

| Плюс | Минус |
|---|---|
| Зрелый, много документации | helper просит пароль при установке |
| Гибкие правила (РФ-сайты — напрямую) | сложнее настройка |
| Бесплатно | TUN-режим чувствителен к правам |

### Вариант 3 — Viscosity (платный клиент)

| Плюс | Минус |
|---|---|
| Профессиональный, стабильный | платно |
| Работает на новых macOS | WireGuard — не основной протокол |
| Поддержка | лишняя зависимость от вендора |

### Вариант 4 — платный VPN со статичным немецким IP

| Плюс | Минус |
|---|---|
| Работает «из коробки», один IP | не наш сервер |
| Ничего не ломает | абонплата |
| Поддержка | IP принадлежит провайдеру |

### Вариант 5 — VPN на роутере

| Плюс | Минус |
|---|---|
| Все устройства сразу, без софта | нужен роутер с поддержкой |
| Mac вообще не трогаем | Авито тоже уйдёт в Германию |

### Вариант 6 — прокси + правила в браузере (без TUN)

| Плюс | Минус |
|---|---|
| Совсем безопасно | **приложения не покрыты** |
| Мгновенный откат | не решает задачу |

## 7. Выбор

**Основной:** вариант 1 (sing-box GUI с WireGuard к нашему серверу) — бесплатно, наш IP, гибкие исключения.
**Запасной:** вариант 4 — если с клиентом снова не выйдет, за 300–700 ₽ получаем стабильный немецкий IP без возни.

## 8. План проверки выбранного варианта (5–6 проверок)

| № | Что проверяем | Как | Критерий |
|---|---|---|---|
| 1 | Туннель без TUN | sing-box в режиме SOCKS, curl через него | IP = `2.31.104.44` |
| 2 | MTU | тот же тест с разными MTU | стабильные ответы |
| 3 | DNS | запрос через туннель | нет утечки к российскому DNS |
| 4 | TUN на Mac | включить, проверить IP в браузере | IP немецкий |
| 5 | Исключения | открыть Авито | российский IP, работает |
| 6 | Откат | выключить клиент | интернет сразу возвращается |

## 9. Правила безопасности

1. Никаких ручных маршрутов — только клиент.
2. Перед включением TUN — проверка туннеля (проверка 1).
3. Откат — одна кнопка в клиенте.
4. Авито и ВК — исключения.
5. Один IP: не переключать серверы.

## 10. Следующий шаг

Установить sing-box GUI, импортировать конфиг WireGuard (пир для Mac), пройти проверки 1–2 **без TUN**. Только после успеха — включать TUN.
