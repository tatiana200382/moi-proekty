## Найденная проблема

При установке «**только для меня**» Tunnelblick **не может менять маршруты** — для этого нужны права администратора. Поэтому VPN поднимается, но трафик идёт напрямую (IP остаётся российским).

## Решение — одна установка «для всех пользователей»

1. Меню Tunnelblick → **«Отключить все»**
2. Дважды щёлкнуть `silversong.ovpn` на Рабочем столе
3. Выбрать **«Все пользователи»** (вместо «Только я»)
4. Один раз ввести **пароль Мака**

После этого маршруты применятся, и IP станет `2.31.104.44`.
