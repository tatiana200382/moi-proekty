# Задание администратору сервера

Дата: 24.11.2026. Скопируйте текст ниже и отправьте администратору.

---

Здравствуйте! Нужно подготовить сервер `ai.m-tik.com` для круглосуточной работы скриптов приёма заявок (Авито → MAX). Прошу сделать пять пунктов.

**1. Добавить SSH-ключ для доступа**

Положите этот публичный ключ в `/home/<пользователь>/.ssh/authorized_keys`:

```
ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJIOz96gnR69ENELfS5YA72mweqbnWXe6GIbqiE9Zpyg silversong-server
```

И сообщите:

- имя пользователя для входа;
- порт SSH (если не 22);
- есть ли `sudo` у этого пользователя.

**2. Разрешить запуск наших скриптов**

Нужны пакеты: `python3`, `git`, `chromium` (или `chromium-browser`), `nodejs` 20+. Если удобнее — дайте `sudo`, мы поставим сами скриптом `bootstrap.sh`.

**3. Отключить сон сервера**

```
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

**4. Закрыть порт 11434 от интернета**

Сейчас Ollama доступна снаружи без пароля — любой может пользоваться моделями и грузить сервер. Просьба закрыть порт файрволом, оставив доступ только с localhost и из локальной сети.

**5. Сообщить, как устроен сервер**

- это физическая машина или VPS;
- какая ОС и версия;
- есть ли ИБП (бесперебойник);
- что будет с сервером при отключении электричества.

Заранее спасибо!

## Если администратор даст только FTP/панель файлов

Тогда минимум: положить папку с нашими скриптами и добавить в cron строку запуска каждые 15 минут. Скажите — подготовлю архив и текст для cron.

## Что делаем после ответа администратора

1. Подключаемся по SSH, проверяем систему.
2. Запускаем `bootstrap.sh` (ставит всё, отключает сон).
3. Переносим токен бота MAX и cookies Авито.
4. Включаем сторож `health-server.py` и расписание опроса.
5. Настраиваем резерв на Mac (`standby.sh`).
6. Проверяем: выключаем Mac — заявка приходит.
