# Перенос заявок на домашний сервер

Дата: 24.11.2026.

## Что освобождается

| Что | До | После |
|---|---|---|
| Mac | должен быть включён | **можно выключать** |
| Опрос Авито и ВК | на Mac | на сервере |
| Бот MAX | серверы MAX | серверы MAX (без изменений) |

## Что нужно сделать по шагам

1. **Доступ по SSH** к серверу (логин и пароль или ключ).
2. **Запустить `bootstrap.sh`** — поставит Python, Node, Chromium, git и клонирует репозиторий.
3. **Перенести файлы доступа**:
   - токен бота MAX,
   - `max-ca.pem`,
   - cookies Авито и ВК (сессия входа).
4. **Загрузить страницу Авито** на сервере в Chromium с этими cookies — проверить, что кабинет открылся без капчи.
5. **Включить службы**: опрос Авито/ВК и приём команд бота.
6. **Отключить автозапрет сна на Mac** — больше не нужен.

## Про сон сервера

На Linux сон отключается так:

```
sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
```

После этого сервер не засыпает. Скрипт `bootstrap.sh` делает это сам.

## Ограничения

| Ограничение | Что значит |
|---|---|
| Свет дома | выключили свет — заявки встали (нужен ИБП) |
| Интернет дома | пропал — то же самое |
| Cookies Авито | живут ограниченно; раз в 1–3 месяца нужно обновлять вход |
| Капча Авито | может появиться и на сервере — тогда вход обновляют вручную |
| Нет экрана | Chromium работает без экрана; смотреть можно через скриншоты |

## Что будет, когда Mac выключен

- заявки **приходят** в чат MAX (их отправляет сервер);
- **ответы** сотрудников идут через сервера MAX → сервер → Авито, Mac не участвует;
- **фото и обработка изображений** остаются на Mac (это тяжёлые задачи);
- **отчёты** по неделе — тоже на сервере, если перенести.

## Проверка после переноса

1. Выключить Mac.
2. Написать в Авито тестовое сообщение с другого аккаунта.
3. Убедиться, что карточка появилась в чате MAX.
4. Ответить командой бота — проверить, что клиент получил ответ.
