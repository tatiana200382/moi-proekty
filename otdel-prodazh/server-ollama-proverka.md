**Главное:** `size_vram = 0` — модели работают **на процессоре, без видеокарты**. Отсюда низкая скорость.

## Подходит ли

| Задача | Подходит? | Почему |
|---|---|---|
| Черновики ответов клиентам | **да** (8b) | 14 секунд терпимо, текст проверяет человек |
| Ответы клиентам в реальном времени | **нет** | клиент не будет ждать 15–80 секунд |
| Тексты для Авито | да, с правкой | качество 27b приличное |
| Фильтр спама, разбор заявок | **да** (8b) | короткие задачи |
| Анализ, стратегия | нет | слабее облака |
| Обработка фото | нет | это не языковая модель |

## Риски

1. **Порт 11434 открыт в интернет без пароля.** Любой, кто знает адрес, может гонять ваши модели и грузить сервер. Нужно закрыть порт и оставить доступ только через Open WebUI или VPN.
2. **Контекст 4096 токенов.** Для длинной переписки мало — половина диалога обрежется.
3. **Нет GPU.** 27b отвечает 78 секунд — для чата неприемлемо.
4. **Модели «qwen3.8»/«qwen3.6»** — нестандартные имена, качество неизвестно; лучше взять известные `qwen2.5:14b` или `gemma3:12b`.

## Что сделать, чтобы сервер подошёл

1. **Закрыть порт 11434** снаружи (файрвол), оставить локально + Open WebUI.
2. **Добавить GPU** или перейти на машину с 16–24 ГБ видеопамяти — тогда 14B будет ~40–60 ток/с.
3. **Поднять контекст** до 8–16k.
4. **Поставить нормальную модель** для русского: `qwen2.5:14b` или `gemma3:12b`.

## Вывод

Сервер **рабочий**, но сейчас это **черновой помощник**, а не замена облаку:

- **годится**: черновики, фильтры, разбор, тексты с проверкой;
- **не годится**: живые ответы клиентам, стратегия, длинные диалоги.

**Следующий шаг:** закрыть порт, поставить `qwen2.5:14b`, и подключить наши скрипты к `http://ai.m-tik.com:11434/api/chat` для черновиков.
