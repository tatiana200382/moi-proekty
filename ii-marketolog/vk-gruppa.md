## Как публиковать

**Сейчас — вручную (работает сразу).** Вы копируете текст из `results/post-vk-gotovyy.md` и прикладываете `results/cover-vk-brand.jpg`. Я готовлю материал и проверяю по чек-листу.

**Через API (нужна настройка, делается один раз).** Чтобы посты уходили без вас, нужно:
1. Создать приложение ВК типа Standalone на vk.com/apps?act=manage.
2. Получить токен с правами `wall`, `photos`, `offline` (и `groups` для статистики).
3. Положить токен в файл **вне папки проекта**, например `~/.config/vk/token`, с правами 600.
4. Дать команду — я настрою публикацию и покажу, как проверить на тестовом посте.

Токен в чат не выводится и в файлы проекта не попадает. Пока этого нет — публикую только через вас.

## Чек-лист публикации

1. Текст взят из `results/`, цена и адреса свежие.
2. Фото 1080×1350, в палитре бренда, без чужих кадров из интернета.
3. Хештеги: `#silversongflowers` + 2–3 по теме.
4. После публикации — записать дату и что опубликовано в `state.md`.
5. Через 7 дней — число обращений с пометкой «букет дня» и число подписчиков.

## План на две недели (черновик)

| Неделя | Публикации |
|---|---|
| 1 | «Букет дня» · состав букета с ценой · ответ на отзыв |
| 2 | уход за цветами (3 совета) · повод (свидание, день рождения) · закулисье: флорист за работой |

Три поста в неделю — из дорожной карты. Больше при 3–4 подписчиках смысла нет: сначала нужен трафик с карт.
