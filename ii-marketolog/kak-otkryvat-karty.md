# Как открывать карточки на картах

Владелец заходит так: Safari → вкладка с красной иконкой (Яндекс.Карты) «Белышева 5/6».
Мне кликать нельзя (macOS не даёт управлять браузером), поэтому открываю ту же карточку по прямой ссылке — результат одинаковый.

## Команда

```bash
open -a Safari "https://yandex.ru/maps/org/silver_song_flowers/138890152139/"
```

## Адреса карточек

| Точка | Ссылка |
|---|---|
| ул. Белышева, 5/6 | https://yandex.ru/maps/org/silver_song_flowers/138890152139/ |
| ул. Адмирала Трибуца, 8 | https://yandex.ru/maps/org/silver_song_flowers/107130274052/ |
| Ленинский проспект, 56 | ссылка не найдена — нужен адрес страницы от владельца |

## Как снимать данные с карточки

1. Открыть ссылку в Safari.
2. Сделать снимок экрана: `screencapture -x /tmp/screen.png` (разрешение на запись экрана уже дано).
3. Обрезать нужную область и прочитать: рейтинг, число оценок и отзывов, фото, часы, кнопки.

Снимок карточки Белышева от 2026-11-04: `materials/yandex-karta-belysheva-2026-11-04.jpg`.
