## Чего не хватает

1. **Аккаунт.** Нужен вход в GitHub с этого компьютера: логин и токен доступа (Personal Access Token) либо установленный GitHub CLI.
2. **Адрес репозитория.** Пустой репозиторий на github.com — публичный или приватный, решает владелец.
3. **Токен** хранится вне папки: в Keychain или в переменной окружения. В файлы проекта и в чат не попадает.

## Как подключить (одна минута)

```bash
cd "/Users/tatiana/Desktop/Обучение ИИ/Мои проекты"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

При запросе пароля GitHub просит не пароль, а токен. После первого успешного `git push` связка работает: агенты коммитят и отправляют изменения сами.

## Что делают агенты

- `git status` перед задачей, коммит после каждой, `git push` — когда удалённый репозиторий подключён.
- Секреты, куки и тяжёлые файлы не коммитятся: список в `AGENTS.md`.
