# 08. Стратегия размещения

1. Один товар — одно объявление. Дубль не обходится переписыванием текста.
2. Дробить по товару: 25/51/101 роза — разные товары; один букет под разными заголовками — дубль.
3. Оси дробления: тип (букет, монобукет, коробка, корзина), повод, размер/цена, сезон.
4. Товары — в Растениях; услуги (оформление, доставка, свадьбы) — отдельными объявлениями в Услугах, если это настоящая услуга.
5. Один город — один набор объявлений; три точки не размножают карточки.
6. A/B невозможен параллельно — только последовательно, 7–14 дней или от 100 просмотров.
7. Менять одну переменную за раз.
8. Метрики: просмотры → контакты → заказы. Ориентир из кейсов: «геройные» карточки 13–14% в контакт, остальные 4–6%.
9. Оценка: 40–80 активных объявлений на город, из них 10–15 «геройных».
10. Блокировки: дубли, несколько товаров в одном, подмена, контакты в тексте.

## Выводы

1. Считать разные товары, а не копии.
2. Тесты — последовательные и по одной переменной.
3. Цена контакта считается до масштабирования.
