# 01. PowerPoint: что полезного

| Инструмент | Что даёт | Нам |
|---|---|---|
| **Мастер-слайды и макеты** | один шаблон на все слайды, меняешь текст — вёрстка держится | прообраз наших HTML-шаблонов |
| **Дизайнер (Designer)** | предлагает варианты оформления по фото и тексту | идеи, не продакшн; нужен Microsoft 365 |
| **Morph** | плавный переход между слайдами | анимация сторис по кадрам |
| **Анимации и переходы** | появление, движение, тайминг | простые ролики |
| **Экспорт слайда в PNG/JPG** | 1080×1350 можно задать размером слайда | быстрый макет без Figma |
| **Экспорт в MP4** | слайды → видео, задаётся длительность | ролик 10–20 с из 3 кадров |
| **SmartArt, иконки, фигуры** | схемы, стрелки, плашки | инфографика для постов |
| **Заметки и докладчик** | сценарий выступления | презентации владельцу |
| **Цветовая схема темы** | палитра на весь файл | дисциплина цвета |

## Приёмы, которые стоит забрать

1. **Размер слайда = формат площадки.** 1080×1350 для поста, 1080×1920 для сторис.
2. **Один макет — много слайдов.** Меняешь только текст и фото.
3. **Morph** даёт движение без монтажной программы.
4. **Экспорт в MP4** — самый дешёвый способ сделать ролик из статики.

## Ограничения

- Дизайнер и часть библиотек — только с подпиской Microsoft 365.
- Цветокоррекции фото нет: только яркость/контраст/обрезка.
- Тяжёлый файл для простых карточек — HTML быстрее.
