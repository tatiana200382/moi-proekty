# 02. Canva: что полезного

Доступ: веб, у нас не открылась (таймаут). Изучено по публичным описаниям функций; часть — только в Pro.

| Инструмент | Что даёт | Тариф |
|---|---|---|
| **Brand Kit** | палитра, шрифты, логотип в одном месте; применяется в один клик | Pro |
| **Magic Resize** | пересборка макета под другой формат (пост → сторис → карточка) | Pro |
| **Background Remover** | удаление фона с фото | Pro |
| **Bulk Create** | генерация сотни карточек из CSV | Pro |
| **Brand Templates** | шаблоны с заблокированными полями: команда меняет только текст | Pro |
| **Content Planner** | календарь публикаций в соцсети | Pro |
| **Магия (Magic Studio)** | тексты, картинки, фоны по описанию | часть бесплатно |
| **Видеоредактор** | нарезка, музыка, субтитры, экспорт 1080p | бесплатно/Pro |
| **Фирменные шрифты и цвета** | единый стиль | Pro |

## Приёмы, которые стоит забрать

1. **Brand Kit** — один источник палитры и шрифтов; у нас это `standarty-vizuala.md` и CSS-переменные.
2. **Magic Resize** — из одного макета получать 4:5, 9:16 и 1:1 без ручной перевёрстки.
3. **Bulk Create** — таблица товаров → серия карточек.
4. **Brand Templates** — шаблон, где нельзя сломать вёрстку.
5. **Планировщик** — календарь публикаций; у нас это `10-processy.md`.

## Ограничения

- Почти всё ценное — в Pro (около 15 $/мес, цена меняется).
- Сайт в РФ работает нестабильно: нужен VPN, а с ним Авито недоступен — планировать по очереди.
- Фотообработки уровня Lightroom нет.
