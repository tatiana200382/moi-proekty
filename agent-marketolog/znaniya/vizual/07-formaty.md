# 07. Форматы площадок

| Формат | Размер | Где |
|---|---|---|
| Пост 4:5 | 1080×1350 | лента |
| Сторис 9:16 | 1080×1920 | истории, клипы |
| Квадрат | 1080×1080 | каталог, карточка товара |
| ВК-пост | от 510×510, прямоугольник 3:2 | ВК |
| Обложка сообщества ВК | 1920×768 | ВК |
| Аватар | 200×200 (загрузка от 400×400) | ВК |
| Товары ВК | 1000×1000 | ВК |
| Авито | от 1000 px по длинной стороне, 4:3 или 1:1 | Авито |

## Безопасные зоны 9:16

- Сверху 14% (269 px), снизу 35% (672 px), по бокам 6% (65 px).
- Текст и лого — в центральные 950×979.

## Правила

- ВК: без вотермарков сторонних приложений, музыка только из библиотеки.
- Клипы ВК: 3 с – 3 мин, лучше до минуты.
- Один файл во все сети — всегда компромисс: из 4:5 в 9:16 уходит ~30% ширины.

## Три вывода

1. Снимать сразу 4:5 и 9:16 с запасом по краям.
2. Единый визуальный код важнее количества постов.
3. Минимум две версии каждого материала.
