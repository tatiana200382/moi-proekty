# 03. Обработка фото

## Порядок действий

1. Импорт RAW, отбор (флаги, звёзды) — в работу 10–20% кадров.
2. Баланс белого по серой карте.
3. Экспозиция: белые лепестки ниже клиппинга, запас −0,3…−0,7 EV.
4. Света/тени: Highlights −30…−50, Shadows +20…+40.
5. Кривые: лёгкая S, чёрную точку не «в упор».
6. HSL: зелень Saturation −20…−40, Lightness −10; красный/оранжевый Lightness +5…+10.
7. Резкость: Amount 40–60, Radius 0,8–1,0, Masking 40–60.
8. Шум: Luminance 20–30, Chroma 25–40 при ISO 800+.
9. Кроп и горизонт.
10. Экспорт-пресет.

## Инструменты

| Задача | Инструмент |
|---|---|
| Основная обработка RAW | Lightroom Classic / Lightroom Mobile |
| Альтернатива | Capture One, darktable, RawTherapee |
| Ретушь | Photoshop, Affinity Photo |
| Быстро с телефона | Snapseed, VSCO |
| Пакетная обработка | ImageMagick, Pillow, sharp |

## Батч и консистентность

- Пресет + Sync Settings на всю серию.
- Один кроп, один экспорт-пресет.
- Не смешивать тёплые и холодные кадры в карусели.

## Экспорт

| Канал | Размер | Формат |
|---|---|---|
| Лента | 1080×1350 | sRGB, JPEG 80–85 |
| Сторис/клипы | 1080×1920 | sRGB |
| Сайт/каталог | 1600–2048 px | sRGB |
| Печать | 300 dpi | Adobe RGB/ProPhoto + soft proof |

## Ошибки

Пересвет белого, кислотная зелень, пластиковые лепестки от шумодава, HDR-ореол, разный баланс белого в серии, «залитая» текстура при ретуши.

## Три вывода

1. Для цветов важна точность: RAW, серая карта, контроль красного канала.
2. Серия продаёт лучше одиночного кадра.
3. Батч и экспорт-пресеты — главный резерв времени.
