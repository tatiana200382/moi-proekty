# 09. Пайплайн

## До съёмки

1. Референс-борд: 10–15 кадров, что берём (свет, фон, кроп).
2. Раскадровка — список кадров: витрина, букет в руках, макро, упаковка, интерьер, видео.
3. Один съёмочный день = 3–5 букетов, 6–8 кадров каждый.

## Съёмка

- ISO 100–400, f/2.8–f/5.6 для букета, f/8–f/11 для группы.
- RAW + JPEG, серая карта в первом кадре.
- 3–5 дублей, три ракурса, сразу вертикаль.

## Отбор и обработка

- Отбор в один проход, в работу 10–20%.
- Порядок: экспозиция → баланс белого → горизонт/кроп → ретушь → цвет.
- Резкость на экспорте.
- Экспорт: sRGB, JPEG 85–90.

## Видео

- 1080×1920, 25 fps, 1/50, ISO вручную, H.264, CRF 18–23.
- ffmpeg для вертикали:
  `ffmpeg -i in.mov -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2" -c:v libx264 -crf 21 -pix_fmt yuv420p -c:a aac -b:a 160k out.mp4`

## Пакетная обработка

- ImageMagick: `magick mogrify -resize "1600x1600>" -quality 88 *.jpg`
- Pillow: кроп под форматы (`ImageOps.fit`), водяной знак, плашка с ценой.
- ExifTool: пакетная запись автора и копирайта.

## Именование и хранение

- `2026-11-07_piony_04_1080x1350_v2.jpg`.
- Исходник `_orig` не трогать, версии только вверх.
- 3-2-1: три копии, два носителя, одна вне офиса.
- Каталог с ключевыми словами вместо папок.

## Чек-лист перед публикацией

- [ ] Резкость на 100%.
- [ ] Нет обрезанных листьев и голов.
- [ ] Цвет не кислотный.
- [ ] Нет цены, лиц и адресов без согласия.
- [ ] В EXIF нет адреса склада.
- [ ] Вес файла в лимите канала.

## Три вывода

1. Узкое место — отбор и хранение, а не съёмка.
2. Один исходник → много каналов.
3. Автоматизация — на повторяемом, творческое — руками.
