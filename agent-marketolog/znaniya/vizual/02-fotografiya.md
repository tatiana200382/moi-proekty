# 02. Фотография

## Экспозиция

- Три рычага: диафрагма, выдержка, ISO.
- f/1.8–f/2.8 — фон растворяется (одиночный букет); f/8–f/11 — резок весь букет и витрина.
- С рук — не длиннее 1/(2×фокусное); цветы шевелит сквозняк, для букета 1/160–1/250.
- ISO 100–200 на улице, 400–800 в зале; выше 1600 — шум.
- Белые лепестки — поправка −0,3…−0,7 EV.
- RAW обязателен (iPhone — ProRAW).

## Свет

- **Мягкий** (окно, софтбокс, рассеиватель) — пионы, пастель, свадебные букеты.
- **Жёсткий** (солнце, одна вспышка) — сухоцветы, графика, фактура.
- Окно: букет в 1–1,5 м от стекла, разворот 45°, фон в 1,5–2 м — иначе тень на фоне.
- Отражатель (пенокартон) с теневой стороны; флаг — уплотнить тень.
- Контровой свет: солнце за букетом, объектив прикрыть от блика.
- Смешанный свет (окно + лампы) — главный источник брака.

## Цвет

- Вспышка 5000–5500K, небо 5500–6500K, накаливание 2500–3500K, люминесцентные 4000–5000K + зелень.
- Серая карта 18% в первом кадре смены света — серия в одном цвете.

## Жанры и приёмы

- **Предметка:** 50–100 мм, f/8, ISO 100, штатив, один источник + отражатель.
- **Макро:** 60–100 мм макро, f/5.6–f/11, фокус по тычинкам; для бутона — стекинг.
- **Фон и реквизит:** 2–3 фактуры (лён, крафт, бетон), одна-две вещи в кадре.
- **Постановка:** не по центру (для ленты), ваза 1/3–1/2 высоты букета.
- **Телефон:** оптический 2×/3×, сетка, фиксация AE/AF, −0,3 EV, вспышка выключена.

## Витрина

Снимать в сумерки, когда внутри ярче улицы: штатив, 1/15–1/30, ISO 400–800, поляризатор, угол 30–45°.

## Три вывода

1. Свет важнее камеры.
2. Дисциплина серии (серая карта, пресет, партии по 10–15 кадров) дешевле техники.
3. Телефон закрывает большую часть задач при оптическом зуме и RAW.
