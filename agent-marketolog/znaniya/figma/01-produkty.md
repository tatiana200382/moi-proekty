# 01. Продукты Figma (2026)

| Продукт | Для чего | Нам полезен |
|---|---|---|
| **Figma Design** | макеты, прототипы | шаблоны поста 4:5, сторис 9:16, карточки товара |
| **Figma Buzz** (beta) | массовые брендовые материалы: баннеры, посты из одного шаблона | серии постов и карточек по одному макету |
| **Figma Slides** | презентации | отчёты владельцу, коммерческие предложения |
| **FigJam** | доска для схем и брейнштормов | план акций, разбор конкурентов |
| **Figma Draw** | векторные иллюстрации | иконки, рамки, декор |
| **Figma Motion** (new) | анимация макетов | простые анимации для сторис |
| **Figma Weave** | ИИ-процессы для изображений, видео, аудио | эксперименты, не продакшн |
| **Figma Make** | промпт → код | прототипы страниц |
| **Dev Mode** | передача в разработку | нам не нужен |

## Что важно

- Figma — облачная, нужен аккаунт и вход.
- Фотообработки в Figma нет: цвет, резкость, RAW — только Lightroom/Pillow.
- Видео в Figma не монтируется: только превью и анимация макетов.
