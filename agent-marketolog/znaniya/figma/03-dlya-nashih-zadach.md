# 03. Что делаем где

| Задача | Инструмент | Почему |
|---|---|---|
| Макет поста/сторис | Figma Design или наш HTML-шаблон | HTML уже работает без логина |
| Серия карточек по шаблону | Figma Buzz (если есть доступ) | массовое производство из одного макета |
| Обработка фото | Lightroom/Pillow | в Figma нет цветокоррекции и RAW |
| Водяной знак | Pillow | точный размер и место |
| Видео 15–30 с | CapCut/DaVinci + ffmpeg | Figma не монтирует |
| Презентация | Figma Slides | удобно собирать из макетов |
| Схема акции | FigJam | быстрый брейншторм |

## Ограничения

- Figma подключена через MCP только в Claude; в DeepSeek Harness доступа нет.
- Лимит MCP: 20 вызовов чтения в месяц, каждый записывать в `results/figma-limit.md`.
- Создание и изменение файлов — только после «да» владельца.

## Что предлагаю

1. Держать наш HTML-шаблон как основной: он бесплатный и автоматизируется.
2. Figma использовать, когда нужен сложный макет или презентация — через Claude.
3. Не переносить фото- и видеообработку в Figma: там этого нет.
