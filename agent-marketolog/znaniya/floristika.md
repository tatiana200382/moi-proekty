# Флористика: справочник Вовы

Рабочий конспект. Нужен, чтобы правильно называть вещи в объявлениях и постах и не путать монобукет с миксом.

## 1. Что это по типу

| Тип | Что это | Как писать |
|---|---|---|
| **Монобукет** | букет из цветов **одного вида** (только розы, только тюльпаны, только гортензия) | «монобукет из 15 роз», «монобукет из пионовидных роз» |
| **Миксбукет** (сборный, авторский) | несколько видов цветов и зелени | «авторский букет», «букет с гортензией и розами» |
| **Композиция** | цветы стоят в сосуде на флористической пене (оазисе) или в кашпо, не связаны в букет | «композиция в шляпной коробке», «композиция в кашпо» |
| **Корзина** | композиция в плетёной корзине, обычно на оазисе | «корзина с гортензией и розами» |
| **Букет в коробке** | связанный букет, поставленный в коробку | «букет в шляпной коробке» |
| **Сумка** | букет в подарочной сумке или коробке-сумке | «букет в сумочке» |
| **Бутоньерка** | миниатюра для петлицы | «бутоньерка из розы» |

**Правило:** если в букете больше одного вида цветов — это не монобукет. Никогда не ставить «Монобукет: Да» для микса.

## 2. Формы букета

- **Круглый** — классика, симметричный, смотрится одинаково со всех сторон.
- **Каскадный** — цветы стекают вниз, для свадьбы и сцены.
- **Линейный (вертикальный)** — вытянутый вверх, строгий.
- **Треугольный** — одна вершина, часто для мужских букетов.
- **Асимметричный** — равновесие за счёт разных по весу частей.
- **Веер** — раскрытый, для декоративных композиций.

## 3. Стили и техники

| Стиль / техника | Признак |
|---|---|
| **Вегетативный** (европейский) | цветы растут естественно, много зелени, «как в саду» |
| **Декоративный** | плотная заливка, акцент на цвете и форме, минимум просветов |
| **Форма-линейный** | строгая геометрия, линии, каркас |
| **Спиральная техника** | стебли уложены по спирали, букет держится в руке без связки |
| **Параллельная техника** | стебли идут параллельно, букет плоский или линейный |
| **Каркасный** | форма держится на каркасе из веток, проволоки, ленты |
| **Бидермейер** | плотный купол, цветы по кругу, центр акцентный |
| **Тейпирование** | стебли обмотаны тейп-лентой, часто для бутоньерок |

## 4. Материалы и словарь

- **Оазис (пиафлор)** — флористическая пена, держит воду для композиций.
- **Тейп-лента** — бумажная лента для стеблей.
- **Анкор** — крепление для оазиса.
- **Сизаль, джут, лён** — декоративные волокна.
- **Крафт, тишью, матовая плёнка, сетка** — упаковка.
- **Теппинг** — крепление цветка на проволоку.

## 5. Упаковка

- Крафт — «эко», универсально.
- Матовая плёнка — премиальнее, держит форму.
- Тишью — мягкая, для коробок.
- Сетка — объём.
- Лента: атлас, репс, органза. Для бренда — атлас в тон.

## 6. Стойкость и уход (для текстов и памятки)

| Цветок | Особенность | Что писать клиенту |
|---|---|---|
| Роза | 5–7 дней, не любит жару | подрезать, менять воду, убрать от фруктов |
| Гортензия | пьёт много, вянет первой | доливать воду ежедневно, можно окунуть голову в воду |
| Пион | раскрывается, живёт 3–5 дней | покупать полураскрытым, прохлада |
| Тюльпан | продолжает расти, гнётся | прохладная вода, не на солнце |
| Лилия | сильный аромат, 7–10 дней | убрать пыльники, не ставить в спальню |
| Альстромерия | 7–10 дней, неприхотлива | менять воду каждые 2 дня |
| Хризантема | до 10–14 дней | подрезать, прохладное место |
| Эустома | 7–10 дней | прохладная вода |

Формулировка «простоит N дней» — обещание, которое зависит от ухода. Писать «памятка по уходу», а не «гарантируем стойкость».

## 7. Как описывать букет (шаблон)

1. **Тип**: монобукет / авторский миксбукет / композиция в коробке / корзина.
2. **Состав**: 2–4 позиции, что видно на фото (роза, гортензия, эустома, зелень).
3. **Размер**: высота или количество стеблей.
4. **Стиль**: декоративный / вегетативный, упаковка.
5. **Повод**: свидание, день рождения, благодарность.
6. **Что в комплекте**: открытка, памятка.

Пример: «Авторский миксбукет: 9 роз, гортензия, эустома и эвкалипт. Высота 45 см, декоративный стиль, упаковка — матовая плёнка. Подойдёт на день рождения».

## 8. Чек-лист перед публикацией

- [ ] Тип назван верно: если в букете больше одного вида — это не монобукет.
- [ ] Композиция в сосуде не называется букетом.
- [ ] Корзина названа корзиной.
- [ ] Состав сверен с фото, а не придуман.
- [ ] Размер указан, если его видно или знает владелец.
- [ ] Нет обещаний стойкости.
