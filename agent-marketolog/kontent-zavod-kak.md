# Как Вова работает с контент-заводом

Пошагово, без импровизаций. Завод делает тексты и сценарии; фото, вёрстка и публикация — твои.

## 1. Взять задачу

Очередь — `../kontent-zavod/ochered.md`. Берёшь задачу со статусом `новая`. Если задача не твоя (например, про фото или цены) — не берёшь, пишешь причину.

## 2. Проверить, что в задаче есть всё

В задаче должны быть: канал, повод, что нужно, факты (цена, адреса, телефон), ограничения, срок. Чего нет — не додумываешь, а пишешь директору или креативному и ставишь статус `возвращена`.

## 3. Отправить на завод

```bash
cd "/Users/tatiana/Desktop/Обучение ИИ/proekty/Мои проекты"
node tools/gpt-factory.mjs kontent-zavod/zadaniya/<файл>.md kontent-zavod/gotovoe/<файл>.md
```

Если команда не сработала (нет вкладки ChatGPT, Chrome не запущен) — запусти Chrome с профилем на порту 9224 и повтори. Не получилось — пиши в отчёт, не выдумывай ответ.

## 4. Забрать ответ

Ответ — `kontent-zavod/gotovoe/<файл>.md`. Если ответ пустой или без заголовка задачи — статус `возвращена`.

## 5. Проверить

1. Чек-лист приёмки креативного директора: `../kreativnyy-direktor/priemka.md` (10 пунктов).
2. Сверка фактов с `knowledge.md`: цена, адреса, телефоны, часы. Расхождений быть не должно.
3. Свои ограничения: длина, один призыв, нет выдуманных обещаний, тон.
4. Если вернул на доработку — не больше 3 кругов, правка формулируется как «сделай X вместо Y».

## 6. Поставить статус

В `../kontent-zavod/ochered.md`: `готова` → `принята` (если прошло) или `возвращена` (с причиной одной строкой).

## 7. Дальше — твоя работа

- Фото обрабатываешь сам по `foto-pravila.md`: формат, свет, водяной знак, кроп.
- Собираешь материал: текст + фото.
- Публикация — только после «да» владельца.
- В отчёт `otchety/ГГГГ-ММ-ДД-otchet.md` — что взял из завода, что проверил, что осталось.

## Чего не делаешь

- Не правишь файл задачи и файл ответа «по месту» — правки идут новым кругом через задачу.
- Не отправляешь в завод две задачи одним запросом.
- Не публикуешь без «да».
- Не подписываешь ответ завода как свой: в отчёте пишешь, что это контент-завод.
