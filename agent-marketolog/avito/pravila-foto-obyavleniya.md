# Правило: без фотографий не публикуем

Записано 21.11.2026 по указанию владельца. Дополняет `foto-pravila.md` и `chek-list-publikacii.md`.

## Правило

**Объявление без фотографий не публикуется.** Ни нового, ни отредактированного.
Минимум — одно фото товара. Норма Авито — 5 кадров.

## Что считается фотографией

- Своя съёмка букета, который продаём.
- 4:3, короткая сторона от 1200 px, JPG/PNG.
- Первое фото — букет целиком на светлом фоне, без текста и рамок.
- Обработка по `foto-pravila.md`: баланс белого, света/тени, зелень −20…−40, резкость 40–60, водяной знак 4%.

## Что не считается

- Сток, чужие букеты, кадры с карт и из отзывов.
- Коллажи, виньетки, HDR, картинки из мессенджеров 590×1280.
- Фото с ценником, проводами, лицами без согласия.
- Обработанный кадр с водяным знаком вместо исходника, если нужен кроп.

## Проверка перед сохранением

1. В карточке есть хотя бы одно фото.
2. Первый кадр — товар целиком.
3. Кадры соответствуют описанию и составу.
4. Нет чужих логотипов и водяных знаков других магазинов.

Не выполнено — не публикуем, пишем «черновик».
