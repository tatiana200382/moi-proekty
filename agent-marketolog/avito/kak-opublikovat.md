# Как опубликовать объявление: три пути

Проблема, из-за которой «100 лет не публикуется»: у Авито обязательные поля-списки (вид товара, состав, цвет) — в интерфейсе они капризные, автозаполнение сбрасывается при перерисовке формы.

## Путь 1 — автозагрузка (основной, обходит капризные списки)

Фид уже есть: `results/avito-feed.xml`. В нём поля передаются значениями, а не выбираются мышкой.

1. Кабинет Авито → **Автозагрузка** (раздел «Товары и услуги»).
2. Создать автозагрузку формата **XML**, указать файл `avito-feed.xml`.
3. В маппинге сопоставить поля: `Id`, `Category`, `GoodsType`, `Title`, `Description`, `Price`, `Address`, `City`.
4. Запустить проверку и публикацию.
5. Ошибки маппинга Авито покажет построчно — исправить и загрузить снова.

**Ограничение:** автозагрузка доступна не всем аккаунтам и может требовать подключённого профиля. Если раздела нет — путь 2.

## Путь 2 — ручное заполнение (один раз, чтобы узнать значения)

1. Открыть черновик `draftId=1838110905`.
2. Заполнить по порядку: **вид товара → состав → цвет → цена → описание → адрес**.
3. На каждом списке: выбрать значение **и** дождаться, пока форма перерисуется, потом идти дальше.
4. Если поле сбросилось — вернуться и выбрать заново, не заполняя остальные.
5. Дойдя до публикации — не нажимать «Опубликовать» без «да» владельца, а сохранить черновик и записать, какие значения Авито принял.

Эти значения потом переносим в фид: они и есть решение блокера.

## Путь 3 — через API (позже)

API Авито даёт опубликовать объявление полями. Нужен доступ к API и токен. Когда появится — публикация станет одной командой.

## Что должно быть готово до любого пути

- [ ] текст описания: `avito/opisanie-1.md`;
- [ ] 3–5 фото, обработанных по `foto-pravila.md`;
- [ ] цена подтверждена владельцем на дату публикации;
- [ ] адрес и телефон точки;
- [ ] «да» владельца на публикацию.

## Чего делать нельзя

- Публиковать один товар дважды (дубли снимают, при повторе — блокировка).
- Ставить «от» в цене.
- Обещать доставку и состав, которых нет в `knowledge.md`.
- Публиковать без «да».
