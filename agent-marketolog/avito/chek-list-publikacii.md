# Чек-лист публикации: 50 проверок до, 10 после

Правило владельца от 2026-11-11: **перед публикацией проверять всё 50 раз** и **не ставить телефоны в текст**.

## Железные запреты

- **Телефон в тексте запрещён.** Ни в заголовке, ни в описании, ни на фото. Номер Авито показывает сам из профиля, а контакты в тексте — нарушение правил и повод снять объявление.
- Ссылки, мессенджеры, e-mail, QR — тоже нельзя.
- Нельзя «от» вместо реальной цены, если такого букета нет.

## Перед публикацией: 50 проверок

Проходить **пятью кругами по 10 пунктов**. Каждый круг — отдельный взгляд, между кругами переключиться на другое (текст → фото → факты → правила → глазами покупателя).

### Круг 1. Факты (10)

1. Цена совпадает с прайсом из `knowledge.md`.
2. Состав совпадает с фото (роза/гвоздика/хризантема — по кадру).
3. Высота и количество указаны, если видно на фото.
4. Адреса — ровно как в `knowledge.md`.
5. Часы работы каждой точки верны.
6. Рейтинги с датой проверки.
7. Год работы магазина верен.
8. Тип товара: букет / композиция / корзина / монобукет — по фото.
9. «Монобукет: да» стоит только там, где один вид цветка.
10. Нет выдуманных обещаний (стойкость, скорость, «гарантия 5 дней»).

### Круг 2. Текст (10)

11. Заголовок до 50 знаков, без цены и «недорого».
12. В заголовке есть повод или количество.
13. Первая строка — крючок с выгодой.
14. Второй абзац — для кого и по какому поводу.
15. Есть блок «почему у нас» из 3–4 доказательств.
16. Есть три уровня цены.
17. Есть адреса и часы.
18. Есть один призыв — и только один.
19. Призыв конкретный, с готовой фразой («напишите: нужен букет на завтра»).
20. **В тексте нет ни одного номера телефона.**

### Круг 3. Фото (10)

21. 5+ фото.
22. Первое фото — букет целиком, не обрезан верх.
23. Фон светлый и ровный.
24. Белые лепестки не пересвечены.
25. Зелень не кислотная.
26. Водяной знак внизу справа, не мешает.
27. Нет чужих логотипов и ценников.
28. Нет людей без согласия.
29. Фото обработаны по `foto-pravila.md` и лежат в `results/foto-gotovye/`.
30. Размер и вес в лимитах Авито.

### Круг 4. Правила Авито (10)

31. Один товар — одно объявление, не дубль.
32. Категория «Растения → Букеты».
33. Вид объявления верный.
34. Характеристики заполнены все.
35. Коды ТН ВЭД/ОКПД2 из каталога Авито, поля с «Данные не нужны» очищены.
36. Галочка «документы не требуются» стоит, если так и есть.
37. Контактное лицо и телефон — из профиля, не в тексте.
38. Самовывоз/доставка настроены.
39. Нет запрещённых слов и контактов.
40. Лимит контактов и срок понятны.

### Круг 5. Глазами покупателя (10)

41. Открыть публичную страницу, не кабинет.
42. Описание видно целиком.
43. Все фото загрузились.
44. Цена и адрес правильные.
45. Характеристики на месте.
46. Нет предупреждений Авито в карточке.
47. Карточка находится поиском по заголовку.
48. С телефона выглядит нормально.
49. Первый экран отвечает: что, сколько, где, как заказать.
50. Хочется написать — проверено на себе.

## Перед публикацией: анализ 100 конкурентов

Без этого шага публикация не начинается.

1. Взято **не меньше 100 объявлений** из выдачи по своим запросам (3–4 запроса, розница).
2. Для каждого зафиксировано: заголовок, цена, число фото, отзывы, продвижение, «оплата частями», доставка.
3. Отобраны **топ-10 по признакам конверсии**: много отзывов + продвижение + полная карточка.
4. Выписаны их приёмы: цифры в заголовке, гео, крючок первой строки, доказательства, призыв.
5. Наши приёмы взяты **не меньше трёх** из этого списка.
6. Результат — в `avito/analiz-konkurentov-ГГГГ-ММ-ДД.md`, со ссылкой на источник данных.

## После публикации

- [ ] публичная страница проверена по кругу 5;
- [ ] через сутки: показы, просмотры, контакты;
- [ ] через неделю: сравнение с конкурентами.

## Как это записывать

В задаче: «проверок 50/50 пройдено, анализов конкурентов 100, источник — выдача от <дата>».
