# Чек-лист публикации: до и после

Объявление считается сделанным не когда нажата кнопка «Опубликовать», а когда карточка проверена глазами покупателя.

## До публикации

- [ ] заголовок: товар + конкретика (повод, количество, ключевое слово), до 50 знаков;
- [ ] цена — одна реальная цифра, без «от»;
- [ ] описание: цена, что получаете, гарантия, адреса с телефонами и часами, один призыв;
- [ ] кодовое слово для замера заявок;
- [ ] 5 фото, обработанных по `foto-pravila.md`;
- [ ] характеристики: вид товара, состав по фото, цвет, наличие;
- [ ] адрес и телефон точки совпадают с `knowledge.md`;
- [ ] самовывоз и доставка подключены, если доступны;
- [ ] «да» владельца на публикацию.

## После публикации — обязательно

Открыть **свою карточку как покупатель** (не кабинет, а публичную страницу) и проверить:

- [ ] описание видно целиком, а не заглушка;
- [ ] все фото загрузились и видны;
- [ ] цена и адрес правильные;
- [ ] характеристики сохранились;
- [ ] в карточке нет предупреждений Авито (GTIN, доставка);
- [ ] карточка находится поиском по своему заголовку.

Если хоть один пункт не выполнен — объявление **не считается опубликованным**, задача возвращается в работу.
