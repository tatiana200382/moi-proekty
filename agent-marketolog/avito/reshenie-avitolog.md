# Нужен ли отдельный Авитолог: решение

Дата: 2026-11-11. Вопрос владельца: создавать отдельного ИИ-специалиста по Авито или оставить площадку Вове.

## Решение

**Оставить у Вовы. Отдельного Авитолога сейчас не создавать.**

## Почему

| Аргумент | Факт |
|---|---|
| Знания уже есть | у Вовы учебник Авито из 8 разделов: алгоритм, продвижение, рейтинг, категории, карточка, аналитика, автозагрузка, стратегии (`znaniya/avito/`) |
| Инструменты выбраны | `avito/instrumenty.md`: 20 кандидатов с GitHub, выбраны 3 |
| Стратегия есть | `avito/strategiya.md`: 5 объявлений, фото, цена, быстрый ответ, тест |
| Материалы готовы | черновики объявлений, 3 обработанных фото, XML-фид `results/avito-feed.xml` |
| Объём мал | активных товарных объявлений — 0; товарные пока в черновиках, 7 удалённых — вакансии |
| Узкое место — не знания | публикацию блокируют обязательные характеристики (монобукет, состав, цвет), модерация бота и отсутствие API для чатов |

Новый сотрудник не решит эти блокеры: он упрётся в те же поля и доступы, но добавит третью роль в отдел, где уже есть путаница между «Марком» и «Вовой».

## Когда Авитолог станет нужен

Любой из порогов:

- больше **10 активных** товарных объявлений одновременно;
- автозагрузка по расписанию с ежедневной проверкой фида;
- больше **20 чатов в день** по объявлениям;
- бюджет продвижения Авито больше **20 000 ₽/мес**;
- нужен отдельный ежедневный отчёт по показам, контактам и цене заявки.

До этого объём закрывает Вова.

## Что сделать вместо нового сотрудника

1. **Автозагрузка вместо ручных характеристик.** Фид `results/avito-feed.xml` уже есть: он передаёт состав и категорию полями, минуя капризные списки в интерфейсе. Это и есть обход блокера.
2. **Один ручной проход** по трём характеристикам для первого объявления — чтобы понять, какие значения Авито принимает, и перенести их в фид.
3. **Шаблоны ответов** в чатах — 5 готовых, чтобы отвечать в течение 15 минут.
4. **Еженедельный отчёт** по Авито: просмотры, контакты, цена контакта → в `plan-testov.md`.

## Что это даёт

- Не плодим роли: одна площадка — один ответственный.
- Экономим управленческое время: задачи не перекидываются между «Маркетом», «Вовой» и «Авитологом».
- Через 2–4 недели по цифрам видно: хватает Вовы или пора выделять специалиста.
