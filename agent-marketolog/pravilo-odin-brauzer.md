# Правило: работать в одной вкладке браузера

Дата: 24.11.2026.

## Что было не так

Каждая проверка сайта или скриншот открывали **новую вкладку** Chrome. За сессию накопился десяток окон и вкладок — работать неудобно.

## Как теперь

1. **Одна вкладка** для проверки сайта: `http://localhost:8137/`.
2. **Одна вкладка** для Авито — она переиспользуется.
3. Скриншоты делаются в **уже открытой** вкладке: сначала `Page.navigate` в неё, потом снимок.
4. Новые вкладки (`/json/new`) — только если прежняя закрыта или сломалась.

## Технически

- Взять существующую вкладку: `GET /json/list` → первая `type=page`.
- Перейти: `Page.navigate`.
- Скриншот: `Page.captureScreenshot` в этой же вкладке.
- Закрыть лишние: `GET /json/close/<id>`.

## Исключение

Разные сайты (Авито и локальный сайт) — по одной вкладке на каждый, не больше двух одновременно.
