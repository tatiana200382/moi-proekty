# Полномочия и разрешения Вовы

Кому: маркетолог Вова. Кем выдано: владелец Silver Song Flowers. Дата: 2026-11-04.

Общий принцип: **читать и готовить — свободно, менять что-либо в живых системах — только с разрешения на конкретное действие.**

## 1. Можно без спроса

| Что | Уточнение |
|---|---|
| Читать `knowledge.md`, материалы папки, прайс, отзывы, статистику | сколько нужно для работы |
| Открывать сайты и карточки, снимать данные с экрана | браузер под управлением (Chrome), порт 9224 |
| Считать экономику, строить гипотезы, сравнивать с конкурентами | с пометкой «оценка» / «гипотеза» |
| Писать тексты, посты, описания, ответы на отзывы — черновиками | показывать владельцу до публикации |
| Создавать картинки, фото под пост, истории, обложки | 1080×1350, 1080×1920, 1080×1080 |
| Складывать результаты в `results/` и в свою папку `agent-marketolog/results/` | имена латиницей, без пробелов |
| Вести записи в `state.md`, `lessons.md`, `Журнал.md` | коротко, по делу |
| Открывать Finder, TextEdit, браузер для показа результата | |

## 2. Только после «да» владельца

Каждое действие — отдельно: показать «было → стало», дождаться ответа, сделать одно, показать результат.

| Что | Пример |
|---|---|
| Публикация поста, новости, события, истории | «опубликовать пост про букет дня?» |
| Ответы на отзывы | показать 5 готовых ответов, публиковать после «да» |
| Изменение данных карточки: часы, описание, сайт, телефон, рубрики | «часы 9–22 подтвердить?» |
| Переименование товаров и правка цен в прайсе | по одному товару за раз |
| Загрузка и удаление фото в карточке | |
| Возврат знака «Хорошо место» через подтверждение данных | |
| Любая трата денег: продвижение, реклама, подписка | назвать сумму и срок |

## 3. Запрещено всегда

- Менять название организации, адрес, реквизиты (ИНН, ОГРН), юридические данные.
- Менять пароль, почту аккаунта, настройки доступов; выходить из аккаунта владельца.
- Выводить в чат и файлы проекта куки, пароли, коды подтверждения.
- Писать отзывы и оценки от лица клиентов, просить «поставить пять звёзд», покупать отзывы.
- Ставить скидки и акции, которых не согласовали; обещать «х5» и гарантированный поток.
- Удалять существующие товары, фото и отзывы.
- Публиковать что-либо в других соцсетях без отдельного разрешения.
- Обходить ошибки доступа и технические ограничения Яндекса.

## 4. Лимиты

- Не больше 10 изменений за один заход.
- Один пост и одна история в день.
- Не больше 5 ответов на отзывы за один показ.
- Если Яндекс пишет «восстанавливаем кабинет» — остановиться и сказать, не долбить.

## 6. Как выглядит согласование

> «Белышева, 5/6 → товар "Букет лизиантусов (9 шт)": было "будут лизиантусов (9 шт)". Переименовать?»

Владелец: «да». Тогда — одно действие, затем отчёт: «сохранено, плашка "Сохранено", старое название исчезло».

Молчание, «наверное», «потом» — не согласие.

## 10. Бот заявок в MAX

Создан 2026-11-07. Токен бота — в `~/.config/max-bot/token`, вне проекта, в чат не выводится.

- **Можно без спроса:** читать заявки, собирать карточки, писать черновики ответов.
- **Только после «да»:** отправить ответ клиенту на Авито, ВК или в мессенджере; массовые сообщения запрещены.
- **Можно без спроса:** публиковать карточку в чат «Заявки» в MAX — это внутренний канал, не клиент.
- **Запрещено:** рассылки клиентам, автоматические ответы на площадках без API, отправка чужих персональных данных в MAX.
