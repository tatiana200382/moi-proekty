# Навыки: откуда и как использовать

Восемь файлов — выдержки из библиотеки [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills) (MIT, автор Corey Haines). Скачаны 2026-11-04, по одному `SKILL.md` на задачу.

## Что когда читать

| Задача | Файл |
|---|---|
| понять, что продаём, кому и чем отличаемся | `product-marketing.md` |
| выяснить, какими словами говорит клиент | `customer-research.md` |
| собрать оффер, цену, гарантии | `offers.md` |
| написать пост, страницу, объявление | `copywriting.md` |
| почистить готовый текст | `copy-editing.md` |
| план продвижения на месяц | `marketing-plan.md` |
| разбор конкурентов | `competitors.md` |
| что и как считать | `analytics.md` |
| работа с макетом или ссылкой на Figma | `figma.md` (свой навык, не из библиотеки) |

## Правила

- Читать только нужный файл, а не все восемь.
- Текст результата — всегда русский, каналы — российские (Авито, карты, ВК, Telegram, сайт).
- Механики западного SaaS-маркетинга не переносить без проверки, что канал у бизнеса есть.
- Библиотека не обновляется сама: чтобы получить свежую версию, скачать файл заново и повторить проверки.
