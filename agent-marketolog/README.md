# Вова — агент-маркетолог: как включить

Это отдельная папка-агент. Пока она открыта как рабочая папка в DeepSeek Harness, Вова работает по умолчанию — без команд «включись».

## Как включить (3 шага)

1. Открыть DeepSeek Harness.
2. Выбрать рабочей папкой `Мои проекты/agent-marketolog` (вместо «Мои проекты»).
3. Написать задачу обычными словами: «пост про букет дня», «разбери конкурента на Ленинском», «ответь на отзыв».

Инструкция `AGENTS.md` подхватится сама — это и есть агент.

## Что внутри

```
agent-marketolog/
├── AGENTS.md      — роль, правила, форматы (мозг агента)
├── knowledge.md   — факты о бизнесе: точки, цены, экономика, цели
├── skills/        — 8 инструкций по маркетингу + карта, что когда читать
├── results/       — готовые материалы: пост, фото, план
└── README.md      — этот файл
```

## Что Вова умеет сам

- Писать посты, офферы, ответы на отзывы, разборы конкурентов, планы.
- Собирать фото под пост: вырезать букет, поставить на фон, добавить бирку с ценой.
- Считать экономику акции и оценивать, окупится ли.

## Чего не может без вас

- Публиковать в ВК и отвечать в сообщениях: нет доступа к аккаунту.
- Видеть статистику группы и карточек на картах.
- Знать цифры, которых нет в `knowledge.md`.

## Отличие от папки `ii-marketolog`

`ii-marketolog` — рабочий комплект с историей испытаний и проверками, для сдачи задания. `agent-marketolog` — сам агент: папка, которую открываешь и работаешь. Знания и навыки в них одинаковые; правишь `knowledge.md` — поправь в обеих.

## Как работать с Figma

Figma доступна Вове только в Claude, а не в DeepSeek Harness. Откройте в Claude папку `Мои проекты/agent-marketolog` и пришлите ссылку на макет. Новая сессия сама подхватит роль Вовы из `CLAUDE.md`.

Правила и лимиты: `skills/figma.md`.
