# Фото: обязательная обработка перед публикацией

Ни одно фото не идёт в пост, сторис, объявление или на карточку **без обработки**. Это правило, а не пожелание.

## Что прочитать перед обработкой

## Порядок обработки (не переставлять)

1. **Отбор.** В работу 10–20% кадров. Кривые, смазанные, с чужим фоном — сразу в брак.
2. **Баланс белого.** Лепестки не жёлтые и не синие; кремовый фон остаётся кремовым.
3. **Экспозиция.** Белые лепестки **не в клиппинге**, запас −0,3…−0,7 EV.
4. **Света/тени.** Highlights −30…−50, Shadows +20…+40.
5. **Кривые.** Лёгкая S, чёрную точку не «в упор».
6. **Цвет (HSL).** Зелень Saturation −20…−40, Lightness −10; красный и оранжевый Lightness +5…+10. Кислотно-зелёный и «мультяшный» цвет — брак.
7. **Резкость.** Amount 40–60, Radius 0,8–1,0, Masking 40–60. Шум — только при ISO 800+.
8. **Кроп и горизонт.** По правилам формата: пост 4:5 (1080×1350), сторис 9:16 (1080×1920), карточка 1:1 (1200×1200).
9. **Водяной знак.** «Silver Song Flowers», внизу справа, высота 4% кадра.
10. **Экспорт.** sRGB, JPEG 85–90, вес до 5 МБ.

## Чек-лист перед публикацией

- [ ] нет чужих логотипов, брендов и узнаваемых чужих букетов;
- [ ] нет лиц без согласия;
- [ ] лепестки не пересвечены, тени не провалены;
- [ ] зелень естественная, цвет по палитре;
- [ ] горизонт ровный, кроп не режет букет;
- [ ] фон чистый, без лишних предметов;
- [ ] водяной знак на месте;
- [ ] размер и формат соответствуют площадке;
- [ ] исходник `_orig` сохранён, версия вверх (`_v1`, `_v2`).

Если хоть один пункт «нет» — фото не публикуется, а возвращается в обработку.

## Куда сохранять

`results/foto-gotovye/ГГГГ-ММ-ДД_<тема>_<формат>_v1.jpg`

Исходники не удалять. Готовое фото показывать владельцу до публикации.

## Запись о работе

В задаче или отчёте указать:

```
Исходник: results/foto-buketov/buket-07.jpg
Готово: results/foto-gotovye/2026-11-08_buket-dnya_post-1080x1350_v1.jpg
Что сделано: ББ, экспозиция −0,5 EV, зелень −25, кроп 4:5, водяной знак
Проверка: чек-лист пройден (10/10)
```

Без этой записи фото считается необработанным.

## Инструменты

| Задача | Инструмент |
|---|---|
| Кроп, цвет, водяной знак, пакет | Pillow (Python) |
| Пакетная обработка | ImageMagick `magick mogrify -resize "1600x1600>" -quality 88` |
| Видео и вертикаль | ffmpeg |
| Макеты с текстом | `templates/vizual/post-4x5.html`, `story-9x16.html` |

## Что запрещено

- Публиковать сток, чужие фото, генерацию товара ИИ.
- Одинаковый кадр во все соцсети: максимум две площадки, для остальных — другой кадр или формат.
- Коллажи, виньетки, HDR, «мультяшная» цветокоррекция.
