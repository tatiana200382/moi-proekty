# Стандарт визуала Silver Song Flowers

Одна страница, по которой снимаем и собираем всё. Основано на `znaniya/vizual/`.

## Палитра

| Цвет | HEX | Где |
|---|---|---|
| Крем | `#FBF3EA` | фон макетов |
| Шалфей | `#8D9D76` | акцент, плашки |
| Пыльная роза | `#C98F94` | акцент второй |
| Тёмный | `#3E4032` | текст |
| Тёплый серый | `#8A8578` | подписи |

## Шрифты

- Заголовки: антиква (Cormorant / Playfair Display).
- Текст и цены: гротеск (Inter / Manrope).
- Кернинг Optical, трекинг заголовка −20.

## Форматы

| Что | Размер |
|---|---|
| Пост в ленту | 1080×1350 (4:5) |
| Сторис и клип | 1080×1920 (9:16) |
| Карточка Авито | 1200×1200 или 4:3 |
| Обложка ВК | 1920×768 |

## Фото: рецепт

1. Окно сбоку 45°, рассеиватель, отражатель с теневой стороны.
2. Фон: лён, бумага, штукатурка. Не больше 3 предметов в кадре.
3. ISO 100–400, f/2.8–f/4 (букет), WB 5200–5600K, RAW.
4. Белые лепестки −0,3…−0,7 EV.
5. Три ракурса: фронт, 45° сверху, деталь.
6. Букет 60–70% кадра, воздух 30–40%.

## Обработка

- Порядок: WB → экспозиция → света/тени → кривые → HSL → резкость.
- Зелень приглушать (Saturation −20), красные не выкручивать.
- Насыщенность не выше +10.
- Экспорт: sRGB, JPEG 85, 1080 px по длинной стороне.

## Водяной знак

Антиква «Silver Song Flowers», белый с мягкой тенью, внизу справа, высота 4% кадра. Не по центру, не на лице букета.

## Текст на макете

- Не больше трёх уровней: заголовок → цена → адрес.
- Заголовок вдвое крупнее подписи.
- Контраст с фоном от 4,5:1.
- Один призыв: «написать» или «забрать».
