# Бот заявок: Авито + ВК + Яндекс.Карты → один чат в MAX

Цель: все заявки с трёх площадок приходят в один чат MAX — уже обработанные, с готовым ответом и статусом.

## Что уже работает

| Часть | Состояние |
|---|---|
| Формат заявки и карточка для MAX | `lead.py` — проверено, карточка собирается |
| Отправка в MAX | `max_client.py` — код готов, ждёт токен бота |
| Хранилище заявок | `../leads/*.json` |

## Что нужно от владельца (два шага)

1. **Создать бота в MAX.** business.max.ru → «Чат-боты» → создать → «⋮» → «Настройки» → токен.
   Токен положить в файл `~/.config/max-bot/token` (одна строка, права 600). В чат и в проект не копировать.
2. **Создать чат для заявок.** В MAX создать групповой чат (например, «Заявки Silver Song»), добавить туда бота. ID чата я получу сам через `POST /subscriptions` после первого сообщения боту в этом чате.

## Архитектура

```
Авито ─┐
ВК ────┼─→ сбор (управляемый Chrome) ─→ нормализация (lead.py) ─→ черновик ответа ─→ MAX-бот ─→ чат «Заявки»
Яндекс ┘
```

## Три этапа, честно

**Этап 1 — пересылка (можно делать сейчас).** Бот читает новые сообщения на площадках через управляемый браузер, формирует карточку и постит её в чат MAX. Ответ клиенту — черновик, отправляет человек.

**Этап 2 — автоответы там, где есть официальный API.** ВК отдаёт сообщения через API сообщества (нужен токен с правами `messages`). Авито — только через API мессенджера для партнёров (нужна заявка на доступ). Яндекс.Карты своего API для переписки не имеют: там кнопка ведёт в Telegram или WhatsApp, и сообщения живут в мессенджере.

**Этап 3 — автоответы через браузер.** Технически возможно, но это автоматизация чужого интерфейса: риск блокировки аккаунта и хрупкость при обновлении сайтов. Делаем только с согласия владельца и с ограничением: отправка одного шаблонного ответа, без массовых рассылок.

## Почему не делаем «полностью сам» сразу

Автоответ без API = бот кликает в браузере. Один сбой вёрстки — и клиент получает мусор, а аккаунт магазина — предупреждение. Поэтому сначала пересылка и черновики, потом API, и только затем автоматизация интерфейса.

## Команды

```bash
python3 bot/max_client.py me                      # проверить токен
python3 bot/max_client.py updates                 # входящие события бота
python3 bot/max_client.py send <chat_id> "текст"  # отправить карточку
python3 bot/lead.py                               # пример карточки
```

## Метрики

Заявка → время до карточки в MAX → время до ответа клиенту → заявка стала покупкой. Считаем в `../leads/` и в `../../../plan-testov.md`.
