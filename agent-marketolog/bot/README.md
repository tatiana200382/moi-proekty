# Бот заявок: Яндекс.Карты + Авито + ВК → один чат MAX

Цель: все заявки с площадок приходят в один чат MAX — с контактами, составом заказа,
черновиком ответа и статусом.

## Что уже работает (проверено 2026-11-07)

| Часть | Состояние |
|---|---|
| Сбор заявок Яндекса | **работает**: читает «Заявки» кабинета Яндекс.Бизнеса через управляемый Chrome, 10 последних заявок сохранены |
| Сбор сообщений ВК | **работает**: сообщения сообщества включены 2026-11-07, читает входящие `/gim188108705`; два текущих диалога — предложения услуг, отфильтрованы |
| Формат заявки и карточка | `lead.py` — карточка с номером, клиентом, телефоном, составом, суммой, комментарием и черновиком |
| Защита от повторов | номер заявки Яндекса; повторный запуск не создаёт дублей — проверено |
| Первый запуск | история сохраняется со статусом «старая» и в MAX не уходит, чтобы чат не получил 10 карточек за прошлый месяц |
| Клиент MAX | `max_client.py` — исправлен по документации: токен в заголовке, `chat_id` в параметре, сертификат Минцифры, разбор ошибок |
| Отправка в MAX | ждёт токен бота и ID чата |

## Чего не хватает

1. **Токен бота MAX.** business.max.ru → «Чат-боты» → создать → «⋮» → «Настройки» → токен.
   Положить в `~/.config/max-bot/token` (одна строка, права 600). В чат и в проект не копировать.
2. **Чат для заявок.** Создать групповой чат (например, «Заявки Silver Song»), добавить бота,
   написать в чате любое сообщение и выполнить `python3 bot/max_client.py discover-chat`.
   ID берётся из `GET /updates` (long polling), публичный вебхук не нужен.
3. **Авито.** На аккаунте только вакансии: одна активная и семь неопубликованных, цветочных
   объявлений нет — собирать нечего. Нужно опубликовать букеты или назвать, какие объявления
   считать магазином.
ВКонтакте сообщения включены 2026-11-07, отдельного действия от владельца больше не нужно.

## Как устроено

```
Яндекс.Бизнес «Заявки» ─┐
Авито (пока нет) ───────┼─→ управляемый Chrome ─→ разбор (collect.py) ─→ карточка (lead.py) ─→ MAX-бот ─→ чат
ВК «Сообщения сообщества» ─┘
```

Сбор — только чтение: скрипт открывает вкладку, читает список и закрывает соединение.
На площадках бот ничего не отправляет. Настройки (например, включение сообщений ВК)
меняются только вручную и с разрешения владельца.

## Команды

Из папки `agent-marketolog`:

```bash
python3 bot/collect.py yandex              # заявки Яндекса, карточки в leads/outbox
python3 bot/collect.py vk                  # сообщения сообщества ВК
python3 bot/collect.py all                 # обе площадки
python3 bot/collect.py all --send          # собрать и отправить новые в MAX
python3 bot/collect.py flush               # отправить всё, что ещё не ушло
python3 bot/collect.py status              # сколько заявок, есть ли токен и чат

python3 bot/max_client.py me               # проверить токен
python3 bot/max_client.py discover-chat    # найти ID чата по событиям бота
python3 bot/max_client.py updates          # входящие события
python3 bot/max_client.py send <chat_id> "текст"
```

## Первый запуск

Первый обычный запуск сохраняет всё, что уже есть на площадках, как историю:
статус «старая», в MAX не отправляется. Дальше бот присылает только новые.
Если нужно отправить и старые — `--all`, но это засыплет чат карточками за прошлые месяцы.
Сообщения ВК, похожие на предложения услуг (сайты, обложки, реклама), отбрасываются
по списку `spam_keywords` в `config.json` — иначе чат заполнят продавцы.

## Где что лежит

- `bot/lead.py` — формат заявки и карточка.
- `bot/collect.py` — сбор, разбор, дедупликация, очередь, отправка.
- `bot/browser.mjs` — управление Chrome (порт 9224), только чтение.
- `bot/sources/*.js` — что именно читать на каждой площадке.
- `bot/max_client.py` — MAX Bot API.
- `bot/certs/max-ca.pem` — корневые сертификаты Минцифры (публичные), без них API MAX не отвечает.
- `../leads/*.json` — заявки; `../leads/outbox/` — неотправленные карточки.

Заявки содержат телефоны и почту клиентов, поэтому папка `leads/` в GitHub не попадает
(добавлена в `.gitignore`).

## Ограничения

- Яндекс отдаёт только видимые 10 строк списка; новые заявки появляются сверху, этого хватает
  для регулярного опроса. Для полной выгрузки есть кнопка «Скачать XLSX».
- Автоответы на Авито и ВК без официального API не делаем: это автоматизация чужого
  интерфейса, риск блокировки аккаунта. Этап 1 — пересылка и черновик, отправляет человек.
- Фильтр ВК простой, по словам. Если реальный клиент напишет про сайт или рекламу,
  сообщение может не попасть в чат — такие случаи надо смотреть в кабинете ВК.

## Метрики

Заявка → время до карточки в MAX → время до ответа клиенту → покупка.
Считаем в `../leads/` и в `../../plan-testov.md`.
