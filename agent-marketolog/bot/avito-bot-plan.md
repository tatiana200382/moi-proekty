# Бот для Авито: план и статус

Цель: бот сам отвечает в чате Авито, задаёт вопросы, собирает заявку и передаёт менеджеру готового клиента (повод, дата, бюджет, доставка, контакт).

## Что уже готово

- `avito_bot.py` — логика диалога до готовой заявки, проверена на демо.
- `lead.py` — карточка заявки, сохранение в `../leads/*.json`.
- MAX-бот (`max_client.py`) — канал для пересылки заявок в один чат.

## Три пути подключения к Авито

| Путь | Что даёт | Условия | Вердикт |
|---|---|---|---|
| **Быстрые ответы** (уже есть в кабинете) | шаблоны в 2 клика, ускоряют ответ | бесплатно | делаем сейчас, без бота |
| **API-интеграция** («Автоматизация чатов → Интеграция по API») | настоящий бот: читает и отвечает сам | подписка на инструменты + доступ к Messenger API | основной путь |
| Браузерная автоматизация | имитация человека | нарушает правила Авито | запрещено |

## Сценарий диалога

1. Приветствие + вопрос о поводе и дате.
2. Бюджет (нормализуется: «до 4000» → 4 000 ₽).
3. Самовывоз или доставка + адрес.
4. Контакт (телефон или имя).
5. Готовая карточка заявки → менеджеру в MAX.

Правила:
- не обещать стойкость и сроки, которых нет;
- если дата сегодня/завтра — помечать «срочно»;
- если бюджет ниже 1 500 ₽ — предложить минимальный вариант;
- при вопросах о наличии — передать менеджеру, не выдумывать.

## Что нужно от владельца

1. Подписка на инструменты Авито (уровень с Messenger API) — цену смотреть в «Тарифе».
2. Доступ к API: client_id и client_secret от Авито (после подключения).
3. Кто принимает заявки: номер/чат MAX и часы работы.
4. Разрешение на отправку автоответов клиентам (правило: ответ клиенту только после «да»).

## Что делаю после «да»

1. Включаю быстрые ответы в кабинете (5 шаблонов).
2. Пишу адаптер к Messenger API и вебхук.
3. Тестирую на одном объявлении, смотрю 20 диалогов.
4. Только потом включаю на все.

## Метрики

Время первого ответа, доля диалогов с заявкой, доля заявок с полными данными, конверсия заявка → заказ.
