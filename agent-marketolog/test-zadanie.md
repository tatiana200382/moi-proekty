# Тестовое задание: проверка инструментов

Одна команда показывает, работает ли всё, чем Вова пользуется. Запускать после перезагрузки, смены браузера, перед важной работой.

## Запуск

```bash
cd "/Users/tatiana/Desktop/Обучение ИИ/Мои проекты/agent-marketolog"
./tools/smoke-test.sh
```

Ничего не публикует, не меняет карточки и объявления. Только читает и проверяет. Если вкладки Авито или ВК закрыты — открывает их сам.

## Если что-то провалилось

| Провал | Что делать |
|---|---|
| Chrome 9224 не отвечает | запустить Chrome с профилем и портом (команда в `../PRAVILA.md`, раздел «Браузер») |
| Авито или ВК не открылись | войти в аккаунт в этом окне; проверить VPN — Авито с ним не работает |
| Рендер не собрался | проверить, что Chrome на месте и `templates/post-card.html` не сломан |
| GitHub API молчит | включить VPN (правило в `../PRAVILA.md`) |
| Навыков меньше 8 | проверить папку `skills/` |

Провал трёх и больше пунктов — не работать, сначала починить: иначе Вова будет обещать, а не делать.
