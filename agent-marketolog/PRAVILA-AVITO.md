# Правила работы с Авито: как человек

Дата: 24.11.2026. Правила действуют для всех скриптов и агентов, которые открывают Авито.

## Главное

**Мы ведём себя как сотрудник магазина в рабочее время, а не как робот-сканер.**
Один человек не обновляет 50 страниц в минуту — и мы не будем.

## Частота

| Что | Как |
|---|---|
| Заход в кабинет | не чаще **1 раза в 15–20 минут** |
| Ночью (23:00–08:00) | раз в **30–60 минут** |
| Сообщения в чатах | читаем каждые 15 минут, но не чаще |
| Просмотр объявлений | **не более 10 карточек** за один заход |
| Между действиями | пауза **2–5 секунд**, случайная |

Интервал всегда с «дрожанием»: 15–20 минут, а не ровно 15:00. Робот точен, человек — нет.

## Признаки блокировки — стоп сразу

| Признак | Что делаем |
|---|---|
| `429 Too Many Requests` | пауза **60–80 минут** |
| «Проблемы с IP» / «Пройти проверку» | пауза **90–120 минут** + сообщение в MAX |
| Просьба войти заново | **не пытаться автоматически**, сообщить владельцу |
| Капча | решает **человек**, скрипт ждёт |

Повторные попытки во время блокировки **запрещены**: каждая попытка продлевает бан.

## Окружение

| Правило | Почему |
|---|---|
| **VPN выключен** | Авито видит зарубежный IP и блокирует |
| **Только домашний IP** | один адрес — как у одного сотрудника |
| **Одна вкладка Авито** | десять вкладок = десять «сотрудников» |
| **Один браузер** | не запускаем второй профиль параллельно |
| **Без параллельных запросов** | строго по очереди |

## Что нельзя делать никогда

1. **Публиковать объявления** без явного «да» владельца.
2. **Менять цены** автоматически.
3. **Отправлять сообщения клиентам** без проверки человеком (кроме ответов сотрудника по команде из MAX).
4. **Открывать чужие объявления** и собирать данные конкурентов массово.
5. **Обходить капчу** и подделывать действия пользователя.
6. **Работать через прокси и VPN** для Авито.

## Оформление объявлений

- текст **свой**, не копия конкурентов;
- фото **свои**, не из интернета;
- поля заполняются **вручную или через интерфейс**, без подмены значений скриптом;
- массовое изменение полей — только по одной позиции и с паузой.

## Если сработал лимит

1. Стоп.
2. Записать в лог: время, страница, код ответа.
3. Пауза по таблице выше.
4. Сообщение в MAX: «Авито ограничил доступ, пауза до HH:MM».
5. После паузы — **один осторожный заход**, не серия.

## Логи

Каждый заход пишем в `otdel-prodazh/runtime/logs/run.log`:

```
Авито: заход 23:40, чатов 12, новых 1, ответ 200
Авито: 429, пауза до 00:55
```

Без логов невозможно понять, где мы превысили темп.

## Проверка перед запуском

- [ ] VPN выключен
- [ ] открыта только одна вкладка Авито
- [ ] сторож `avito-guard.sh check` разрешает заход
- [ ] прошло не меньше 15 минут с прошлого захода

## Ответственность

Правила нарушены → аккаунт может получить ограничение, а магазин — потерять заявки.
Поэтому **лучше пропустить цикл, чем рискнуть блокировкой**.
