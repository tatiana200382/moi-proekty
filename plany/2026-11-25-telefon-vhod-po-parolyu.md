# План (упрощение): вход по паролю для телефона

Дата: 25.11.2026. Разрешение: получено (владелец просил довести настройку телефона).

## Зачем
Импорт ключа через облако/заметки не получается. Пароль вводится вручную — это проще и не требует файлов.

## Что меняю на сервере
1. Создать пользователя `phone` (только для туннеля).
2. Задать ему длинный случайный пароль.
3. Разрешить вход по паролю (в sshd уже разрешён).
4. fail2ban уже стоит — защита от перебора есть.

## Проверка на изолированном участке
```
ssh -o PreferredAuthentications=password phone@2.31.104.44 "echo ok"
```
(с Мака, с вводом пароля)

## Откат
```
userdel -r phone 2>/dev/null
```

## Риск
- Пароль можно подобрать перебором → длинный пароль + fail2ban.
- Пользователь без sudo — только туннель.

## Результат (проверено на сервере)
| Проверка | Результат |
|---|---|
| Вход `phone` по паролю | ✅ `Accepted password for phone` (дважды) |
| Активная сессия | ✅ есть |
| Исходящие соединения сервера | ✅ **к серверам Telegram** (149.154.*:443, :5222) |

**Вывод: телефон подключён к нашему серверу, трафик идёт через него.**
