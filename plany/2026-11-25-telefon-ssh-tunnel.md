# План: телефон через наш сервер по SSH (как на Маке)

Дата: 25.11.2026. Разрешение: **запрошено** (нужна покупка приложения 9,99 $).

## Почему этот путь
Факты, проверенные на Маке:

| Транспорт | 1 МБ | Итог |
|---|---|---|
| **SSH (порт 22)** | ✅ 1,4 МБ/с | работает |
| VLESS+Reality (443) | ❌ рвётся | провайдер режет |
| Shadowsocks (8443) | ❌ ~1 КБ/с | душится |
| VMess TCP | ❌ рвётся | — |

**SSH — единственный транспорт, который проходит полностью.** На Маке он и используется.

## Решение
Приложение **«SSH Tunnel: VPN и SOCKS5»** (App Store, id1260223542, **9,99 $**) — умеет поднимать системный VPN поверх SSH, с автопереподключением и работой в фоне. По сути это то же, что мы сделали на Маке, но с системным туннелем.

## Что нужно
1. Купить приложение (разрешение владельца — обязательно, это трата).
2. Ключ доступа: отдельная пара ключей для телефона.
3. Настройки подключения: сервер `2.31.104.44`, пользователь `root`, ключ ed25519.

## Порядок
| № | Шаг | Где |
|---|---|---|
| 1 | Сгенерировать ключ для телефона | Мак |
| 2 | Добавить публичный ключ на сервер | сервер |
| 3 | Положить приватный ключ в iCloud Drive (файлом) | Мак |
| 4 | Установить приложение, импортировать ключ из «Файлов» | телефон |
| 5 | Подключиться, проверить IP и сайты | телефон |
| 6 | Проверить по логам сервера, что сессия есть | сервер |

## Откат
```
# на сервере убрать строку ключа телефона из /root/.ssh/authorized_keys
sed -i '/phone-tunnel/d' /root/.ssh/authorized_keys
```

## Риск
- В приложении ключ без пароля (как на Маке) — доступ к серверу только по ключу, пароли отключены.
- Трата 9,99 $ — только с разрешения владельца.

## Подготовлено (сделано)
| Шаг | Результат |
|---|---|
| Ключ для телефона создан | ✅ `/tmp/phone-tunnel` (ed25519, без пароля) |
| Публичный ключ добавлен на сервер | ✅ `/root/.ssh/authorized_keys` |
| Проверка входа по ключу | ✅ успешно, сервер отвечает |
| Приватный ключ в iCloud Drive | ✅ `iCloud Drive → Silversong → phone-tunnel.key` |

## Осталось (владелец)
1. Купить **«SSH Tunnel: VPN и SOCKS5»** (9,99 $) — ссылка: https://apps.apple.com/app/id1260223542
2. Установить, открыть, создать подключение:
   - сервер `2.31.104.44`, порт `22`
   - пользователь `root`
   - ключ: импорт из «Файлов» → iCloud Drive → Silversong → `phone-tunnel.key`
3. Включить VPN, проверить сайт.

## Проверка после подключения (сервер)
```
last -a | head -3
journalctl -u ssh | tail -5
```
