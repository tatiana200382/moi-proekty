# План: заставить Codex (внутри ChatGPT.app) ходить через наш туннель

Дата: 25.11.2026. Разрешение владельца: **ожидается**.

## Диагноз
- Вход в **Codex** (не в сам чат) оканчивается ошибкой `token_exchange_failed`, `403 Country, region, or territory not supported`.
- Браузер и обычный чат через туннель работают, страна определяется как **DE**.
- Codex — отдельный исполняемый файл (Rust), который **не читает системный SOCKS-прокси** macOS и ходит напрямую → запрос уходит с российского адреса.

## Проверка диагноза (перед изменением)
1. Убедиться, что при попытке входа соединения Codex **не идут** через `127.0.0.1:1082`.
2. Убедиться, что браузерная страница `127.0.0.1` приходит с нашего же адреса.

## Что меняю
Задать переменные окружения для графических приложений (одна команда, откат — вторая):
```
launchctl setenv HTTPS_PROXY  socks5h://127.0.0.1:1082
launchctl setenv HTTP_PROXY   socks5h://127.0.0.1:1082
launchctl setenv ALL_PROXY    socks5h://127.0.0.1:1082
```
Затем перезапустить ChatGPT.app.

## Критерий успеха
- Вход в Codex проходит; ошибка 403 не появляется.

## Если не помогло
- Поднять локальный HTTP-прокси, который пересылает через SOCKS, и задать `HTTPS_PROXY=http://127.0.0.1:8118`.

## Откат (без агента)
```
launchctl unsetenv HTTPS_PROXY
launchctl unsetenv HTTP_PROXY
launchctl unsetenv ALL_PROXY
```
и перезапуск ChatGPT.app.

## Риск
- Переменные влияют на приложения, запущенные **после** установки. Системный прокси остаётся включённым, поэтому остальное поведение не меняется.
