# План: телефон через наш сервер — VMess по обычному TCP

Дата: 25.11.2026. Разрешение: запрошено.

## Задача
Телефон должен ходить через **наш** сервер `2.31.104.44` (не через чужие серверы).

## Что уже известно (факты)
| Проверка | Результат |
|---|---|
| TLS с SNI `bing/cloudflare/samsung` до нашего сервера | ✅ проходит |
| TLS с SNI `microsoft/google/apple/yandex` | ❌ режется провайдером |
| Обычный TCP (без TLS) до нашего сервера | ✅ проходит (проверено эхом 30 КБ в обе стороны) |
| SSH-туннель на Маке | ✅ работает полностью |
| VLESS+Reality (TCP/Vision) с Мака | ✅ работает |
| VLESS+Reality на iPhone (Happ) | ❌ подключается, данные не идут |

## Гипотеза
Проблема — в **TLS/Reality на iPhone**, а не в сервере. Значит нужен транспорт **без TLS**: VMess по обычному TCP (порт 8443).

## Что меняю на сервере
- добавить вход `vmess` (без TLS), порт **8443**;
- открыть 8443 в ufw.

## Проверка на изолированном участке (Мак)
1. Клиент xray: vmess → socks 127.0.0.1:1098.
2. `curl` через socks: внешний IP должен быть `2.31.104.44`.
3. Скачивание 100 КБ.

**Только если оба пункта пройдены — делаю QR для телефона.**

## Откат
```
python3 (удалить вход 8443 из /root/xray.json)
ufw delete allow 8443/tcp
systemctl restart xray
```

## Риск
- VMess без TLS не маскируется: DPI может его распознать. Если провайдер режет — вернёмся к Reality, но с другим SNI.
