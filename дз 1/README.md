## Структура

Сейчас все документы лежат в корне папки. В подпапках, кроме `отчёты/`, пока только `README.md` с их назначением.

```
дз 1/
├── проект/         — для итоговых документов; пока пусто
├── материалы/      — для задания, промптов, черновиков; пока пусто
├── данные/         — для цифр бизнеса; пока пусто
├── отчёты/         — сводки и разборы; в скриншоты/ четыре снимка для сдачи
└── эксперименты/   — для тестов и замеров; пока пусто
```

## Правила папки

- Один результат — один файл. Не смешиваем точку А с дорожной картой.
- Каждая цифра — со статусом: `подтверждено`, `оценка`, `нет данных`. Выдуманных значений нет.
- Источник факта пишем рядом: «из 1С», «со слов», «примерно».
- Задание и промпты школы не переписываем — это оригинал.
