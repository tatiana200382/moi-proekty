# Правило категорий на Авито: товар и вакансия не смешиваются

## Решение владельца (2026-11-21)

- Цветы продаём **с этого же профиля**: другого номера телефона для отдельного профиля нет. Каждый раз вручную «Другая категория» → «Для дома и дачи» → «Растения» → «Букеты».
- **Вакансии остаются лично за владельцем.** Команда раздел «Работа» не трогает, только чтение.
- Черновик 1838137179 **удаляется**, вместо него создаётся новое объявление.

Введено 2026-11-21 после разбора `results/2026-11-21-kategorii-avito.md`. Причина: аккаунт — профессиональный профиль в категории «Работа», форма подачи стартует в «Работе», и никакое правило не заставляло проверить категорию.

## 1. Стоп-кадр категории (главное)

Публикация не начинается, пока в отчёте нет **скриншота шапки формы**, где видно «Для дома и дачи → Растения → Букеты». Путь один: «Разместить объявление» → **«Другая категория»** → «Для дома и дачи» → «Растения» → «Букеты». Форма, открывшаяся в «Работе», — это отказ, а не «сейчас поправлю».

## 2. Проверка после сохранения — по URL

Открыть публичную страницу и посмотреть адрес:

- правильно: `avito.ru/sankt-peterburg/**rasteniya**/...`
- ошибка: `avito.ru/sankt-peterburg/**vakansii**/...`

Скриншот страницы — в `results/skriny/`. Пока URL не проверен, в отчёте пишется «черновик», а не «опубликовано».

## 3. Слова-маркеры

- В товаре запрещены: продавец, флорист, вакансия, зарплата, график, смены, стажировка, опыт работы, резюме.
- В вакансии нет цены букета и цены товара.
- Заголовок товара начинается с «Букет»/«Композиция»/«Розы».

## 4. Границы по ролям

| Кто | Что может |
|---|---|
| Владелец | создаёт, правит и удаляет вакансии в разделе «Работа» |
| Вова (`agent-marketolog`) | товары в «Растения → Букеты»; раздел «Работа» — **только чтение**, ни одной кнопки |
| Директор | проверяет отчёт и скриншоты, публикаций не делает |

Вакансии «Продавец цветов в ночь» и «Флорист продавец цветов» — личные объявления владельца, не команды.

## 5. Фид — отдельный шаблон товаров

- `Category` = **Растения** (не «Цветы»; такого значения в дереве Авито нет).
- `GoodsType` = из строки товара: Букеты / Комнатные растения / Другое.
- Вакансии в фид не попадают вообще: один фид — только товары.
- Перед загрузкой прогнать файл через `autoload.avito.ru/format/xmlcheck/` и приложить отчёт проверки.

## 6. Порядок перед каждой публикацией

1. Категория выбрана через «Другая категория», скриншот шапки есть.
2. Слова-маркеры проверены (п. 3).
3. После сохранения проверен URL (п. 2).
4. Строка в `../agent-marketolog/avito/schet-pervyh-10.md` и в отчёте: ID, URL, раздел, кто подал.

Нарушение любого пункта — публикация не считается сделанной.
