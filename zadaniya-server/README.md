# Задания для серверного агента

Здесь лежит **очередь задач**, которые выполняет сервер (а не Мак).

## Как это работает

| Шаг | Что происходит |
|---|---|
| 1 | Вы (или Мак) кладёте файл `*.md` в `ochered/` — в нём текст задачи обычными словами |
| 2 | Синхронизация копирует файл на сервер (ярлык «Синхронизировать-проект») |
| 3 | Сервер каждые **5 минут** проверяет очередь и берёт **самый старый** файл |
| 4 | Агент на сервере выполняет задачу (`dsh --profile headless`) |
| 5 | Ответ кладётся в `vypolneno/<имя>.otvet.md`, задача — в `vypolneno/<имя>.zadanie.md` |
| 6 | Синхронизация возвращает ответы на Мак |

## Правила

- **Одна задача — один файл.** Имя: `гггг-мм-дд-кратко.md`.
- В задаче пишите: **что сделать** и **как проверить, что готово**.
- Сервер работает **без Мака** — задачи идут, пока Мак выключен.
- Задачи, которым нужен **российский IP** (Авито, ВК, MAX), на сервере **не выполнятся** — это ограничение.

## Пример

```
# 2026-11-26-otchet
Собери сводку: сколько файлов в проекте, какие папки самые большие,
что изменялось за последние сутки. Запиши ответ в файл и закончи.
```

## Запуск вручную (на сервере)

```
systemctl start server-agent.service
journalctl -u server-agent.service -n 20
```
