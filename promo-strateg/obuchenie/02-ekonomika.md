# 2. Экономика акции

## База для расчёта

- Средний чек — 2 500 ₽ (подтверждено).
- Валовая маржа — около 55% (закупка ~50% выручки минус потери).
- Значит **скидка 20% = минус почти вся прибыль по чеку**.

## Формулы

1. **Маржа после скидки** = (цена × 0,55) − (цена × скидка). Если меньше 0 — акция убыточна.
2. **Сколько заявок нужно**, чтобы отбить стоимость акции: стоимость ÷ (маржа на заказ).
3. **Цена заявки** = расход ÷ число заявок. Порог — 300 ₽.

## Пример

Букет 2 500 ₽, маржа 1 375 ₽. Доставка за наш счёт 400 ₽ → маржа 975 ₽. Скидка 10% (250 ₽) → 725 ₽. Всё ещё плюс, но каждый пятый заказ «в минус по времени флориста».

## Упражнение: посчитать три идеи из банка и отсеять убыточные.
