# 4. Как измерить акцию

Пока акцию нельзя измерить, её нельзя запускать.

| Способ | Когда подходит |
|---|---|
| Кодовое слово в сообщениях | ВК, Авито, карточки |
| Промокод | если есть корзина на сайте |
| Отдельная ссылка | реклама |
| Вопрос «откуда узнали» | на кассе, в звонке |
| Отдельный телефон | если акция крупная |

## Минимум для теста

- Дата старта и конца.
- Сколько потратили.
- Сколько заявок и покупок.
- Цена заявки и цена заказа.

## Упражнение: для трёх идей из банка придумать способ замера без сайта и CRM.
