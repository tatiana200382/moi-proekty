# 6. Как вести банк идей

1. Одна идея — одна строка в `../marketing-idei/bank.md`.
2. Оценки: влияние (10 = сильно), стоимость (10 = дорого), риск (10 = опасно), скорость (10 = за день).
3. Статусы: `новая → в работу → тест → принята / архив`.
4. Раз в месяц — ревизия: что не дошло до теста и почему.
5. Не повторять идеи из архива без новой причины.
