# Совет директоров

Верхний уровень: даёт указания отделам и проверяет исполнение. Не заменяет владельца — владелец ставит цели совету и утверждает деньги.

## Как работает

1. Совет формулирует **указание**: что сделать, какому отделу, зачем, срок, по какой цифре проверим.
2. Указание кладётся в `ukazaniya/` по шаблону и уходит руководителю отдела.
3. Отдел отвечает: принимает, пишет план исполнения, через срок — отчёт в `otchety/`.
4. Совет проверяет: сделано / не сделано / нужны данные. Итог — владельцу.

## Правила

- Одно указание — один отдел и одна проверяемая цифра. Не «сделайте всё хорошо».
- У указания всегда есть **срок** и **признак выполнения**.
- Отдел может вернуть указание с вопросом, если данных не хватает — но не молча.
- Указание не отменяет правило «да» владельца на публикации, цены и траты.
- Спор отдела и совета решает владелец.
