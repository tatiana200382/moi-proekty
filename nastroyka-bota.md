# Как настроить бота «Котик»

Главное: бот не учится правилам из сообщений в чате. Правила — это его системная инструкция (system prompt). Текст правил лежит в `CLAUDE.md`, его и нужно вставить в настройку бота.

## 1. Токен

- BotFather → `/mybots` → ваш бот → **API Token**.
- Токен хранится в файле `.env` в папке проекта. В чат, в этот файл и в скриншоты он не попадает.
- Если токен засветился — в BotFather `/revoke`, старый сразу перестанет работать.

## 2. Профиль бота в BotFather

- `/setname` — «Котик».
- `/setdescription` — «Личный секретарь: план, напоминания, идеи, журнал».
- `/setabouttext` — короткое описание для профиля.
- `/setcommands` — три команды:
  ```
  plan - план на сегодня
  itogi - итоги дня
  idei - список идей
  ```
- `/setjoingroups` → **Disable**: бот личный, в группы не добавляется.

## 3. Куда вставить правила

**Вариант А — платформа без кода** (n8n, Make, готовый конструктор):
в поле системной инструкции / System prompt вставить текст `CLAUDE.md` целиком, без изменений.

**Вариант Б — свой скрипт на Python или Node:**
скрипт читает `CLAUDE.md` при старте и подставляет в запрос к модели. Код могу написать — скажите, где будете запускать.

## 4. Проверка

Написать боту три сообщения и посмотреть результат:

1. «план» → должен ответить списком из `Напоминания.md`.
2. «напомни завтра в 9 позвонить в банк» → строка в `Напоминания.md`.
3. «идея: продавать букеты по подписке» → запись в `Идеи.md` плюс разбор.

## Чего не делать

- Не присылать токен в чат с ботом или с кем-то ещё.
- Не давать боту право писать другим людям от вашего имени.
- Не хранить пароли и доступы в файлах этой папки.
