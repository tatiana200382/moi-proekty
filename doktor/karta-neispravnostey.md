# Карта неисправностей: симптом → причина → проверка → лечение

Справочник Доктора. Идём сверху вниз: сначала дешёвые проверки.
Каждая строка — гипотеза, которую надо **закрыть фактом**, а не «наверное, оно».

## 1. Структура и файлы

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| Ссылка в документе не открывается | файл переименован или удалён | `ls` по пути из ссылки | починить ссылку или вернуть файл из git |
| В корне появился «файл на память» | забыли правило `STRUKTURA.md` | `ls *.md \| wc -l`, сверить с картой | предложить `arhiv/` или папку роли |
| Два документа противоречат друг другу | правило скопировали в два места | `grep` по ключевой фразе | оставить источник в `PRAVILA.md`, в копии — ссылку |
| Симлинк `obsidian`/`sekretar` битый | переехала целевая папка | `ls -l obsidian sekretar; test -e` | пересоздать ссылку `ln -s` |

## 2. Правила и алгоритмы

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| Правило есть, но его не выполняют | правило спрятано в длинном файле | есть ли раздел в `PRAVILA.md` и ссылка в `AGENTS.md` | вынести в начало, добавить в чек-лист |
| Агент «забыл» шаг (голос, Obsidian) | шаг не в чек-листе «Проверка перед сдачей» | пройти чек-лист по пунктам | добавить пункт в чек-лист |
| Ошибка повторяется | урок не записан или не прочитан | `uroki.md` — есть ли строка | записать урок, прочитать перед похожей задачей |

## 3. Скрипты и голос

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| `skazat.sh` молчит | TTS-сервер 8765 не поднят / нет venv | `curl -s -m1 localhost:8765/say?text=` | перезапустить `tools/tts_server.py`, лог `/tmp/tts_server.log` |
| Голос тихий | громкость плеера | `afplay -v 2.5` | повторить с усилением |
| Скрипт не запускается | снят бит исполнения | `ls -l skazat.sh` | `chmod +x` |
| `command not found: node` | нет PATH от nvm | `which node` | работать через полный путь к node |

## 4. Браузер

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| CDP не отвечает | Chrome не запущен с `--remote-debugging-port=9224` | `curl -s localhost:9224/json/version` | перезапустить Chrome с профилем `.chrome-profile` |
| Сайт просит войти заново | протухли куки в профиле | открыть сайт руками в этом профиле | войти, куки не копировать в git |
| Страница пустая, хотя есть HTML | контент рисуется JS | подождать/`waitForSelector` | использовать ожидание, а не `sleep` на глаз |

## 5. Git и GitHub

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| Не пушится | сеть/VPN или протух SSH | `git ls-remote origin` | сменить сервер VPN, ключ не трогать |
| Конфликт после чужой ветки | правки GPT в main | `git fetch && git status` | показать владельцу, мержить через ветку `gpt/<тема>` |
| В git попали куки/профиль | забыли `.gitignore` | `git ls-files \| grep -c chrome-profile` | убрать из индекса, `git rm --cached`, добавить в `.gitignore` |

## 6. Данные и отчёты

| Симптом | Вероятная причина | Проверка | Лечение |
|---|---|---|---|
| Цифра в отчёте ≠ таблице | разные даты выгрузки или ручная правка | пересчитать по исходнику | пересчитать и указать дату источника |
| Заявка «пропала» | дубликат/фильтр или лид вне окна 5 минут | сравнить скриншот и таблицу | расширить окно, записать правило |
| CSV не читается | разделитель `;`, кодировка, кавычки | `head -3 file.csv` | явно указать `sep`/`encoding` |

## Как пользоваться

1. Нашёл строку — выполнил **проверку** из таблицы.
2. Проверка подтвердила причину — лечение.
3. Проверка не подтвердила — вычеркнуть гипотезу, перейти к следующей.
4. Закрыл — запись в `zhurnal.md`.
