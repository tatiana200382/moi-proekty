# Почему ответ из бота не дошёл до клиента

Дата: 2026-11-27, разбор по жалобе. Только чтение, ничего не менял.

## Короткий ответ

Бот **не пытался отправить** ответ: он не нашёл заявку по номеру из сообщения и молча остановился. В логе одна строка — `номер не найден: 3264646`.

## Факты

| Что проверено | Результат |
|---|---|
| Сообщение-ответ | `3264646 привет`, пришло в **личку** боту от пользователя `max:44842615` |
| Что сделал бот | `max-inbox-server`: `номер не найден: 3264646` → отправка не запускалась |
| Что в базе заявок (`state.json`) | 107 заявок, из них MAX — **одна** (код `1206870`, статус `skip`); кода `3264646` нет |
| Что в `zayavki.csv` | 107 строк: vk 44, avito 36, yandex 26, max 1; строка с кодом `3264646` отсутствует |
| Следы отправки | нет ни одной строки «передано в отправку» за период — то есть ответы не терялись на площадке, до неё дело не дошло |

## Причина

1. **Номер не совпал.** Коды заявок живут только в `state.json`. Сообщение с числом `3264646` не совпало ни с одной текущей заявкой — вероятно, это код из более старой карточки, а база пересобиралась (`sync: добавлено 0, всего 106`).
2. **Нет обратной связи.** При ненайденном номере бот пишет только в лог. Флорист в чате не видит, что ответ не ушёл — со стороны это выглядит как «бот не ответил клиенту».
3. **Нет фильтра по чату.** `max-inbox-server` разбирает любые сообщения с числом в начале, включая личные сообщения боту. Поэтому сообщение попало и в разбор ответов, и в сбор заявок (создалась заявка «Татьяна: 3264646 привет»).

## Что предлагаю починить (нужно «да»)

| Правка | Зачем |
|---|---|
| На ненайденный номер отвечать в чат: «Заявка 3264646 не найдена, проверьте номер» | флорист сразу видит проблему |
| Разбирать ответы только из чата заявок (`-81003587560055`), не из личек | клиентские сообщения перестанут путаться с ответами |
| Хранить коды отдельно от пересборки базы (архив кодов или code → заявка) | старые карточки продолжат работать |
| Показывать код в карточке явно и проверять его при создании | меньше опечаток |

Откат: правки только в `max-inbox-server.py`, копия файла перед изменением.
