# Аудит правил на сервере: включён

Дата: 2026-11-26. План: `plany/2026-11-26-audit-na-servere.md`. Разрешение: получено.
Работает без Mac: сервер `2.31.104.44`.

## Что теперь происходит само

| Когда | Что | Куда сообщает |
|---|---|---|
| 06:00 UTC (09:00 МСК) ежедневно | обновляет копию репозитория, запускает `audit.py` | нарушение → Telegram; чисто → тихая запись |
| каждые 5 минут | сторож проверяет, что аудит был не позже 26 часов назад | тревога, если аудит замолчал |
| при сбое обновления | проверяет вчерашнюю копию | 🟠 «не удалось обновить» |

## Проверки (факты)

| № | Что проверял | Результат |
|---|---|---|
| 1 | Первый запуск на сервере | клон `rc=0`, аудит `rc=0 fails=0`, копия на коммите `e593422` |
| 2 | Снимок без `.git` (изолированно) | `FAIL 0`, 1216 файлов |
| 3 | Подсунутый токен в файле | `FAIL 1: П4 секреты` |
| 4 | Правка `PRAVILA.md` без записи | `FAIL 1: П5 правила без записи` |
| 5 | Возврат к чистому состоянию | `FAIL 0` |
| 6 | Сквозная тревога | `audit rc=1 fails=1`, `alert ok=True отправлено` |
| 7 | Таймер | `doktor-audit.timer`, следующий запуск 06:00 UTC |
| 8 | Контроль молчания | сторож: «OK аудит правил: последний запуск 0.0 ч назад» |
| 9 | Уборка | `/root/audit-test` удалён, тестовые правки откатаны |

## Что понадобилось и чего не понадобилось

- Репозиторий оказался **публичным**, поэтому хватило анонимного HTTPS-клона. Deploy-ключ не нужен — на одно действие владельца меньше.
- Клон `--depth 1` в `/opt/doktor/repo`; перед аудитом `reset --hard origin/main`, чтобы локальные следы не мешали.
- Для тестов добавлен флаг `--no-pull` (прогон без обновления копии).

## Ограничения

- Видит только **запушенное** в GitHub. Локальные незакоммиченные правки на Mac не видны (их ловит локальный запуск).
- Реагирует раз в сутки: нарушение, сделанное в 10:00, будет замечено в 09:00 следующего дня. Можно участить — одна строка в таймере.
- Секреты ищутся по шаблонам: нестандартный формат токена может не поймать.
- Не заменяет ворота: они не дают нарушить, аудит только находит.

## Откат

```
systemctl disable --now doktor-audit.timer
rm -f /etc/systemd/system/doktor-audit.timer /etc/systemd/system/doktor-audit.service
rm -rf /opt/doktor/repo /var/lib/doktor-audit
systemctl daemon-reload
```
