# Фото букетов

85 фотографий, скопированы 2026-11-04 из папки «фото букетов» на рабочем столе. Оригиналы не тронуты. Съёмка — 5 сентября 2026.

Имена: `buket-01.jpg` … `buket-85.jpg`, порядок — как в оригинальной папке по времени.

## Что на снимках

Готовые букеты и композиции: корзины, коробки, бумажная упаковка. Часть — в руках у продавца, часть — на белой ткани. Фон простой, без лишнего.

## Лучшие для публикации

- `buket-03.jpg` — пастельная корзина с гортензией и гвоздиками, рука продавца, живой кадр.
- `buket-31.jpg` — бело-голубая композиция в коробке, ровный свет, похоже на витрину.

Оба хороши тем, что видно состав и размер. Для поста «букет дня» подойдёт любой из них.

## Чего не хватает

1. Флорист за работой: руки, стол, срез стебля. Это то, что хвалят в отзывах, и этого нет ни на одном кадре.
2. Фото входа или витрины — чтобы человек узнал магазин в своём районе.
3. Кадр «букет рядом с человеком» для масштаба: видно, большой он или маленький.
4. Свежие кадры: сентябрьские фото через два месяца уже не совпадают с тем, что стоит в зале.

## Как снимать дальше (телефон, 3 минуты)

- Свет: у окна или на улице днём. Вспышку не включать.
- Фон: однотонная стена, ткань, дерево. Не ковёр и не прилавок с ценниками.
- Кадр: букет целиком плюс один крупный план цветка.
- Без фильтров и без чужих фото из интернета.
