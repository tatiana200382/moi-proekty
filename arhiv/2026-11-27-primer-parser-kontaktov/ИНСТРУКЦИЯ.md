# Инструкция: собрать базу контактов за один запуск

Инструкция для человека, который делает это впервые. Время — около 20 минут, из них 15 ждёт компьютер.

---

## 0. Что понадобится

- Компьютер с Windows.
- Python 3.10 или новее.
- Телефон на Android — если нужны контакты из телефонной книги.
- Аккаунт Telegram — если нужны контакты оттуда.

Если чего-то нет, соответствующий шаг просто отключается в настройках.

---

## 1. Установить Python

Скачать с python.org, запустить установщик, **обязательно** поставить галочку **Add Python to PATH** на первом экране.

Проверка: откройте «Командную строку» и введите

```
python --version
```

Должно ответить `Python 3.12.x` или похоже.

---

## 2. Положить ADB (только для телефона)

ADB — программа, которая разговаривает с телефоном.

1. Скачайте **SDK Platform-Tools** с сайта Android Developers (страница «SDK Platform-Tools»).
2. Распакуйте, например, в `C:\platform-tools`.
3. В `config.json` укажите путь:

```json
"phone": { "enabled": true, "adb_path": "C:\\platform-tools\\adb.exe" }
```

Если пропустить этот шаг, телефонный сбор не запустится, а Telegram-часть отработает нормально.

---

## 3. Включить отладку на телефоне

1. Настройки → О телефоне → семь раз нажать «Номер сборки». Появится «Для разработчиков».
2. Настройки → Для разработчиков → включить **Отладка по USB**.
3. Подключить телефон кабелем, выбрать режим «Передача файлов».
4. На экране телефона появится запрос «Разрешить отладку» — нажать **Разрешить**.

Проверка: в командной строке `adb devices` должен показать устройство со словом `device`.

---

## 4. Настроить config.json

Файл лежит рядом с `Собрать-базу.cmd`. Открывается блокнотом.

```json
{
  "phone":    { "enabled": true,    "adb_path": "adb" },
  "telegram": { "enabled": true,    "chats": ["Название вашего рабочего чата"] }
}
```

- `chats` — названия чатов, откуда нужно вытащить людей. Пишите ровно как в Telegram. Можно несколько. Пустой список — значит, только контакты из книги Telegram.
- `output_name` — как назвать итоговый файл.

---

## 5. Запустить

Двойной клик по **`Собрать-базу.cmd`**.

При первом запуске:

1. Скрипт поставит две библиотеки (telethon, openpyxl) — нужен интернет, минута.
2. Спросит номер телефона в формате `+79991234567`.
3. Telegram пришлёт код — ввести его в окно.
4. Если включена двухфакторная защита — спросит пароль.

Код и пароль вводятся **только в это окно на вашем компьютере**. Они никуда не передаются и не сохраняются: сохраняется лишь файл сессии в папке `tg/`, как в самом Telegram Desktop.

При следующих запусках вход уже не потребуется.

---

## 6. Что происходит дальше

| Шаг | Что делает | Сколько ждёт |
|---|---|---|
| 1 | снимает контакты с телефона | 10 секунд |
| 2 | вход в Telegram | разово |
| 3 | забирает контакт-лист | 5 секунд |
| 4 | тянет профили: о себе, канал, ссылки | ~1 профиль в секунду |
| 4б | читает рабочие чаты, ищет людей | 1–3 минуты |
| 5 | склеивает, размечает, собирает Excel | 10 секунд |

Про шаг 4: Telegram отдаёт описание профиля только по одному запросу на человека. На 1 500 контактов это примерно 25 минут. Процесс можно закрыть и запустить снова — собранное сохраняется, докачается остаток.

---

## 7. Забрать результат

Папка `output/`, файл `База_контактов.xlsx`.

Начните с листа **«Сводка»** — там видно, сколько всего людей, сколько подрядчиков, чего не хватает. Дальше лист **«Подрядчики»**: это рабочий список, отсортированный по полезности.

---

## Частые проблемы

**«Python не найден».** Python установлен без галочки Add to PATH. Переустановите, отметив её.

**«ADB не найден».** Не указан путь в `config.json` или не установлены platform-tools.

**«Телефон не найден».** Кабель, режим передачи файлов, отладка по USB или не подтверждён запрос на экране телефона. Проверьте по порядку.

**«Ни одной таблицы получить не удалось».** На экране телефона висит неподтверждённый запрос доступа. Разблокируйте телефон и нажмите «Разрешить».

**«Неверный код».** Код живёт несколько минут. Запустите скрипт снова и введите новый.

**«Flood wait».** Telegram временно ограничил запросы. Подождите указанное время, запустите снова — прогресс сохранён.

**Excel не открывается / нет файла.** Смотрите последние строки в окне: там написано, на каком шаге остановилось. Чаще всего — не было контактов ни в телефоне, ни в Telegram.

---

## Что важно знать про данные

- Всё происходит на вашем компьютере. Ничего не отправляется на сторонние серверы, кроме запросов к самому Telegram.
- Файл сессии `tg/main.session` даёт полный доступ к аккаунту, как пароль. Не пересылайте его и не кладите в облако.
- База содержит персональные данные. Храните её так же, как хранили бы телефонную книгу.
