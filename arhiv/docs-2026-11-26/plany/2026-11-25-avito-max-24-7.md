# План: Авито и MAX работают 24/7 при выключенном Маке

Дата: 25.11.2026. Разрешение владельца: получено на подготовку плана.

## Задача
При выключенном MacBook заявки с Авито продолжают приходить в чат «Заявки» в MAX, а сотрудники могут отвечать клиентам из MAX.

## Проверено фактами (25.11.2026)

| Откуда | Avito сайт | Avito API | MAX API |
|---|---|---|---|
| **Немецкий сервер** `2.31.104.44` | ❌ **429** (слишком много запросов) | 302 (отвечает) | ❌ **000** (недоступен) |
| **Мак** (российский IP) | ✅ работает | — | ✅ работает |
| **Российский сервер** `ai.m-tik.com` (188.242.157.159, SkyNet, СПб) | ⏳ не проверено | — | ⏳ не проверено |

**Вывод: из Германии Авито и MAX не работают.** Нужен российский выход.

## Архитектура, которая решает задачу

```
[Немецкий сервер]                        [Российский хост]
 бот 24/7  ──SSH-туннель (SOCKS)──▶  Avito / MAX
 файлы, DSH, агенты                        российский IP
```

- Бот живёт на немецком сервере (там уже DSH, Xray, nginx).
- Запросы к **Avito** и **MAX** идут через SSH-туннель на российский хост.
- Остальной трафик — напрямую из Германии.

## Что нужно от владельца
**SSH-доступ к российскому хосту `ai.m-tik.com`** (или прокси на нём).
Это единственное, чего не хватает: остальное готово.

## Почему не новый российский VPS
| Причина | Деталь |
|---|---|
| Авито блокирует адреса хостингов | уже видно: с немецкого хостинга ответ **429** |
| Домашний/офисный IP SkyNet работает | сотрудники работают с него каждый день |
| Деньги | не нужны |

## Варианты, если SSH на ai.m-tik.com не дадут
1. Прокси на этом хосте (squid, только для Авито и MAX, с паролем).
2. Российский VPS с резидентным прокси — дороже и риск блокировки Авито.
3. Оставить на Маке — не решает задачу (Мак выключен).

## После получения доступа
| № | Шаг | Проверка |
|---|---|---|
| 1 | SSH-ключ, туннель `ssh -D` с немецкого сервера на российский | `curl --socks5` → российский IP |
| 2 | Проверить Авито и MAX через туннель | 200 и 200 |
| 3 | Перенести бота (файлы `otdel-prodazh/tools`, `agent-marketolog/bot`) | запуск вручную |
| 4 | Перенести сессию Авито (профиль Chrome с куками) | вход не требует пароля |
| 5 | Служба systemd + таймер каждые 5 минут | `systemctl status` |
| 6 | Тест: заявка с Авито → сообщение в MAX → ответ сотрудника → уходит в Авито | сквозной тест |

## Откат
```
systemctl disable --now sales-bot
```
Бот на Маке остаётся как есть.

## Ограничение
Cookies Авито привязаны к сессии: при смене IP может потребоваться повторный вход. Тогда потребуется ваш телефон для кода.
