# Серверный агент: задачи выполняются без Мака

Дата: 25.11.2026. Запущено и проверено.

## Что это

На немецком сервере работает **агент**, который берёт задачи из очереди и выполняет их сам — **даже когда Мак выключен**.

## Как устроено

| Компонент | Что делает |
|---|---|
| `/root/server-agent.sh` | берёт самый старый файл из очереди и запускает `dsh --profile headless` |
| `server-agent.timer` | запускает проверку очереди **каждые 5 минут** |
| `enqueue-daily.timer` | каждый день в **06:00 UTC (09:00 МСК)** ставит задачу «ежедневная сводка» |
| Ключ модели | берётся из `/root/.dsh/.credentials.yaml` при запуске |

## Папки (синхронизируются с Маком)

```
zadaniya-server/
├── ochered/      — задачи, ждут выполнения
├── vypolneno/    — выполненные: .zadanie.md, .otvet.md, .code
├── logi/         — журналы запусков
└── README.md     — инструкция
```

## Что можно переносить сюда

| Тип задачи | Подходит |
|---|---|
| Сводки, отчёты, разбор файлов проекта | ✅ |
| Проверки служб, чистка, бэкапы | ✅ |
| Тексты, планы, аналитика по файлам | ✅ |
| **Авито, ВК, MAX** | ❌ нужен российский IP |
| Telegram (чтение чатов) | ❌ нужен экран Мака |

## Как пользоваться

1. Положить файл задачи в `zadaniya-server/ochered/` (имя: `гггг-мм-дд-кратко.md`).
2. Запустить ярлык **«Синхронизировать-проект»**.
3. Через 5–10 минут ответ появится в `vypolneno/` — синхронизировать снова.

## Откат

```
systemctl disable --now server-agent.timer enqueue-daily.timer
```
