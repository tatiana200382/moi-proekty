## Защита агента от сбоев

| Механизм | Значение |
|---|---|
| Тайм-аут одной задачи | **600 секунд** |
| Повтор при сбое | **2 попытки** |
| Задач за один запуск | не больше **2** |
| «Ядовитая» задача | уходит в `karantin/`, очередь не блокирует |
