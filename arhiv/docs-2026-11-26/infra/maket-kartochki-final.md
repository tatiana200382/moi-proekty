```
Действие: ответить

Наш ответ: Здравствуйте! Да, есть. На какую дату и время нужен?

123456            ← номер в блоке
```

## Правила вида

| Что | Как |
|---|---|
| Фото | **первым**, вложением-картинкой (не ссылкой) |
| Время | первой строкой вместе с источником |
| Клиент | вторая строка |
| Сообщение клиента | «От клиента: …» — **только его слова** |
| Наш ответ | «Наш ответ: …» — последний отправленный/черновик |
| Номер | последней строкой, `<code>номер</code>` — **без слов «Ответить»** |

## Проверено

| Проверка | Результат |
|---|---|
| API: html + `<code>` | ✅ 200 |
| API: картинка по внешнему URL | ✅ 200 |
| Тестовое сообщение удалено | ✅ |
| Рендер карточек ВК и Авито | ✅ см. выше |
| Dry-прогон чтения ВК | ✅ карточка формируется с обеими репликами |
