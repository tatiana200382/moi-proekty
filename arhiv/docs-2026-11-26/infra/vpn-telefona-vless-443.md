# VPN для телефона: почему перестал работать и как починить

Дата: 25.11.2026, 22:20.

## Что произошло

Скриншот владельца (21:19, LTE):

```
New connection — phone@2.31.104.44:22
Failed to establish initial TCP/IP connection
ssh: handshake failed: read tcp 100.77.105.29:54470->2.31.104.44:22: i/o timeout
```

**Разбор:**

| Что | Значение |
|---|---|
| Приложение | SSH Tunnel, профиль `phone@2.31.104.44:22` |
| Сеть телефона | LTE, адрес `100.77.105.29` — **CGNAT мобильного оператора** |
| Куда стучались | порт **22** |
| Результат | **i/o timeout** — пакеты не дошли |

## Почему не работает

| Проверка | Результат |
|---|---|
| Сервер Германии | ✅ xray и sshd живы, порт 22 **открыт** |
| С домашнего интернета SSH на 22 | ✅ работает |
| **С мобильного интернета на 22** | ❌ **таймаут** |

**Вывод:** мобильный оператор **не пропускает порт 22** к внешнему адресу (типичное ограничение в РФ). Дело не в сервере и не в пароле.

## Решение

Переключить телефон на **VLESS на порт 443** — он уже настроен на сервере и работает как обычный HTTPS.

## Что делать на телефоне

| № | Действие |
|---|---|
| 1 | Открыть **Happ** (или Streisand) |
| 2 | «+» → **Импорт из буфера обмена** (ссылка выше скопирована) |
| 3 | Подключиться |
| 4 | Проверить: `2ip.ru` показывает **Германию** |

## Откат

| Что | Как |
|---|---|
| Вернуться на SSH Tunnel | включить старый профиль `phone@2.31.104.44:22` (работает только с Wi-Fi) |
| VLESS-профиль | удалить в приложении |

## Почему SSH Tunnel ещё может пригодиться

С **домашнего Wi-Fi** порт 22 проходит — старый профиль там рабочий. С мобильного — нет.

## Дополнение 22:35 — Telegram через MTProto-прокси

**Проблема:** в Telegram на телефоне остался прокси `127.0.0.1:1082` (от старого SSH-туннеля). При включённом Happ (VLESS) этот локальный порт не работает → Telegram висит на «соединение». В логах xray за 20 минут — **0 обращений к Telegram**.

**Решение:** поднят **MTProto-прокси** на немецком сервере — не зависит от VPN.

| Параметр | Значение |
|---|---|
| Сервер | `2.31.104.44` |
| Порт | **2443** |
| Секрет | `ee8cc2070bc901b28fe1a5f54e8da260b57777772e62696e672e636f6d` |
| Служба | `mtg.service` (active) |
| Порт в ufw | ✅ открыт |
| Проверка снаружи | ✅ порт 2443 доступен |

**Ссылка для Telegram:**

```
tg://proxy?server=2.31.104.44&port=2443&secret=ee8cc2070bc901b28fe1a5f54e8da260b57777772e62696e672e636f6d
```

QR: `infra/telegram-mtproto-qr.png`

**Откат:** `systemctl disable --now mtg` и `ufw delete allow 2443/tcp`.
