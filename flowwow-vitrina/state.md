# Состояние работы

Обновлено 09.11.2026.

## Цель

Вести витрину Silver Song Flowers на Flowwow: карточки, цены, акции, подборки. План — 20–30 заказов в месяц, растянутая цель 50 при бюджете на продвижение.

## Сделано

- Собраны правила площадки: название, описание, обязательные поля, фото, модерация (источники — в [knowledge.md](knowledge.md)).
- Найден seller API `apis.flowwow.com`: ping работает, без токена 401.
- Проведён поиск готовых навыков: 3 кандидата, два адаптированы частично, один отклонён ([skills-register.md](skills-register.md)).
- Написаны два своих навыка и паспорт сотрудника.
- Собраны 3 испытания на учебных входах ([checks.md](checks.md)) — ждут приёмки.

## Не сделано и почему

| Что | Почему |
|---|---|
| Инвентаризация карточек | нет доступа: кабинет — приложение, API без токена |
| Комиссия и доставка | официальные страницы тарифов пустые |
| Реальная карточка на модерацию | нужен вход от владельца |
| Промо-план с точными цифрами | нет комиссии и статистики показов |

## Следующий шаг

1. Владелец даёт одно из двух: API-токен или 2–3 скриншота из приложения (товары, финансы, статистика).
2. Сотрудник собирает инвентаризацию витрины и находит 5–7 потерь.
3. Одна реальная карточка переделывается целиком и отправляется на модерацию.
4. После приёмки — промо-план декабря.
