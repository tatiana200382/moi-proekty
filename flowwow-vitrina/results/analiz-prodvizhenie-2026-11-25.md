# Продвижение Flowwow: инструменты, цифры, гипотезы

25.11.2026. Источники: официальная документация инструмента, API магазина (95 товаров), кабинет.

## Что изучил

### Инструмент «Продвижение товаров» (по документации)

| Параметр | Факт |
|---|---|
| Где показывается | блоки продвижения: «Также может понравиться», поиск, страницы каталога |
| Мест в блоке | **16** |
| Модель | **аукцион второй цены**: платишь ставку ближайшего конкурента + 0,01 ₽ |
| Оплата | **только за клик**; показы бесплатны |
| Дневной лимит | максимум трат за сутки, **не может быть ниже ставки** |
| Бонус | **1 000 бонусов** на первое продвижение (1 бонус = 1 ₽) |
| Кто может управлять | роль «Директор», только из приложения Flowwow Seller |
| Критерии попадания в блок | та же подкатегория, другой магазин, доставка по адресу, цена 80–120% от просматриваемого |
| Статистика кампании | показы, клики, CTR, CPC, конверсия, заказы, продажи, средняя стоимость заказа |

|---|---|---|---|---|

### Эффект топ-18 (естественный эксперимент)

| Группа | Средние показы каталога | Средние просмотры товара |
|---|---|---|
| В топ-18 (17 товаров) | **16,0** | 1,2 |
| Без топ-18 (78 товаров) | **2,3** | 0,1 |

**Товары в топ-18 получают в 7 раз больше показов.** Это подтверждает: топ-18 работает как рычаг, и он уже почти заполнен.

## Гипотезы и виртуальный расчёт

| № | Гипотеза | Расчёт | Ожидание |
|---|---|---|---|
| H1 | Продвижение даст поток кликов | CPC 15 ₽, CR 6% → **250 ₽ за заказ** | окупается (порог 600 ₽) |
| H2 | При CR 3,7% продвижение дорогое | 15 ₽ / 3,7% = **405 ₽ за заказ** | всё ещё в норме |
| H3 | Продвижение при плохой карточке сжигает бюджет | CPC 15 ₽, CR 2% → 750 ₽ | выше порога — сначала карточка |
| H4 | Активация 12 скрытых карточек добавит показов | каждая даёт ~2–16 показов | +30–190 показов/мес |
| H5 | Больше показов без конверсии не помогает | 451 × 8 = 3 600 показов × 6% × 3,7% | **8 заказов/мес** — мало |

**Вывод:** продвижение выгодно при ставке до 20 ₽ и конверсии от 4%. Но даже ×8 трафика при текущей конверсии даёт 8 заказов в месяц, а не 43. Поэтому продвижение запускаем **одновременно с работой над конверсией карточек**, а не вместо неё.

## Блокер: почему я не запустил сам

| Проверка | Результат |
|---|---|
| Веб-раздел продвижения `/admin/promotion` | **«Unknown error»** — страницы нет |
| Пункт «Продвижение» в прогрессе на вебе | отсутствует |
| API продвижения (`/apiseller/promotion/...`) | **404** на четырёх проверенных путях |
| Документация | управление — **только в приложении** Flowwow Seller |
| API скрытия/открытия карточек | работает только по `offerId`, а у наших карточек он **пустой** → недоступно |

Вывод: кампанию можно запустить только из приложения. Это две минуты: «Прогресс» → «Продвижение» → «Создать кампанию» с параметрами выше.

## Что делаю без приложения

1. Активирую 12 годных скрытых карточек через веб-кабинет (по одной, с проверкой модерации).
2. Дозаполняю 18-й слот топ-18.
3. Готовлю карточки к конверсии: заголовки «повод + состав», состав поштучно, размер и вес.
