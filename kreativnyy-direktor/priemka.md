# Приёмка креатива

Материал принимается только если все пункты «да».

- [ ] идея читается с первой строки / первого кадра;
- [ ] есть повод, а не просто «букет»;
- [ ] цена и факты совпадают с `knowledge.md`;
- [ ] один призыв, понятный шаг;
- [ ] нет выдуманных цифр, отзывов, обещаний «х5»;
- [ ] тон наш: живой, короткий, без пафоса;
- [ ] фото по стандарту: формат, свет, водяной знак, честность кадра;
- [ ] нет чужих брендов, лиц без согласия, стока;
- [ ] формат соответствует площадке;
- [ ] понятно, что проверить владельцу.

Вердикт: «принято» или «возвращено» + список правок (не больше 5).
