# Инструменты для креатива — выбор по правилу PRAVILA

Дата: 2026-11-10. Задача: выбрать инструменты для фото, видео и публикаций в ВК. Бюджет 0 ₽. Правило — `../../PRAVILA.md`, раздел «Выбор инструментов»: 10–20 кандидатов с GitHub, сравнение по звёздам, последнему коммиту, лицензии и живости, топ-3 с обоснованием.

**Как искал.** GitHub Search по запросам: «image editing cli», «social media scheduler», «content calendar», «copywriting ai», «ffmpeg video templates», «figma templates», «background removal», «vk api», «photo batch processing», «video templates». Цифры — со страниц репозиториев на 10.11.2026; дата последнего коммита — из `commits.atom`. GitHub API упирался в лимит запросов, поэтому звёзды и лицензии брал с html-страниц, дату — из Atom-ленты. Для проверки ставил `which magick ffmpeg` и импорт Pillow в Python.

**Что уже есть в среде.** Pillow 12.3.0 — есть в bundled Python 3.12; системный `python3` его не видит. `magick`, `convert`, `ffmpeg` в PATH не нашлись — если они установлены в другом окружении, перед работой проверить `which`. Figma доступна только в Claude, здесь её нет.

## Топ-3

### 1. Pillow — 13 980 ★, коммит 10.11.2026, MIT-CMU

Почему лучше остальных: уже установлен (12.3.0), не требует сервера, оплаты и лицензионных согласований; закрывает почти весь визуал — кроп 4:5 и 9:16, шаблон с ценой, водяной знак, пакетная обработка 85 фото. ImageMagick и libvips мощнее, но у нас нет задач, где нужна их скорость, а ставить второй инструмент ради того же результата — лишняя работа.

**Как используем у нас:** собираем шаблон поста 1080×1350 и сторис 1080×1920, ставим водяной знак и режем архив под формат одним скриптом.

### 2. FFmpeg — 66 896 ★, коммит 10.11.2026, LGPL-2.1+

Почему лучше остальных: стандарт для видео, живёт с 2000-х, активен; умеет собрать вертикальный ролик из 3–5 фото, обрезать, ускорить, наложить музыку и титры. Remotion и Motion Canvas дают красивую анимацию, но требуют кода и времени; Remotion к тому же платный для компании из 12 человек. Editly и ffmpeg-python заброшены — по правилу не берём.

**Как используем у нас:** делаем 10-секундный ролик «сборка букета» из трёх фото, 1080×1920, с музыкой и подписью, без отдельной съёмки видео.

### 3. vk_api — 1 365 ★, коммит 17.07.2026, Apache-2.0

Почему лучше остальных: единственный живой кандидат, который работает именно с ВК. Postiz популярнее (41 тыс. звёзд), но VK в его README не заявлен, а разворачивать AGPL-сервер с базой ради одной группы — overkill. vk_api ставит отложенные посты через `wall.post` с `publish_date` и загружает фото; 1,3 тыс. звёзд для обёртки над официальным API достаточно.

**Как используем у нас:** календарь постов в Markdown → Python-скрипт ставит отложенные записи в группу ВК; нужен токен сообщества с правами на стену и фото.

## Почему не остальные — коротко

- **Postiz, Mixpost, n8n:** Postiz и Mixpost не заявляют VK в README, у n8n VK-интеграция не проверена; всем трём нужен сервер, база и обслуживание — для одной группы это дороже по времени, чем 20 строк на Python.
- **Remotion:** лицензия бесплатна только для компаний до 3 сотрудников; у нас 12 — нужна платная.
- **ImageMagick, libvips:** хорошие, но Pillow уже есть; второй инструмент не решает новую задачу.
- **rembg:** вырезанный фон выглядит как коллаж, а стандарт визуала запрещает коллажи и генерацию товара.
- **Penpot, Excalidraw:** полезны для схем и мудборда, но не для точной вёрстки 1080×1350; Penpot ещё и требует сервер.
- **marketingskills, anti-slop:** это чек-листы и правила тона, а не программы; возьмём в работу как памятку.
- **Google Fonts:** не инструмент, а источник шрифтов Cormorant и Inter — нужен для Pillow.

## Что осталось за владельцем

1. **VK-токен.** Создать токен сообщества с правами `wall`, `photos`, `offline` (или `groups`) и передать не в файлы, а в защищённое место. Без него автопубликация не работает.
2. **Проверить ffmpeg.** Если его нет — установка бесплатная, но это изменение системы; нужно ваше «да». Альтернатива без установки — только фото, без роликов.
3. **Разрешить тест.** Один шаблон поста и один 10-секундный ролик, без публикации: сначала смотрим, потом решаем.
4. **Дать 3 свежих фото** букета дня — иначе шаблон и ролик останутся на архивном примере.
