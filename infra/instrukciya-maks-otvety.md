# Как отвечать клиентам из чата «Заявки» (MAX)

Дата: 26.11.2026. Формат закреплён владельцем в чате MAX.

## Формат сообщения

```
<номер диалога> <текст ответа>
```

**Пример:**

```
41432799 Здравствуйте, Иринка! Заказ принят, подтвердите дату и время.
```

| Что | Правило |
|---|---|
| Номер диалога | только **цифры**, без решётки |
| Разделитель | **пробел** |
| Далее | текст ответа клиенту |
| Слово «ответ» | **не нужно** |

## Работают и старые варианты (для совместимости)

| Вариант | Разбор |
|---|---|
| `#41432799 ответ: текст` | номер `41432799`, текст «текст» ✅ |
| `41432799 ответ: текст` | ✅ |
| `41432799 текст` | ✅ **основной формат** |

## Что происходит после отправки

| Шаг | Что видно в чате |
|---|---|
| 1 | Бот читает сообщение сотрудника |
| 2 | Отправляет текст клиенту в ВК или Авито |
| 3 | В чате появляется подтверждение: `✅ Имя · ответ в ВКонтакте` и текст |

Если отправить не удалось — приходит `⚠️ Не отправлено…` с причиной.

## Что важно помнить

| Правило | Почему |
|---|---|
| Номер — **из карточки заявки** | у каждого клиента свой диалог |
| Текст — **клиенту**, без служебных пометок | «Черновик:», «Вы:» вырезаются автоматически |
| Одна строка = один ответ | несколько ответов — несколькими сообщениями |
