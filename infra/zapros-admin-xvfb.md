# Запрос администратору: Xvfb на plex2

Дата: 26.11.2026, 03:45.

## Текст (можно отправить как есть)

---

Саша, привет! Нужна одна установка на plex2: пакет **xvfb** — виртуальный экран.

Без него Авито не показывает в браузере интерфейс чата: страница мессенджера открывается, список чатов видно, а поле ввода в чате не отрисовывается (вместо чата «Перейти в Помощь»). С виртуальным экраном браузер работает как обычный, с окном, и чат появляется.

Команда:

```
sudo apt install -y xvfb
```

Больше ничего ставить не нужно, права root — только на установку этого пакета.
