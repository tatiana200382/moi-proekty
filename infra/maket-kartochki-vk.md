# Макет карточки ВК (с фото, временем и нашим ответом)

Дата: 26.11.2026, 01:14. Только макет и тест в режиме «показать», отправки нет.

## Макет

```
[ФОТО букета — картинкой, не ссылкой]
🟪 26.11 01:13 · Заявка ВКонтакте
Клиент: Иринка
От клиента: Добрый вечер
Наш ответ: Здравствуйте, Иринка! Заказ № 1094406 принят: букет «Нежная роскошь», 7 100 ₽.

Ответить: 41432799 ваш текст
```

## Что проверено (режим `--dry`)

| Проверка | Результат |
|---|---|
| Время **первой строкой** | ✅ `🟪 26.11 01:13 · Заявка ВКонтакте` |
| Сообщение клиента | ✅ `От клиента: Добрый вечер` |
| **Наш ответ** | ✅ `Наш ответ: …` (из журнала `runtime/vk-sent.json`) |
| Подсказка без решётки | ✅ `Ответить: 41432799 ваш текст` |
| Наши сообщения не создают карточку | ✅ фильтр |
| Спам отфильтрован | ✅ |
| Отправка в чат | ❌ **не включал** |

## Как появляется «Наш ответ»

| Шаг | Что |
|---|---|
| 1 | `vk-reply-browser.py` при успешной отправке пишет текст в `runtime/vk-sent.json` |
| 2 | `vk-inbox.py` при следующей карточке берёт оттуда последний ответ |
| 3 | В карточке появляется строка «Наш ответ: …» |

**Проверено:** после записи в журнал карточка показала наш текст.
