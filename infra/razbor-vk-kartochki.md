# Почему из ВК не приходили карточки в чат «Заявки»

Дата: 26.11.2026, 01:08. Только диагностика и тесты, живые отправки не включал.

## Причина (найдена)

| Факт | Значение |
|---|---|
| Моя правка «обход прокси» в `vk-inbox.py` | вставилась **с битым отступом** |
| Результат | скрипт падал **при запуске** (ImportError/SyntaxError) |
| В логе цикла | `ВКонтакте: диалогов 0` / `всего карточек: 0` |
| Вывод | карточки из ВК **не создавались вообще**, начиная с этой правки |

**То есть «Ирина пишет, а в чат ничего не приходит» — следствие моего же сломанного файла.**

## Что исправлено (с резервной копией `vk-inbox.py.bak-dry`)

| Исправление | Зачем |
|---|---|
| отступы в `read_dialogs()` | скрипт снова запускается |
| режим `--dry` | проверка **без отправки** в чат |
| в `--dry` состояние не пишется | тест не влияет на работу |
| время — **первой строкой**: `🟪 26.11 01:07 · Заявка ВКонтакте` | как вы просили |
| фильтр «наши сообщения» | не присылает карточку, если последним писал магазин |
| фильтр спама | «делаю сайты», «продвижение», «SEO» и т.п. |
| подсказка ответа: `41432799 ваш текст` | совпадает с новым форматом |

## Изолированный тест (без отправки)

| Проверка | Результат |
|---|---|
| Реальное чтение диалогов | ✅ 4 диалога |
| Карточка для клиентского сообщения | ✅ `🟪 26.11 01:07 · Заявка ВКонтакте / Клиент: Иринка / Сообщение: Добрый вечер / Ответить: «41432799 ваш текст»` |
| Наши сообщения и спам | ✅ отфильтрованы (0 карточек) |
| Запись состояния в тесте | ✅ не пишется |
