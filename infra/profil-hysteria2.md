# Hysteria2 для телефона: UDP 443

Дата: 25.11.2026, 23:35. Гипотеза 5.

## Почему Hysteria2

| Проверка | Вывод |
|---|---|
| TCP-профили (443, 2053, xhttp 8443) на её телефоне | ❌ соединение есть, данные не идут / nginx отдаёт **408** |
| Алматы (xhttp) на её телефоне | ✅ работает |
| Значит | проблема в **прохождении TCP** через её оператора |

Hysteria2 работает по **UDP/QUIC** — другой транспорт, часто проходит там, где TCP «душат».

## Что настроено

| Компонент | Значение |
|---|---|
| Сервер | `/usr/local/bin/hysteria` (v2.14.0) |
| Порт | **443/UDP** |
| Сертификат | самоподписанный (CN `www.bing.com`) |
| Пароль | `SilversongHy2026` |
| Маскировка | прокси на `www.bing.com` |
| Служба | `hysteria.service` — **active** |
| ufw | 443/udp разрешён |
| TCP-443 (xray) | **не тронут** |

## Откат

```
systemctl disable --now hysteria
ufw delete allow 443/udp
```

## Если и это не сработает

| Гипотеза | Что делать |
|---|---|
| Оператор режет **весь UDP** | WireGuard на 51820 (тоже UDP) — смысла нет |
| Оператор режет всё, кроме 443/TCP с «правильным» TLS | нужен **VLESS+Reality, но с другой маскировкой** (SNI другого сайта) |
| Проблема в Happ | проверить тот же профиль в **Streisand** |
