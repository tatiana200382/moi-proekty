## Вывод

| Что | Как есть |
|---|---|
| Блокировка не только по IP | **`curl` и headless-браузер блокируются даже с домашнего IP** |
| Обычный браузер с профилем | ✅ работает с домашнего IP |
| Адрес HostKey | ⚠️ показывает CAPTCHA «Проблема с IP» — **адрес дата-центра не подходит** |
| Домашний адрес | ✅ подходит, но нужен **настоящий браузер с профилем** |

## Что это значит для задачи

1. **HostKey** остаётся для ВК и MAX (они работают), но **не для Авито**.
2. **Авито** должен работать с домашнего адреса — либо на Маке, либо на домашнем сервере.
3. На домашнем сервере нужен **настоящий Chromium** (не headless), запускаемый **без root** (через Playwright в личной папке) и **профиль с cookies** от её браузера.

## План (без root, без риска для их системы)

| № | Шаг | Проверка |
|---|---|---|
| 1 | `python3 -m venv` в домашней папке, `pip install playwright` | установилось |
| 2 | `playwright install chromium` | бинарник в `~/.cache` |
| 3 | Запуск Chromium под `xvfb-run` (или headless=new + stealth) | Авито открывается |
| 4 | Перенос cookies из Chrome на Маке | Авито отдаёт страницы без CAPTCHA |
| 5 | Бот заявок по расписанию | заявка → MAX |
