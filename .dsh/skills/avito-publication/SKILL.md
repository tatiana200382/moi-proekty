# Публикация объявления на Авито

Проверено на живой карточке 8404314990 (2026-11-11). Все нормы Авито меняются: перед работой сверять с кабинетом.

## Когда применять

- Новое объявление о букете, композиции, корзине.
- Правка опубликованного: заголовок, фото, цена, описание.
- Разбор, почему карточка не даёт просмотров и контактов.

Не применять: для вакансий (другая категория и правила) и для услуг (отдельная карточка, нельзя дублировать товар).

## Входные данные (без них не начинать)

| Поле | Откуда |
|---|---|
| Тип товара: букет / композиция / корзина / монобукет | фото + `znaniya/floristika.md` |
| Цена одной цифрой | `knowledge.md` |
| Состав и высота | фото, подтверждение владельца |
| Адрес и часы | `knowledge.md` |
| 5 фото 4:3, 1600×1200 | `results/foto-gotovye/` |
| Коды ТН ВЭД и ОКПД2 | каталог Авито в форме (для срезанных цветов — 0603 19 700 0 и 01.19.21.190) |
| «Да» владельца на публикацию | правило первых 10 объявлений |

## Действия

1. **Разбор 100 конкурентов.** 3–4 запроса по Санкт-Петербургу, не меньше 100 уникальных карточек. Парсер: `ii-marketolog/tools/js/parse-ads.js`. Фиксировать: заголовок, цена, фото, отзывы, продвижение. Топ-10 — по признакам конверсии. Взять минимум 3 приёма. Результат — `agent-marketolog/avito/analiz-konkurentov-ГГГГ-ММ-ДД.md`.
2. **Заголовок.** До 50 знаков, формула «товар + количество/размер + гео или доставка». Без цены, «недорого», телефонов и эмодзи.
3. **Фото.** 5 разных кадров 1600×1200 по `foto-pravila.md`, первое — букет целиком. Проверить, что нет повторов.
4. **Цена.** Одна реальная цифра. Три уровня — только в описании.
5. **Описание.** 900–1000 знаков: крючок → для кого и повод → «почему у нас» (3–4 доказательства) → цены → адреса и часы → рейтинги с датой → один призыв с готовой фразой. **Телефонов нет.**
6. **Характеристики.** Вид товара, монобукет (только если один вид цветка), состав по фото, цвет, страна, доступность.
7. **Коды.** Вписать ТН ВЭД и ОКПД2 из каталога. Поля «Номер свидетельства», «Ссылка на свидетельство», «Номер декларации» **оставить пустыми** и поставить галочку «Подтверждаю, что документы не требуются». Текст «Данные не нужны» в полях даёт ошибку «Неверный формат».
8. **Адрес.** Выбрать из подсказок города, проверить район — иначе карточка уходит в другой район.
9. **Контакты.** Контактное лицо заполнено, телефон из профиля, не в тексте.
10. **50 проверок.** Пять кругов по 10 пунктов из `agent-marketolog/avito/chek-list-publikacii.md`.
11. **Проверка владельцем.** Скриншот публичной страницы + текст + список фото + строка «проверок 50/50, конкурентов 100, приёмов 3».
12. **Публикация и оплата.** Тариф по просмотрам: выбрать срок (14/30/60 дней), пропустить продвижение, оплатить с кошелька.
13. **Самопроверка.** Открыть публичную страницу: описание целиком, 5 фото грузятся, цена, адрес, характеристики, нет предупреждений.

## Контроль результата

| Что | Как проверить |
|---|---|
| Заголовок | до 50 знаков, есть количество или гео |
| Фото | 5 разных, первое — букет целиком, миниатюры грузятся |
| Описание | видно целиком на публичной странице, а не одну строку |
| Телефон | отсутствует в тексте и на фото |
| Коды | ошибок «Неверный формат» нет |
| Цена и адрес | совпадают с `knowledge.md` |
| Публикация | в «Мои объявления» статус «Активно», карточка находится поиском |

## Типовые ошибки

1. **Описание сохранилось одной строкой.** Вставка через `execCommand` в contenteditable иногда сохраняет только хвост. Вводить текст реальным набором и после сохранения проверять публичную страницу.
2. **«Данные не нужны» в полях документов** → «Неверный формат». Поля очистить, оставить галочку.
3. **Фото не отображается** после первой публикации — удалить все и залить заново те же файлы.
4. **Неверный район в адресе** — выбрать подсказку «улица … , Санкт-Петербург», а не первую строку списка.
5. **Дубли фото** — Авито показывает 5, но по факту 3 разных. Сверять визуально.
6. **Телефон в тексте** — нарушение, объявление снимают.
7. **Цена «от»** без реальной позиции — отклонение.
8. **Дубль товара** — блокировка, включая разные категории.
