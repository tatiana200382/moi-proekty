# Практическая проверка команды

Статус всех ролей: инструкции подготовлены; работа на данных магазина ещё не проверена. Оценка не присваивается за самоописание.

Общий учебный кейс: реальное фото букета и подтверждённая карточка товара от владельца. Если их нет, допускается только явно обозначенный учебный пример без публикации.

| Роль | Практическое испытание | Условие допуска |
|---|---|---|
| Руководитель | Составить план выпуска на неделю | Есть владельцы, ресурсы, сроки и зависимости |
| Стратег | Сформировать 3 гипотезы для разных поводов | У каждой есть измерение и связь с заказом |
| Контент-менеджер | Подготовить один пакет в 4 версиях | Данные согласованы, форматы и ссылки проверены |
| Редактор | Проверить предложение с ошибкой в цене/доставке | Найдены все критические расхождения с карточкой |
| Копирайтер | Написать предложение по карточке | Нет новых выдуманных свойств, есть действие |
| Сценарист | Написать съёмочный сценарий | Снимается доступной командой; понятен без звука |
| Фотограф | Подготовить съёмочный лист, затем оценить снимки | Товар показан точно, есть масштаб и детали |
| Ретушёр | Обработать реальное фото | Цвет и количество цветов не изменены; сохранён исходник |
| Видеограф | Подготовить план и проверить реальные исходники | Резкость, звук и покрытие сценария достаточны |
| Монтажёр | Сделать ролик из предоставленных файлов | Экспорт просмотрен; титры и звук проверены |
| Дизайнер | Подготовить карточку и обложку | Читаются на телефоне; товар не искажён |
| Моушн-дизайнер | Создать вставку при наличии редактора | Читается и не закрывает товар |
| Ведущий | Подготовить подачу и проверить запись человека | Естественно и без неверных обещаний |
| Комьюнити | Ответить на заказ, жалобу и запрос замены | Условия точны; данные защищены; есть передача |
| Аналитик | Рассчитать показатели по реальной выгрузке | Формулы и знаменатели проверены; ограничения указаны |
| Продвижение | Подготовить тест с лимитом и остановкой | Учитывает маржу и возможности доставки |

Если испытание провалено: исправить артефакт, повторить только соответствующую проверку, записать вывод. Владелец оценивает бренд и бизнес-факты, флорист — продукт, доступный инструмент — технический результат. Для независимой экспертизы нужен отдельный проверяющий; повторная проверка той же моделью не считается независимой.
