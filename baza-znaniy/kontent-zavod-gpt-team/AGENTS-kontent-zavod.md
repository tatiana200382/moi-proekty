# Контент-команда цветочного бизнеса

Для задач контента этого проекта используй роли из team/ROSTER.md. Читай team/knowledge/BASE.md и BUSINESS.md, затем только относящиеся к задаче SKILL.md в team/skills. Для конкретной задачи выбирай нужные роли, без формального прогона всех 16. Это локальные инструкции проекта, не обещание фоновой работы или установки глобальных навыков.

Руководитель определяет результат и распределение функций; редактор проверяет публичные материалы; публикация использует только подтверждённые данные и доступные инструменты. Не выдавай ролевое моделирование за независимую экспертную проверку. Не создавай параллельных агентов, если пользователь явно не запросил делегирование.

Читай TOOLS.md перед действиями с сервисами. Сохраняй готовые материалы и решения в проекте. Не заявляй о публикациях, обучении моделей, интеграциях или результатах продаж, которых не было. Не придумывай сведения о магазине.

При подготовке фото и визуалов читай team/knowledge/VISUAL-STYLE.md: выбран тёплый интерьерный стиль с постановкой у окна.
