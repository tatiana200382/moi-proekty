# Подготовка учебного хранилища

Начните с [урока 1](LESSON-01.html). Он содержит все действия установки и открытия папки для Mac и Windows. [Урок 2](LESSON-02.html) посвящён проверке и продолжению в другом чате.

1. Установите Obsidian с https://obsidian.md/download.
2. Скопируйте папку template-vault из комплекта в домашнюю папку.
3. Переименуйте копию в AI-Memory-Lab.
4. В Obsidian выберите «Открыть папку как хранилище» и укажите копию.
5. Проверьте три папки слева: 00_start, 01_projects, 04_inbox.

Свой случай: `04_inbox/my-experience-source.md`. Задача: `01_projects/my-project/index.md`. Черновик создаётся в первом занятии: `04_inbox/my-first-experience.md`. Записка продолжения заполняется во втором: `01_projects/my-project/handoff.md`.

## После двух занятий: выберите нужный вариант

Эти варианты решают разные задачи. Проходить их все по очереди не требуется.

**Реестр опыта без сторонних плагинов.** Если стало трудно просматривать много кейсов, попробуйте встроенный Bases: он показывает файлы и свойства в выбранном представлении. Сначала проверьте доступность нужного вида в своей версии. Фильтр вида не ограничивает права ИИ. [Bases](https://obsidian.md/help/bases).

**Локальный агент.** Выберите учебную папку как рабочую область и отдельно проверьте чтение, создание тестовой заметки и повторное чтение. Инструкции из `AGENTS.md` передайте явно. Пройдите [проверки приёмки](ACCEPTANCE.md), включая запрет доступа к искусственному закрытому файлу. Не подключайте рабочий vault, shell с широкими правами или автоматический wrap ради первого теста. Модель и программа, предоставляющая ей инструменты, - разные части системы.

**Официальный desktop CLI.** Это необязательный адаптер после ручного урока. Документация требует installer 1.12.7+, включение CLI в **Settings → General** и работающее приложение; первый вызов может его запустить. Наличие этой функции не означает, что она включена на вашем Mac. Для режима чтения разрешайте конкретные операции: CLI содержит также команды изменения и `eval`. [Справка CLI, проверена 03.11.2026](https://obsidian.md/help/cli).

**MCP.** Нужен совместимый клиент; он не обязателен для памяти или синхронизации. Для локального stdio можно рассмотреть [filesystem server](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem), указав только учебную папку и зафиксировав версию. Альтернатива при работающем Obsidian - плагин [Local REST API со встроенным MCP](https://github.com/coddingtonbear/obsidian-local-rest-api): перед подключением проверьте установленную версию, авторизацию и список доступных операций. Это разные варианты транспорта, без обещания автоматической совместимости каждого клиента.

Roots в актуальной спецификации MCP устарели и служат подсказкой о контексте, а не механизмом доступа. `readOnlyHint` также не принуждает инструмент работать только на чтение. Реальную границу задают сервер и среда исполнения; проверяйте её отрицательными тестами. [Roots](https://modelcontextprotocol.io/specification/2026-07-28/client/roots), [аннотации MCP](https://github.com/modelcontextprotocol/modelcontextprotocol/blob/main/blog/content/posts/2026-03-16-tool-annotations.md).

**Поиск по смыслу.** Добавляйте его, если ручной поиск уже мешает работе. Проверяйте найденные фрагменты и ссылки на оригиналы. Локальный индекс не доказывает локальность генерации ответа: выбранный облачный провайдер может получить эти фрагменты.

**Headless.** Отдельный beta-клиент требует Node.js 22+; для Headless Sync нужна подписка Sync. Он полезен для серверного обмена, но не требуется первому уроку. Не запускайте Headless Sync как второй Sync-клиент на том же устройстве рядом с desktop Sync. [Официальные требования Headless Sync](https://obsidian.md/help/sync/headless).

## Копия, синхронизация и ключи

До автоматизации закройте учебное хранилище, сделайте отдельную копию его папки и проверьте восстановление искусственной заметки. Синхронизация переносит изменения между устройствами; резервная копия нужна для возврата прежнего состояния. Выбранный способ обмена проверяется отдельно от доступа ИИ.

API-ключи храните вне vault, комплекта и экспортов, в менеджере секретов или предусмотренном хранилище клиента. `.gitignore` не защищает от чтения агентом или другим синхронизатором. Не переносите личные конфигурации преподавателя в учебный шаблон.

При нескольких редакторах сохраняйте предложения отдельно. Условная запись Local REST API относится к операциям через этот API; она не обещает общей защиты от параллельных записей из shell или другого редактора. Сначала испытайте конфликт на искусственных данных.
