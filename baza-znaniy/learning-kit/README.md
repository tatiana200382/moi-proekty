# Второй мозг с ИИ - учебный комплект 2.2

Два занятия без терминала, плагинов и программирования. Автор: Виталий Волков.

1. [Урок 1. Сохраните свой опыт](LESSON-01.html), около 30 минут: установка Obsidian, свой случай и сохранённый черновик.
2. [Урок 2. Проверьте и продолжите в другой нейросети](LESSON-02.html): проверка, записка продолжения и второй сервис.

Распакуйте архив и откройте LESSON-01.html двойным щелчком. Для Obsidian скопируйте только template-vault в отдельную папку AI-Memory-Lab. Демонстрационные данные искусственные; личные заготовки ещё нужно заполнить.

## Что получится

Вы сохраните один небольшой случай из собственного опыта, отделите наблюдение от вывода, проверите черновик ИИ и запишете его в Obsidian. Затем другая нейросеть продолжит работу по сохранённым файлам. Важный результат - вы сможете объяснить, откуда взялся вывод и когда его нельзя применять.

Урок проверяет четыре способности: **сохранить → найти → понять → применить**. Число заметок и установленных плагинов не является критерием успеха.

## Как открыть комплект

1. Распакуйте ZIP в обычную папку. Дважды нажмите `LESSON-01.html`: урок откроется в обычном браузере. Весь текст и запросы уже внутри; `LESSON-01.md` - тот же материал в Markdown.
2. По уроку скопируйте **только папку `template-vault`**, переименуйте копию в `AI-Memory-Lab` и откройте её в Obsidian как хранилище. Программы, тесты и весь комплект не нужно помещать внутрь vault.
3. Работайте со своей копией. Демонстрационный проект остаётся примером; собственный опыт записывайте в подготовленные личные заготовки.

## Материалы двух занятий

В вашей копии vault появятся или будут заполнены:

- `01_projects/my-project/index.md` - задача и следующий шаг;
- `04_inbox/my-experience-source.md` - исходное наблюдение;
- `04_inbox/my-first-experience.md` - запись опыта со статусом и областью проверки;
- `01_projects/my-project/handoff.md` - передача контекста другой модели.

Статус `reviewed` означает, что человек сверил запись с указанными основаниями. Он не означает доказанную причинность или универсальность правила. Передача файлов в новый чат остаётся явным действием: сохранённая заметка сама по себе не появляется в контексте всех нейросетей.

## Необязательный локальный адаптер

Этот раздел нужен после двух занятий. `brain_io.py` не запускает модель и не требует сторонних библиотек. Python 3.11+ можно получить на [официальном сайте](https://www.python.org/downloads/).

Из папки распакованного комплекта:

```sh
python3 -m unittest discover -s tests -v
python3 brain_io.py export --vault template-vault --allowlist allowlist.json > context-demo.md
python3 brain_io.py import --help
```

Этот allowlist экспортирует **вымышленный демонстрационный пример**, а не личные записи урока. Он нужен для технического прогона адаптера и не является входным пакетом личных промптов из `prompts/`. Для личного экспорта сначала укажите путь своей копии vault и создайте отдельный явный список выбранных файлов; просмотрите их содержимое. Не добавляйте всю папку автоматически.

Импорт используется только после проверки текста человеком. Он создаёт новый файл в `04_inbox/` указанного vault; существующее имя должно привести к отказу. Точные параметры показывает `import --help`. Флаг `--reviewed` фиксирует действие пользователя, а не устанавливает истинность заметки. При сбое новый файл может остаться неполным - откройте и проверьте результат. Ручной маршрут не требует этого инструмента: ученик сохраняет текст вручную.

Автоматические тесты адаптера и прошлые тесты преподавателя не подтверждают подключение конкретного ученика. Его результат отмечается отдельно по [ACCEPTANCE.md](ACCEPTANCE.md).
