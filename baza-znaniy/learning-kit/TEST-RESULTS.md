# Проверки учебного комплекта

## Редакция 2.2.0 - 04.11.2026

Изменены учебные инструкции и примеры. Новое человеческое прохождение пока не проводилось. Квитанции проверки браузера, архива и адаптера для этого выпуска формируются отдельно при сборке. Исторические результаты ниже не являются новым тестом редакции 2.2.

## Историческая проверка 2.1.0

Проверено 03.11.2026. Авторский проход и независимая проверка выполнялись отдельно.

- 9 тестов локального адаптера прошли на временных данных. Код адаптера не менялся.
- Агент реально распаковал ZIP 2.0 через Finder, открыл отдельный чистый vault в Obsidian 1.14.5, заполнил исходный лист и проект, передал четыре текста в ChatGPT web и получил разбор и черновик.
- В ChatGPT выбран временный чат Без персонализации. Содержательный ответ перечислил четыре файла и сохранил неизвестную прибыль.
- Опыт, проект и handoff записаны через интерфейс только учебного Obsidian. Закрыто и повторно открыто учебное окно. Все 12 Markdown SHA до/после совпали. Более поздняя правка разметки учтена отдельной квитанцией; она не подменяет старые хеши.
- По найденным затруднениям исправлены выбор папки, исходный Markdown с YAML, проверка формата ответа, раннее сохранение draft, параметры контекста и отличие загрузки от отправки. 8 этапов и 4 полных запроса включены в автономный HTML.
- Независимый проверяющий не нашёл блокирующих противоречий в исправленной инструкции. Свежая установка и самостоятельное прохождение человеком не проводились.

Подробные наблюдения, результаты другого провайдера и ограничения находятся в отдельном отчёте практического прохождения, выдаваемом вместе с комплектом. Рабочие заметки пользователя не редактировались.

## Границы текущей проверки

Первый этап 03.11 был остановлен загрузкой Claude web и региональным отказом Gemini. Позже реальное продолжение было получено через Claude web, Claude Code и штатный DeepSeek Harness; квитанции этого восстановления хранятся отдельно от комплекта. Прямой API не засчитывался вместо Harness.

Новая редакция 2.2 не прошла самостоятельный человеческий пилот. Скриншоты интерфейса, локальная проверка страницы и техническое чтение файлов не измеряют понимание, сложность обучения или прирост продуктивности. «Около30минут» - план занятия, без измеренного результата ученика.

## Упаковка

SHA256SUMS.json содержит контрольные суммы выдаваемых файлов, кроме самого манифеста. ZIP исключает кэши, тестовый vault и служебные файлы прогона. CRC, состав и контрольные суммы проверяются отдельно. Таблицы ACCEPTANCE.md заполняются результатами конкретного ученика.
