# Контент-завод (GPT) и отдел маркетинга

Одна точка обмена: задачи уходят на контент-завод, готовое возвращается сюда. Никаких «в личку» и «в другом чате».

## Кто с кем

| Сторона | Кто | Что делает |
|---|---|---|
| Заказчик | директор по маркетингу (`../direktor-marketinga/`) | решает, какой контент нужен и зачем |
| Постановщик | креативный директор (`../kreativnyy-direktor/`) | пишет бриф и задачу по шаблону |
| Исполнитель | контент-завод (GPT) | делает тексты, сценарии, варианты креативов |
| Приёмщик | Вова (`../agent-marketolog/`) | проверяет по стандартам, обрабатывает фото, публикует после «да» |

## Как это работает

1. Задача кладётся в `zadaniya/` по шаблону `shablon-zadaniya.md`, коммитится и пушится.
2. Контент-завод читает задачу (через коннектор GitHub в ChatGPT) **или** агент отправляет текст задачи в чат «контент-завод».
3. Ответ возвращается в `gotovoe/` тем же именем файла.
4. В `ochered.md` статус: `новая → отправлена → готова → принята / возвращена`.

## Правила синхронизации

- **Один файл задачи — один ответ.** Не смешивать несколько задач в одном запросе.
- **Факты только наши:** цены, адреса, телефоны — из `../agent-marketolog/knowledge.md`. Фабрика не придумывает цифры.
- **Формат ответа фиксирован** (см. `pravila-dlya-fabriki.md`): без вступлений, сразу материал, в конце — что проверить.
- **Ничего не публикуется** ни фабрикой, ни агентом без «да» владельца.
- **Фото обрабатываются у нас** по `../agent-marketolog/foto-pravila.md`; фабрика тексты и сценарии, не фото.
